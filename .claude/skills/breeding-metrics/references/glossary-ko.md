### 지역 적응 시험(MET)·안정성 (2026-10-27 정리 회차 3 추가)

| 화면 표기 | 약어·영문 | 비고 |
| --- | --- | --- |
| 지역 적응 시험 | MET, multi-environment trial | "다환경 시험"을 괄호로 병기할 수 있다 |
| 환경 | Environment | 지역 × 연도 한 조합(예 "철원 2026") |
| 유전자형×환경 상호작용 | GxE, G×E | 화면 첫 등장 "유전자형×환경 상호작용(GxE)" |
| GGE 바이플롯 | GGE biplot (G + GE) | "어느 계통이 어디서 이겼나(which-won-where)" 병기 가능 |
| 메가 환경 | Mega-environment | which-won-where 다각형에서 같은 꼭짓점 승자를 갖는 지역 묶음. 권역(행정·기후 구분)과 같은 말이 아니다 |
| 환경 지수 | Environmental index, I | 환경 평균 − 전체 평균(형질 단위, 예 kg/10a) |
| 반응 규준 | Reaction norm (Finlay–Wilkinson) | 환경 지수에 대한 회귀선 |
| 반응 기울기 | Regression slope, b | b = 1 평균 반응, b > 1 좋은 환경에 민감 |
| 생태가 | Ecovalence, W (Wricke) | "Wricke 생태가(W)". 작을수록 안정. "안정도"로 바꿔 쓰지 않는다 |
| AMMI 안정성 값 | ASV | 작을수록 안정 |
| 최소 유의차 | LSD | "LSD(5%)"처럼 유의 수준을 함께 쓴다 |
| 대비 품종 대비 지수 | Index vs. check | 100 · 계통 평균 / 대비 품종 평균(%) |
| 분산 분해 | Variance partitioning | G · E · GxE 비율 |

### 파이프라인 세트·연중 판정·KASP 방향 (2026-10-29 정리 회차 4 추가)

값과 연도별 수는 `program-baseline.md` 「MET 세트 정의」·「연중 연도 KPI 판정」·「KASP 대립유전자 방향」을 따른다.

| 화면 표기 | 약어·영문 | 비고 |
| --- | --- | --- |
| 완료 세트 | Completed MET set | 그해 지역 적응 시험(2년제)을 마친 세트 = 출원 후보 선정 대상. 화면 "지역 적응 시험(MET) 완료" 또는 "그해 완료 세트". **"MET 진입"으로 쓰지 않는다** |
| 1년차 세트 | First-year MET set | 그해 시작한 MET 세트(Y~Y+1). 화면 "MET 1년차"·"1년차 세트" |
| 포장 계통 | Lines in field | 그해 포장에 실제로 심은 계통 = 완료 세트 + 1년차 세트. 이앙·포장 작업을 말할 때 쓴다. 예 "포장 38계통(2년차 18 · 1년차 20)" |
| 코호트 진급률 | Cohort advancement rate | 같은 계통 묶음을 따라간 다음 단계 수 / 이전 단계 수. AYT → MET는 완료 세트(Y) / AYT(Y−2). 문장 표기 "2024 생산력 검정(AYT) 38계통 중 47.4%" |
| 같은 해 단계 수 비 | Cross-sectional stage ratio | 같은 해 두 단계 계통 수의 비(다른 해에 출발한 세트끼리의 비). breeding-pipeline-flow는 "횡단 통과율(같은 해 단계 수 비)". "AYT → MET 통과율"로 부르지 않는다. 코호트 진급률과 직접 비교하지 않는다 |
| 연말 전망 달성률 | Year-end forecast achievement | 진행 중 연도의 누계형 KPI(출원 건수 등) 등급 근거 = (실적 + 그해 안 확정 예정) / 목표. 큰 값·표시 달성률은 실적, 전망은 보조 문구 "연말 전망 2/3건(66.7%)" |
| 효과 대립유전자 / 표적 대립유전자 | Effect (target) allele | KASP 기능 마커에서 BB = 효과 대립유전자 동형(저항성 보유·저아밀로스·출수 지연형·반왜성·천립중 증가형). 방향이 정해진 유리 형질이면 "유리 대립유전자"도 쓴다(haplotype-viewer). ID 마커(품종 식별용 중립 SNP)는 BB = 대체 대립유전자(IRGSP-1.0 기준) |
| 진급 심사회의 / 진급 심의 | Advancement review meeting | 단계 진급을 정하는 회의. 날짜가 정해진 회의는 "진급 심사회의 2026-11-06(예정)", 대기 노드처럼 짧게 쓸 때 "진급 심의 대기(11-06)" |

## 숫자 표기

- 천 단위 구분 쉼표: 12,480
- 큰 수는 한국식 단위 선택 가능: 1.2만 샘플(대시보드 KPI), 표에서는 원 숫자
- p값: 3.2×10⁻⁹ 또는 3.2e-9(표), −log10 변환값은 소수 1~2자리
- 백분율: 소수 1자리(98.7%), 상관·정확도: 소수 2자리(0.62)
- 날짜: 2026-10-23 또는 2026년 10월
