# 지표 카탈로그

값 범위는 목업 데이터의 기본값이다. 작물·형질·프로그램 규모에 따라 달라지므로, 범위를 벗어나는 값을 쓸 때는 명세에 이유를 적는다.

## 목차
1. 육종 프로그램 성과 지표
2. 정량유전 파라미터
3. 유전체 선발(GS) 지표
4. 유전체 분석실·데이터 품질 지표
5. GWAS·QTL 지표
6. 유전 다양성 지표
7. 표현형·시험포장 지표
8. 운영·비용 지표
9. 지역 적응 시험(MET)·안정성 지표
10. 종자 관리 지표

## 1. 육종 프로그램 성과 지표

| 지표 | 정의·계산식 | 단위 | 목업 범위 |
| --- | --- | --- | --- |
| 유전적 개량량 ΔG | 육종가 방정식 ΔG = i·r·σA / L | 형질 단위/년 또는 평균 대비 %/년 | 작물 수량 0.5~2.5%/년, 젖소 유량 약 1%/년 |
| 유전적 추세(genetic trend) | 코호트(출생·육성 연도)별 평균 EBV/GEBV의 회귀 기울기 | 형질 단위/년 | ΔG와 같은 범위, 연도별 노이즈 포함 |
| 품종 개발 기간 | 최초 교배~품종 출원까지 | 년 | 전통 10~12년, 디지털육종 적용 5~8년 |
| 파이프라인 단계별 계통 수 | F1 → 세대 진전 → 예비·생산력 검정 → 지역 적응 → 출원 | 계통 수 | 예: 2,000 → 600 → 120 → 25 → 2~3 (깔때기) |
| 신품종 출원·등록 | 연간 출원 수 | 건 | 기관 규모에 따라 1~10 |
| 목표 대비 달성률 | 실적 / 목표 | % | 70~120% |

## 2. 정량유전 파라미터

| 지표 | 정의 | 범위 | 비고 |
| --- | --- | --- | --- |
| 협의 유전력 h² | σA² / σP² | 0~1 | 수량 0.2~0.4, 초장·출수기 0.5~0.8, 내병성 0.1~0.5 |
| 반복력 | 동일 개체 반복 측정 상관 | h² ≤ 반복력 ≤ 1 | 축산 형질에 주로 사용 |
| 유전 상관 rg | 두 형질 육종가의 상관 | −1~1 | 수량-품질은 흔히 음(−0.3~−0.1) |
| 상가적 유전분산 σA² | — | 형질 단위² | σA는 평균의 5~15%가 흔함 |
| 선발 강도 i | 선발 집단 평균 편차 / σP (정규 절단) | — | p=50% 0.798, 20% 1.400, 10% 1.755, 5% 2.063, 1% 2.665 |
| 세대 간격 L | 부모 세대 평균 나이 또는 사이클 길이 | 년 | 벼 전통 4~5, 속성세대진전 1~1.5, GS 사이클 1~2, 젖소 전통 5~6 → GS 2.5 |

## 3. 유전체 선발(GS) 지표

| 지표 | 정의 | 범위 |
| --- | --- | --- |
| GEBV(유전체 추정 육종가) | 마커 효과 합 또는 GBLUP 예측값. 집단 평균 0 기준 편차로 표현 | 대략 ±3σA |
| 예측 정확도 r | corr(GEBV, TBV) ≈ corr(GEBV, y)/√h² | 0.3~0.7(작물), 0.5~0.8(젖소) |
| 예측 능력(predictive ability) | corr(GEBV, y) | 정확도 × √h² |
| 신뢰도(reliability) | r² | 0.1~0.6 |
| 훈련 집단 크기 | 표현형+유전형 모두 있는 개체 수 | 300~5,000 |
| 교차 검증 | k-fold(보통 5-fold) 반복 평균 ± SD | SD 0.02~0.06 |
| 모델 비교 | GBLUP, BayesB, rrBLUP, RKHS 등 | 모델 간 차이 0.01~0.05가 현실적 |

## 5. GWAS·QTL 지표

| 지표 | 정의 | 기준·범위 |
| --- | --- | --- |
| −log10(p) | 연관 검정 p값의 음의 상용로그 | 귀무 SNP 0~3, 피크 8~30 |
| 전장 유전체 유의 수준 | 본페로니 0.05/M 또는 관례 5×10⁻⁸ | 5e-8 → −log10 = 7.30, 0.05/50,000 → 6.0 |
| 제안적 유의 수준 | 1×10⁻⁵ | −log10 = 5 |
| 유전체 팽창 계수 λGC | 관측 χ² 중앙값 / 0.455 | 0.95~1.10 정상, >1.1 구조 미보정 의심 |
| 효과 크기 β, PVE | 대립유전자 효과, 설명 분산 비율 | PVE 주효 QTL 5~25%, 소효 1~3% |
| LD r² | 두 마커의 연관불균형 | 0~1 |
| LD 감소 거리 | r²가 0.2(또는 최대의 절반)로 떨어지는 거리 | 벼 100~200kb(자식), 옥수수 1~10kb, 젖소 50~100kb |
| QTL 구간 | 피크 ± LD 블록 | 수십 kb~수 Mb |
