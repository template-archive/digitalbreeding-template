# 가상 육종 프로그램 기준값

모든 템플릿은 하나의 가상 프로그램(벼, 중부 평야지, 시드 20261023, 기준일 2026-10-23)을 서로 다른 화면으로 보여 준다. 그래서 같은 사실은 어느 템플릿에서나 같은 숫자여야 한다. 사용자는 템플릿을 나란히 놓고 보며, 숫자가 하나만 어긋나도 라이브러리 전체를 목업 티 나는 것으로 여긴다.

**사용 규칙**
- 명세 모드: 브리프가 다루는 사실이 아래 표에 있으면 그 값을 그대로 쓰고, 명세 「가정」 절에 "program-baseline 준수"라고 적는다. 다른 값을 써야 하면 이유를 적는다(예: 다른 연도, 다른 집단).
- 동기화 모드: 새 템플릿이 다른 템플릿과 공유될 만한 새 사실(계통·품종·연도별 값)을 만들었으면 이 표에 한 줄 추가한다.
- 표와 템플릿 코드가 다르면 코드가 실제 화면이다. 코드를 확인하고 이 표를 고친다.
