# 지표·분석 결과별 시각화 가이드

육종 분야에는 사용자가 이미 익숙한 표준 차트가 있다. 표준을 따르면 학습 비용이 없고, 표준에서 벗어나면 전문가가 오히려 혼란스러워한다. "필수 주석"이 빠지면 차트의 의미가 사라지므로 반드시 넣는다.

| 분석·지표 | 표준 차트 | 필수 주석·규칙 | 피할 것 |
| --- | --- | --- | --- |
| GWAS 결과 | 맨해튼 플롯(x: 염색체 누적 위치, y: −log10 p) | 전장 유전체 유의선(7.3 또는 본페로니), 제안선(5), 염색체 교대 2색, 피크 SNP 라벨·후보 유전자 | 염색체별로 12색 무지개 |
| GWAS 보정 확인 | QQ 플롯(기대 vs 관측 −log10 p) | y=x 대각선, 95% 신뢰 띠, λGC 값 표기 | 맨해튼 없이 단독 사용 |
| LD 구조 | LD 히트맵(삼각형, r²), LD 감소 곡선(거리 vs r²) | r² 0~1 연속 색 척도, 감소 곡선에 r²=0.2 기준선과 교차 거리 | 발산형(diverging) 색 척도 |
| 집단 구조 | PCA 산점도(PC1 vs PC2), ADMIXTURE 누적 막대 | 축 제목에 설명 분산 %(예: PC1 18.2%), 하위 집단 색 구분 | 3D 산점도 |
| 유전적 관계 | GRM·근연 계수 히트맵(계층 군집 순서) | 대각 원소 강조 또는 마스킹, 군집 덴드로그램 | 무작위 순서 정렬 |
| 계통·혈통 | 계통도(pedigree, 세대별 레이어, 부·모 두 부모 연결) | 성별/모부본 구분 기호, 근연 루프 강조, 선택 개체 하이라이트 | 단일 부모 트리로 단순화 |
| GEBV·선발 | 분포(히스토그램·밀도) + 선발 기준선, 순위 표 | 선발 비율·기준 GEBV 표시, 정확도(신뢰도) 열, 형질별 정렬 | 정확도 없이 GEBV만 표시 |
| 다형질 선발 지수 | 레이더 대신 막대(형질별 표준화 GEBV), 산점도(두 형질 GEBV + 지수 등고선) | 경제적 가중치 표기 | 레이더 차트에 형질 8개 이상 |
| 유전적 추세 | 연도별 평균 GEBV 선 + 회귀선 | 기울기(ΔG/년) 라벨, 표현형 추세와 구분 | 0을 기준선으로 쓰지 않는 막대 |
| 예측 정확도 | 모델·형질별 막대 + 오차 막대(교차 검증 SD) | 오차 막대 필수, y축 0~1 | 소수점 4자리 표기 |
| 파이프라인 진척 | 깔때기 또는 단계별 가로 막대(로그 축 고려) | 단계별 통과율 % | 3D 깔때기 |
| 분석실 처리량 | 시계열 막대/선 + 목표선, 콜레이트 분포 | QC 기준선(95%), 실패 샘플 수 | 파이 차트로 시계열 표현 |
| 시험포장 | 포장 배치 격자 히트맵(행×열) | 반복·블록 경계선, 대조 품종 표시, 결측 구 | 실제 배치와 다른 정렬 |
| 형질 상관 | 상관 행렬 히트맵(발산형 −1~1, 0이 중간색) | 셀에 계수 숫자, 유의성 표시 | 순차형 색 척도 |
| 교배 조합 설계 | 부모 × 부모 행렬(예측 자손 평균·분산, 근교도) | 근교도 경고 셀, 추천 조합 강조 | — |
| 마커·하플로타입 | 개체 × 마커 행렬(대립유전자 색), 염색체 트랙 | 참조/대체 대립유전자 범례, QTL 구간 | — |
| GxE 분산 분해 | 100% 가로 누적 막대(G · E · GxE) + 분산분석 표 | 반올림 합이 100이 아니면 각주, F의 분모(오차 대비 / 임의 환경 가정) 명시 | 파이 차트 |
| GGE 바이플롯(which-won-where) | 산점(유전자형 점 + 지역 벡터) + 볼록 다각형 + 수선 | 축 제목에 PC1·PC2 설명 %, **x·y 같은 축척(1:1)**, 원점에서 다각형 변에 내린 수선(구역 경계), 꼭짓점 유전자형 라벨, 메가 환경 구역 표시, "2차원 근사 — 실측 1위와 다를 수 있음" 각주와 메가 환경 근거(지역·연도 실측 1위 횟수), 지역 라벨이 서로·마커와 겹치지 않게 배치 | 축척이 다른 축(각도·구역이 왜곡됨), 라벨 없는 꼭짓점 |
| 평균–안정성 | 산점(x = 평균, y = W% 또는 ASV) | 세로 기준선 전체 평균, 가로 기준선 W 평균(= 100 / 유전자형 수) 또는 ASV 평균, y축 이름에 "↑ 불안정", "고수량·안정" 사분면 라벨 | y축 방향을 숨김 |
| 반응 규준 | 선(x = 환경 지수, y = 형질) + 실측점 | 기울기 1 기준선(y = ȳ.. + I), 범례에 b 값 | 환경을 지역명 순서로 늘어놓은 꺾은선 |
| 시험지 기상–환경 지수 | 요인별 r 가로 발산 막대 + 선택 요인 산점·회귀선 | 0 기준선, 유의 임계 ±\|r\|(n 표기), 연도를 색 외 모양으로 구분, "상관 ≠ 인과" 각주 | 유의성 없이 r만 표시 |
| 일별 기온(재배기) | 최고·최저 띠 + 평균선 | 기준선(고온 33·35 °C, 저온 17 °C, `hMarkLine`), 출수 ±15일 음영, 이앙·출수·수확 세로선, 기준선 라벨이 선·띠에 가리지 않게 | 평년선 없는 실측만 |
| 종자 재고 | 로트 표(재고·립 환산·발아 판정·재검사 기한 배지) + 요청 점검 목록 | 정조 기준 표기, 재고 막대가 무엇 대비인지(로트/계통 최소 보유량) 범례, 차단·경고를 색 + 문구로 구분 | 음수 재고 예상값 표시 |
| 종자 증식 단계 | 단계 × 연도 타임라인(기본식물 → 원원종 → 원종 → 보급종 → 농가) | 단계별 1작기, 계획/실적 구분(빗금), 빈 칸의 이유 각주 | 단계 순서 생략 |

(2026-10-27 정리 회차 3: GxE 분산 분해·GGE 바이플롯·평균–안정성·반응 규준·시험지 기상·일별 기온·종자 재고·종자 증식 단계 행 추가. 기준 구현은 met-gxe-stability, trial-site-environment, seed-inventory, variety-adoption)

## KPI 카드 규칙

- 값 + 단위 + 기준 기간 + 전기 대비 변화(▲▼, 색과 기호를 함께 — 색약 사용자 고려) + 목표 대비.
- 육종 지표는 "높을수록 좋음"이 아닌 경우가 있다: 세대 간격·개발 기간·근교계수·TAT·비용은 낮을수록 좋다. 증감 색을 지표 방향에 맞춘다.
- 스파크라인은 같은 카드 묶음에서 같은 기간을 쓴다.

## 대용량 렌더링

- SNP 2만 개 이상 산점도는 ECharts `large: true` 또는 `sampling`을 쓴다. SVG로 그리지 않는다.
- 히트맵 500×500 이상은 캔버스 렌더러를 쓴다.
