# 승격 보류 목록

승격 단계(오케스트레이터 4단계)에서 보류한 공통 모듈 후보와, 다시 검토할 조건이다. design-system-architect가 승격 작업 때마다 갱신한다. 빌더는 비슷한 로컬 컴포넌트를 만들기 전에 이 표를 확인한다(template-authoring 「로컬 컴포넌트를 만들 때」).

보류 이유는 세 가지다.
- **사용처 1곳**: 두 번째 사용처가 생기면 다시 검토한다.
- **화면 차이**: 같은 역할인데 템플릿마다 크기·간격·구성이 달라 합치면 한쪽 화면이 바뀐다. 처음 만든 빌더가 기존 구현을 보지 않고 새로 만든 결과다. 그래서 새 사용처는 기존 구현의 시각 규격을 그대로 따른다.
- **알고리즘 차이**: 계산 규칙(동률 처리, 보간식)이 달라 합치면 숫자나 색이 바뀐다.

2026-10-30 디자인 개선 1차(A단계)에서 신설·공개해 이 표에서 뺀 것: 결론 띠(17곳 개별 구현) → `SummaryCallout`, 페이지 머리 → `PageHeader`, KPI 격자 → `KpiRow`, 표가 아닌 가로 스크롤 안내 → `ScrollRegion`, 심각도 태그 → `SeverityTag`, 데이터 위 선택 표시 → `selectionStroke`(@/charts)·`select-ring`. 기존 로컬 구현은 B단계 빌더가 옮긴다(`_workspace/08_architect_design_fix.md`).

2026-10-30 C단계(B단계 공통 요청)에서 뺀 것: Legend 견본 모양 → `Legend` `shape`(`circle`·`ring`·`diamond`·`triangle`·`hatch`·`missing`), 산점 선택 고리(후광 시리즈 + 글자색 고리, gebv-selection·gwas-manhattan·trial-site-environment 3곳) → `selectionSymbolSeries`(@/charts, 세 곳 모두 옮김).
