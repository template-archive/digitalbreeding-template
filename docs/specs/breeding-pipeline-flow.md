## 가정

- 작물: 벼(*Oryza sativa*), 중부 평야지 가상 프로그램. **program-baseline 준수**(파이프라인 2026, 연도별 PIPELINE, GS 도입 2022, 별하랑, 2026 MET 결과·출원 후보, 출원 예정 YR19-0118).
- 사용자: 연구 관리자·육종 책임자. 사용 시나리오: 연말 진급 심의 전 "올해 각 단계에 몇 계통이 있고, 한 코호트가 몇 년에 걸쳐 어디까지 갔으며, 어디서 왜 빠졌는가"를 본다.
- **코호트 = GS 1차(계통 선발) 연도 G.** 브리프의 "교배 연도 또는 GS 1차 연도" 중 GS 1차 연도를 쓴다. GS 1차 이후로는 모든 계통이 같은 연차로 움직이지만, 교배 연도는 세대 진전 속도(관행 연 2세대, 속성세대진전 연 3.85세대)에 따라 GS 1차 연도가 갈라지기 때문이다. 교배 연도는 계통명 접두(YR19- = 2019 교배)와 이름이 있는 계통 목록에서 보인다.
- **추적 가능한 코호트는 GS 코호트 2022~2026의 5개.** 2021 이전(표현형 계통 선발) 코호트는 MET가 3년제에서 2년제로 바뀌는 과도기에 한 해 두 세트가 겹쳐 계통 흐름을 하나로 이을 수 없다. GS 도입 전 구조는 2019 연간 단계 현황(횡단)으로만 비교한다(program-overview·conventional-vs-digital과 같은 값).
- **디지털 공정 연차**(variety-profile 별하랑 일정과 같음): GS 1차·PYT = G년, AYT = G+1년, MET = G+2~G+3년(2년, 8개 지역), 출원 후보 선정 = G+3년 말, 출원 = G+4년. 별하랑: GS 2022 → PYT 2022 → AYT 2023 → MET 2024~2025 → 2025 동계 선정 → 2026-06-09 출원.
- **연간 단계 현황의 MET 수 = 그해 끝나는 2년 MET 세트의 계통 수.** program-overview `PIPELINE[Y][4]`가 이 값이다. 2026 MET 18 = met-gxe-stability의 2025~2026 시험 18계통, 2025 MET 21 = 별하랑이 들어 있던 2024~2025 세트. 그래서 코호트 G의 MET 수 = `PIPELINE[G+3][4]`, 출원 후보 수 = `PIPELINE[G+3][5]`, AYT 수 = `PIPELINE[G+1][3]`이다.
- 이 템플릿이 새로 정한 사실(추정): 2024 코호트 MET 1년차(2026~2027) 20계통, 각 전환의 탈락 사유 배분, 2022 코호트의 다른 출원 후보 YR18-0742·YR19-0611과 선정 제외 사유(품질(밥맛)·도열병(MET 발병)). 품종명·계통명은 모두 가상이다.
- 횡단 통과율과 코호트 진급률은 다르다. 횡단(같은 해 단계 수의 비, program-overview `passRates`)은 2026 AYT→MET 45.0%(18/40)이고, 코호트 진급률은 2023 코호트 AYT 2024 38 → MET 18 = 47.4%다. 화면은 두 값을 이름으로 구분한다("통과율(같은 해 단계 수 비)" / "진급률(코호트)").

## 화면 목적과 핵심 질문

1. 2026년 각 단계에 몇 계통이 있고 목표 대비 어디가 모자란가? → 2,000 → 600 → 120 → 40 → 18 → 3, MET 18/25(72.0%) 미달.
2. 선택한 코호트는 몇 년 동안 어느 단계까지 갔고, 단계마다 몇 계통이 왜 빠졌나? → 2022 코호트: 1,800 → 480 → 100 → 36 → 21 → 3 → 출원 1(별하랑, GS 1차 후 4년·교배 후 7년). 가장 많이 빠진 사유는 수량 미달.
3. GS 도입 전후 진급 구조가 어떻게 달라졌나? → 계통 선발에서 더 많이 남기고(20.0 → 30.0%) PYT 편성에서 더 강하게 거른다(30.0 → 20.0%). 후보 대비 출원 후보 0.133% → 0.150%, 시험 계통(PYT+AYT+MET) 135 → 178.

const REASONS = ['yield', 'blast', 'heading', 'quality', 'lodging', 'stability', 'other'] as const
const BASE = {
  T1: { yield: .56, blast: .12, heading: .14, quality: .12, lodging: .06, stability: 0, other: 0 },   // GEBV 근거

  T3: { yield: .46, blast: .16, heading: .12, quality: .12, lodging: .09, stability: 0, other: .05 }, // PYT 포장
  T4: { yield: .44, blast: .14, heading: .08, quality: .22, lodging: .08, stability: 0, other: .04 }, // AYT 포장
}
const rng = createRng(20261023)
for (const G of COHORTS) {                    // 2022 → 2026 순서
  const c = cohortCounts(G)
  const nDone = { 2022: 4, 2023: 4, 2024: 4, 2025: 3, 2026: 2 }[G]  // T1~T4 중 끝난 수
  for (let t = 1; t <= nDone; t++) {
    const D = c[t - 1] - c[t]
    const w = {}
    for (const r of REASONS) { const b = BASE['T' + t][r]; if (b > 0) w[r] = b * Math.exp(0.2 * rng.normal()) } // b = 0이면 난수를 뽑지 않음
    drops[G]['T' + t] = hamilton(D, w)
  }
}
// hamilton(total, w): q_r = total·w_r/Σw, floor 후 남은 수를 나머지 큰 순(같으면 REASONS 순서)으로 1씩
