## 가정

- 작물: 벼(*Oryza sativa*, 12개 염색체, 약 430 Mb, 자식성). 개량 대상 형질은 **쌀 수량(kg/10a, 백미 기준)**이다. ΔG·r·σA는 모두 쌀 수량 기준이다. "정조 수량"이라고 쓰지 않는다.
- 프로그램: 다른 템플릿과 같은 가상 "중부 평야지 벼 육종 프로그램". 2019~2021년은 표현형 선발(전통 육종), 2022년부터 유전체 선발(GS)과 속성세대진전을 도입했다.
- **비교 기준 시점**
  - 전통 육종 = **2019년 공정**. 2019~2021년 표현형 선발기를 대표한다. 그 3년 동안 ΔG는 0.75·0.74·0.76%/년이고, 3년 평균 4.199 kg/10a/년도 2019년 값 4.200과 같은 4.20으로 반올림된다. digital-breeding-process와 genetic-gain-tracker(LMDI 2019 → 2026)의 전통 기준도 2019년이다.
  - 디지털육종 = **2026년 공정**(GS 5년차, 진행 중 연도. ΔG는 구성 요소로 계산한 예측값).
- 개발 기간 6.7년은 디지털 공정 **설계값(예상)**이다. 실제 최단 출원은 별하랑 7년(2019 교배 → 2026 출원, 도입 과도기 계통)이다(program-baseline, digital-breeding-process `SHORTEST_ACTUAL_YEARS`).
- **비용은 모두 추정이다.** 가상 프로그램의 직접비(현장·분석 소모성 경비)만 넣는다. 인건비, 시설·장비 투자(생육상·칩 스캐너) 감가상각, 교배 작업비(두 공정이 같음)는 뺀다. 원화로 표기하며 환율은 1 USD ≈ 1,390원(추정, 칩 단가 환산에만 씀)으로 둔다. 단가 표는 「목업 데이터 생성 규칙」에 있다.
- 사용자: 정책 결정자, 예산 심의 담당자, 외부 방문객, 언론. 육종 비전공자다. 브리핑 슬라이드, 정책 보고서 부록, 인쇄 배포물에 넣는다.
- 사용 시나리오: 정적인 한 장 인포그래픽이다. 필터나 데이터 갱신이 없다. 화면 캡처나 A4 가로 인쇄로 쓴다.
- digital-breeding-process와 역할을 나눈다. 저쪽은 **단계 흐름**(7단계 카드, 기간 타임라인)을 보여 주고, 이 화면은 **지표별 좌우 대비**와 **왜 빨라지는가(ΔG 방정식 구성 요소의 기여)**를 보여 준다. 단계 카드, 단계별 누적 기간 막대, 흐름 화살표는 이 화면에 넣지 않는다.
- 품종명·기관명은 모두 가상이다.

## 화면 목적과 핵심 질문

1. 디지털육종으로 바꾸면 무엇이 얼마나 달라지는가? → 해마다 쌀 수량 유전 개량이 **4.20 → 12.82 kg/10a/년(0.75 → 2.29%/년, 3.1배(예측) · 실현 2.6배)**, 품종 개발 기간은 **11.0 → 6.7년(설계값, −4.3년)**
2. 왜 빨라지는가? → ΔG 증가분 8.62 kg/10a/년 가운데 **세대 간격(L) 단축이 65.1%(+5.61)**, 선발 정확도(r) 26.1%(+2.25), 선발 강도(i) 14.9%(+1.28). 상가적 유전 표준편차(σA)가 줄어 −6.0%(−0.52)
3. 돈은 얼마나 더 드는가? → 연간 직접비 **1.30억 → 1.88억 원(1.45배, 추정)**. 그러나 개량 1 kg/10a에 드는 연간 직접비는 **3,096만 → 1,466만 원(−52.6%)**

export const dG = (yr: Year) => I[yr] * R[yr] * SIGMA_A[yr] / L[yr]          // 2019 4.2000, 2026 12.8227
export const dGpct = (yr: Year) => dG(yr) / MU * 100                         // 0.7500, 2.2898

export function lmdi(yr): Record<'i'|'r'|'sigmaA'|'L', number> {
  const p = yr - 1, g0 = dG(p), g1 = dG(yr)

}

## 상호작용

- 정적 인포그래픽이다. 필터·드릴다운·툴팁이 없다(인쇄물과 화면이 같아야 한다).
- 캔버스: 공통 `ScaledCanvas`(`width={1920}`, `height={1080}`, `print="a4-landscape"`). 모든 크기는 `u(n)`. 1440px 미리보기에서 잘림·가로 스크롤이 없어야 한다.
- 캔버스가 최소 배율에 걸려 잘리는 폭(390·768, 2026-10-30부터 768 포함)에서 `ScaledCanvas summary`로 캔버스 위에 **모바일 요약**(`data-print-hide`)을 둔다. 2열 카드 4개: "연간 유전적 개량량 4.20 → 12.82 kg/10a/년(3.1배(예측))", "품종 개발 기간 11.0 → 6.7년(설계값)", "세대 간격 4.5 → 2.2년(2.3년 단축)", "개량 1 kg/10a당 직접비 3,096만 → 1,466만 원(추정 · 예측 기준)". 그 아래 한 줄 "개량량 증가분의 65.1%는 세대 간격 단축 덕분입니다". 글자 14px 이상, 큰 숫자 22px 이상. 캔버스 본체는 `minScale` 기본 0.6과 가로 스크롤로 보여 준다(재배치하지 않음).
- 인쇄: A4 가로 한 쪽. 인쇄 버튼(`Button`, `data-print-hide`)으로 `window.print()`. 앱 크롬은 공통 인쇄 계약(`data-print-hide`·`data-print-flat`·`data-print-canvas`)으로 숨긴다. 템플릿 안에 `@media print`를 직접 쓰지 않는다.
- 흑백 인쇄 대비: 전통/디지털 구분은 좌우 위치와 "전통"/"디지털" 문자 라벨로, 전통 막대는 옅은 회색 또는 빗금. σA 음수 기여는 빗금 + "감소" 글자.

## ΔG 배율 표기(2026-10-26 정리 회차 2, 사용자 결정)

- **표기 규칙(사용자 결정 2026-10-26)**: 헤드라인 ΔG 배율은 구성 요소(i · r · σA / L)로 계산한 **예측** 배율이므로 실현 배율과 병기한다.
  - 표준 문구: **"3.1배(예측) · 실현 2.6배"** — 문장·해설·각주·`ariaLabel`처럼 공간이 있는 곳.
  - 좁은 곳(배지, KPI 보조 줄, 큰 숫자, 모바일 요약 카드): **"3.1배(예측)"**만. 이때 같은 화면의 다른 위치(문장·각주)에 표준 문구나 실현 배율 설명이 있어야 한다.
  - 두 숫자는 상수에서 만든다: `${f1(GAIN_RATIO)}배(예측)`, `실현 ${f1(REALIZED_RATIO)}배`. 하드코딩 금지.
