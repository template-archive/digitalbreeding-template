# 교배 조합 설계 — 명세

- slug: `cross-planner` · category: `workflow` · 기준일: 2026-10-23
- 지표 기준: `.claude/skills/breeding-metrics/references/metrics-catalog.md` (모든 값은 카탈로그 범위 안의 가상 목업)
- 연결 템플릿: `program-overview`와 같은 프로그램·형질 기준(σA = 28.2 kg/10a, 2026년 수량)을 쓴다.

## 가정

- 작물: 벼(*Oryza sativa*, 12개 염색체, 약 430 Mb, **자식성**). 부모 후보는 모두 고정된 근교계(F ≈ 1)다.
- 주 형질: **쌀 수량 GEBV(kg/10a, 백미 기준)**. "정조 수량"으로 쓰지 않는다(program-baseline, 2026-10-23 사용자 결정). 보조 형질: 출수기(파종 후 일수), 간장(cm), 도열병 저항성 유전자(Pi) 보유.
- 사용자: 육종가. 다음 교배 시즌(2027년 1차 교배, 온실)에 쓸 교배 조합(Cross)을 고른다.
- 시나리오: 후보 60계통에서 부모 8~12개를 고르고 → 부모×부모 행렬에서 예측 자손 성적과 근연 정도(자손 분산 축소)를 비교해 조합을 담고 → 경보·주의를 확인한 뒤 확정한다.
- 자손은 계통 육성(RIL, F6 이상 고정계)을 전제로 한다. 정역교배 차이(세포질 효과)는 예측에 넣지 않는다. 모본(♀)·부본(♂)은 확정 단계에서 지정만 한다.
- 이번 회차 상한: 부모 12계통(66조합), 선택 조합 30건. 프로그램 전체 교배 수(카탈로그 200~2,000건/년)의 일부를 계획하는 화면이다.
- **근연 표기**: 자식성 벼에서 RIL(F6 이상)을 육성할 때 부모가 가까우면 생기는 문제는 근교 약세가 아니라 자손의 분리 분산 축소다. 그래서 등급 이름은 "근교 경고/주의"가 아니라 "강한 근연"(f ≥ 0.375)·"근연 주의"(0.25 ≤ f < 0.375)로 쓰고 "자손 분산이 작음"을 보조 설명으로 붙인다(program-baseline, 2026-10-23 사용자 결정).
- 계통명은 모두 가상이다(`YR22-0412` 형식). 실존 계통·품종과 관계없다는 문구를 화면 하단에 넣는다.
- 유전자 이름(Pi-ta, Pib, Pi9, Pigm)은 실제 도열병 저항성 유전자 이름이지만, 계통별 보유 여부는 가상이다.

## 화면 목적과 핵심 질문

1. 어떤 부모 조합이 선발 후 자손 성적(유용성 기준 UC)이 가장 높은가? — 평균만 높은 형제 계통끼리의 조합이 아니라 분산까지 고려한 순위.
2. 고른 조합 중 부모가 너무 가까운(근연, 자손 분산 축소) 조합, 개화기가 맞지 않는 조합, 한 부모에 쏠린 계획은 없는가?
3. 확정할 조합은 몇 건이고, 사용 부모 수·평균 공조계수(f)는 얼마인가?

## 목업 데이터 생성 규칙

- 시드: **20261023** (`createRng(20261023)` from `@/lib/rng`, `lineName` from `@/lib/genomics`)
- 앵커 8계통과 앵커 간 f는 위 표의 **상수**. 나머지 52계통과 그 관계 계수만 난수로 만든다. μ·σ·UC·등급·추천·요약은 모두 **계산**하고 하드코딩하지 않는다.
- 후보 60계통 = A 30(앵커 4 + 생성 26), B 20(앵커 2 + 생성 18), C 10(앵커 2 + 생성 8).

```ts

const I_BY_P = { '10': 1.755, '5': 2.063, '1': 2.665 }
const KIN_WARN = 0.375, KIN_CAUTION = 0.25, HEADING_GAP = 10, PARENT_MAX_USE = 3
const MAX_PARENTS = 12, MAX_CROSSES = 30

// 가계 구성(앵커 포함)
// A: F01..F10 각 3계통 (F01 = 앵커1, 앵커2 + 생성1 / F05 = 앵커3 + 생성2 / F09 = 앵커4 + 생성2 / 나머지 7가계 생성3)
// B: F11..F17 (F12 = 앵커5, 앵커6 + 생성1 / 나머지 6가계 생성 3,3,3,3,3,2)

const rng = createRng(20261023)
const famEffect = Object.fromEntries(FAMILIES.map(f => [f, rng.normal(0, 7)]))  // 가계 순서 F01..F27
const GROUP = {
  A: { mean: 22, gebv: [-15, 44.0], heading: [118, 3, 110, 126], culm: [84, 5, 72, 96], pi: [['Pi-ta', .3], ['Pib', .2], ['없음', .5]] },
  B: { mean: 10, gebv: [-15, 44.0], heading: [108, 3, 101, 115], culm: [78, 4, 68, 88], pi: [['Pib', .3], ['없음', .7]] },
  C: { mean: -8, gebv: [-25, 8.0], heading: [116, 7, 100, 130], culm: [92, 8, 75, 110], pi: [['Pi9', .35], ['Pigm', .35], ['Pi-ta', .15], ['Pib', .15]] },
}
// 생성 계통(가계 순서대로)
for (const fam of generatedSlots) {

  const id = uniqueLineName(rng, 'YR', rng.int(2019, 2023))   // 앵커·기존 이름과 겹치면 다시 뽑는다

  rel  = round2(0.30 + 0.30 * rng.beta(4, 4))                  // 0.30~0.60

}
// 생성 계통 GEBV 상한 44.0 → 앵커 1~4가 전체 상위 4위가 된다

// 공조계수(앵커-앵커 쌍은 상수표 사용). 쌍 순서: 후보 배열 인덱스 i<j 이중 루프 (2026-10-26 정리 회차 개정)
const round2 = v => Math.round(v * 100) / 100 || 0     // −0 정규화(음수 f 반올림 시 −0 → "-0.00" 방지)
function kinship(P, Q) {
  if (P.family === Q.family)        return round2(clamp(0.50 + rng.normal(0, 0.07), 0.38, 0.66))   // 이전 N(0,0.03), 0.42~0.58
  if (isHalfSib(P.family, Q.family)) return round2(clamp(0.28 + rng.normal(0, 0.04), 0.15, 0.36))   // 정리 회차 2(이전 0.27 + N(0, 0.025), 0.20~0.34)
  if (P.group === Q.group)          return P.group === 'C'
                                      ? round2(clamp(0.05 + rng.normal(0, 0.015), 0.01, 0.09))
                                      : round2(clamp(0.1092 + rng.normal(0, 0.03), 0.04, 0.19))   // 정리 회차 2(이전 0.11)

  return round2(clamp(-0.018 + rng.normal(0, 0.012), -0.06, 0.03))                                    // 이전 0.03 + N(0,0.01), 0~0.06
}

// 조합 예측(난수 없음)
const mu    = (P, Q) => (P.gebv + Q.gebv) / 2
const k     = (P, Q) => 0.85 + 0.25 * Math.min(1, Math.abs(P.gebv - Q.gebv) / 50)
const sigma = (P, Q) => SIGMA_A * Math.sqrt(1 - f(P, Q)) * k(P, Q)

const kinLevel = f => f >= KIN_WARN ? 'warn' : f >= KIN_CAUTION ? 'caution' : 'ok'
const headingGap = (P, Q) => Math.abs(P.heading - Q.heading)

// 추천: 선택 부모의 모든 쌍 중 f < 0.25, UC 내림차순 상위 5
// 확정 ID: 확정 시점에 UC 내림차순으로 CR27-001, CR27-002 ...
```

- 통계 점검: 모든 f ∈ [−0.06, 0.66](실행값 −0.05~0.64, 음수 420쌍, −0 없음), 신뢰도 ∈ [0.30, 0.61](실행값 0.34~0.61), σ_PQ > 0, UC > μ_PQ. 같은 가계 쌍은 모두 f ≥ 0.38여서 강한 근연이 된다(f 0.38 쌍 2개: YR22-0415 × YR23-6127, YR21-5004 × YR19-6821).

## 상호작용

- **① 선택**: 행 체크박스로 선택·해제(Space/Enter). 12계통 초과 선택 시 체크박스 비활성 + 안내 "부모는 최대 12계통까지 선택할 수 있습니다". 부모를 해제하면 그 부모가 들어간 선택 조합도 함께 해제하고 안내 문구 "선택 조합 n건이 함께 해제되었습니다"를 보인다. "다음: 조합 검토"는 부모 2계통 이상일 때만 활성.
- **필터**: 즉시 적용. 필터는 표시만 바꾸며 선택 상태는 유지한다. 결과 0건이면 `EmptyState` "조건에 맞는 후보가 없습니다" + "필터 초기화".
- **② 행렬**: 셀 클릭/Enter는 셀을 포커스해 상세 패널(G)에 보이기만 한다. 담기·빼기는 상세 패널의 "조합 담기/빼기" 버튼(모바일 목록 보기에서는 카드의 버튼)으로만 한다. 30건 초과 담기 불가 안내. "추천 조합 모두 담기"는 아직 담지 않은 추천 조합만 추가. 셀 툴팁(또는 `aria-label`): "YR22-0412 × YR23-0136, UC 97.5, μ 49.0, σ 23.5, f 0.11, 정상". 행렬 행·열은 GEBV 내림차순, 초기 모본은 행 부모(GEBV가 높은 쪽). p를 바꾸면 UC·추천·셀 색이 즉시 갱신된다.
- **③ 확정**: 모본·부본 바꾸기(초기값: 행 부모 = 모본), 빼기. 선택 조합 0건이면 `EmptyState` "담은 조합이 없습니다" + "조합 검토로 돌아가기", 확정 버튼 비활성. 강한 근연 조합이 있으면 확인 체크박스를 체크해야 확정 가능.

## 수용 기준

- [ ] 기본 필터(GEBV 최소 −25)에서 후보 표에 60계통이 모두 보이고("60계통 중 60계통 표시") GEBV 내림차순 기본 정렬에서 상위 4계통이 YR22-0412(+52.4), YR22-0415(+49.8), YR21-0877(+47.1), YR23-0136(+45.6)이며, 모든 열 머리글로 정렬할 수 있다.
- [ ] GEBV 최소·신뢰도 최소·출수기 범위·간장 최대·그룹 필터가 표시 행 수를 바꾸고 "60계통 중 N계통 표시" 문구가 표의 행 수와 일치하며, 필터로 숨겨진 선택 부모는 칩으로 남아 선택이 유지된다.
- [ ] 행렬은 선택 부모 n개에 대해 상삼각 n(n−1)/2개 셀만 값을 가지며(초기 8계통 → 28셀), 대각은 "—"이다.
- [ ] 모든 셀에서 μ = (GEBV_P + GEBV_Q)/2, σ = 28.2·√(1−f)·k, UC = μ + i·σ가 성립하고, 셀 상세 패널의 식(예: 1×4 "UC = 49.0 + 2.063 × 23.5 = 97.5")이 셀 값과 같다.
- [ ] 초기 상태(p = 5%)에서 UC 최고 셀은 YR22-0412 × YR23-0136(97.5)이고, μ가 가장 높은 YR22-0412 × YR22-0415(μ 51.1)는 UC 85.9로 그보다 낮으며 강한 근연 셀로 표시된다.
