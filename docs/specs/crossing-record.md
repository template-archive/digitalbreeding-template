## 가정

- **program-baseline 준수.** 벼(*Oryza sativa*, 12개 염색체, 약 430 Mb, **자식성**), 중부 평야지 가상 육종 프로그램.
- 사용자: 육종 연구원(조합 관리, F1 진위 판정)과 현장 기술원(교배 야장 입력). 교배·수확이 끝난 뒤 야장 값을 전산에 옮기고, F1 진위 결과를 확인하고, 다음 회차에 다시 교배할 조합을 고른다.
- **회차: 2026년 2차 교배(하계, 교배 망실 포장)**, GS 부모 재순환 조합 **24건**, 조합 ID **CR26-301~CR26-324**.
  - 조합 ID는 cross-planner와 같은 `CR{연도 2자리}-{3자리}` 체계다. 회차마다 번호 블록을 나눈다(1차 001~, 2차 301~, **추정**). 2027년 1차 교배 계획이 CR27-001부터 시작하는 것(program-baseline)과 맞는다.
  - 기준일까지 끝난 일: 교배 2026-08-01~08-18 → F1 종자 조기 수확(교배 후 28일) 08-29~09-15 → 1차 묶음 F1 진위 결과 09-30. 2차 묶음 F1은 온실에서 키우는 중이라 진위 확인이 **대기**다.
- 교배 방법: 온탕 제웅(43 °C 7분, **추정**) 후 상부 영화를 잘라 내고 인공 수분한 뒤 봉지를 씌운다. 정상 조합의 결실률 평균 28%, 정상 범위 12~50%, 정상 제웅의 잔여 자식률 2%는 모두 **추정**이다. 제웅·영화 절단·봉지 관리가 잘 된 프로그램을 가정한 값이다.
  - 출처 1은 "제웅 방법에 따라 결실률과 진성 F1 비율이 크게 다르다"는 근거로만 쓴다(온탕 제웅 결실률 16.5%·F1 54.6%, 흡입 제웅 31.5%·F1 8.4%). 이 연구의 온탕 제웅 F1 비율(자식 약 45%)을 그대로 쓰지 않는다. 결실 과다를 자식 의심 신호로 보는 판정(> 50%)은 "결실이 많을수록 자가수분 종자가 섞였을 가능성이 크다"는 방향만 이 연구에서 가져왔다.
- 교배포 파종 2026-04-15(모본). 부본은 출수를 맞추려고 7일 간격 3회 분할 파종(04-08·04-15·04-22, **추정**)한다. 그래서 모본·부본의 출수 일수 차가 13일인 조합(CR26-302, 324)도 교배할 수 있다.
- **부모 14계통**은 모두 cross-planner 후보 60계통에 있는 계통이다. 출수 일수(파종 후 일수)·그룹·가계·도열병 저항성 유전자는 cross-planner `CANDIDATES` 실행값을 복사한다. 이 부모들은 2026 상반기 GEBV로 고른 2차 교배 부모이며, 2026 하반기 부모 후보 60계통에도 다시 들어갔다.
  - 이 화면은 GEBV를 보이지 않는다(교배 당시와 현재 GEBV가 달라 혼동된다).
  - cross-planner 기본 추천 조합(1×4, 1×5, 1×6, 1×3, 2×6)과 p = 1% 추천(1×7, 1×8)과 겹치는 앵커끼리 조합은 넣지 않았다. 모든 조합은 앵커 × 비앵커 또는 비앵커끼리다.
  - 24조합 공조계수 f(cross-planner `kinship` 실행값)는 −0.04~0.15다. 근연 조합(f ≥ 0.25)은 없으므로 근연 배지를 쓰지 않는다.
- **F1 진위 확인**: KASP 16마커 패널(genotyping-lab-ops·sample-tracking과 같은 패널) 중 **부모 간 다형 마커**로 판정한다. 조합당 F1 유묘 **4주**를 검정한다.
  - 1차 묶음(16조합, 수확 ≤ 09-07): 09-09 온실 1차 입실 파종 → 09-23 잎 채취(3엽기) → **KSP-2609-09**(접수 09-24, 결과 09-30, TAT 6일). 이 플레이트는 genotyping-lab-ops `PLATES`에 있는 실제 행이고 실패 0건이다. 그래서 이 회차 시료는 모두 QC를 통과한다. 94웰 구성: 이 회차 F1 64 + 부모 대조 14 + 다른 의뢰 16(이 화면 범위 밖).
  - 2차 묶음(8조합, 수확 09-09~09-15): 휴면 타파(50 °C 5일, **추정**) 후 10-08 온실 2차 입실 파종 → 10-26 잎 채취 예정 → **KSP-2611-01** 접수 예정 10-27, 결과 예정 11-03(TAT 목표 7일). 플레이트 ID의 MM은 결과 제공(예정) 월이다(sample-tracking 규칙). 기준일에 아직 접수 전이므로 sample-tracking 추적 범위(12장)에 없는 것이 맞다.
- 새로 정한 사실(**추정·가상**): 2차 교배 회차·조합 24건, 교배포 파종일, 조기 수확 28일, 온실 입실일, 목표 F1 종자 40립, 결실률 정상 범위, 부모 14계통의 KASP 유전형, KSP-2609-09의 플레이트 구성, KSP-2611-01 접수 예정일.
- 계통명은 모두 가상이다. 유전자 이름(Pi9, Pi-ta, Pib, Pigm, Xa21, xa5, Bph18, Wx, Hd1, sd1, GS3)은 실제 유전자 이름이지만 계통별 보유 여부는 가상이다. 하단에 고지 문구를 둔다.

### KASP 16마커와 부모 유전형(상수 `MARKERS`, `PARENT_GENO`)

마커 순서: Pi9, Pi-ta, Pib, Pigm(도열병) · Xa21, xa5(흰잎마름병) · Bph18(벼멸구) · Wx(아밀로스) · Hd1(출수) · sd1(반왜성) · GS3(입형) · ID02, ID04, ID07, ID09, ID11(품종 식별용 고다형 SNP, 번호는 염색체). genotyping-lab-ops의 패널 설명("Pi9, Pita, Pib, Xa21, xa5, Bph18, Wx 등 16개")과 맞는다. 화면 표기는 cross-planner를 따라 "Pi-ta"로 쓴다.

0 = AA, 2 = BB. 고정 근교계라 이형접합은 없다. **대립유전자 방향(2026-10-29 정리 회차 4)**: 기능 마커(유전자 이름 마커 11개)는 **BB = 효과(표적) 대립유전자 동형**이다 — 저항성 보유(Pi9·Pi-ta·Pib·Pigm·Xa21·xa5·Bph18), Wx 저아밀로스, Hd1 출수 지연형, sd1 반왜성, GS3 천립중 증가형. Hd1·sd1·GS3·Pi-ta·Pi9 다섯 칸은 haplotype-viewer 리드 SNP 표적 대립유전자 보유 판정(BREED 행 `carry`, 리드 결측 추정 0건)과 같다(14계통 × 5좌위 불일치 0). ID 마커 5개(ID02~ID11)는 품종 식별용 중립 SNP라 AA = 기준 게놈(IRGSP-1.0) 대립유전자, BB = 대체 대립유전자이며 효과 방향이 없다.

```ts
  if (LOW_SET.has(c))               s = 0.04 + 0.06 * rng.next()
  else if (INCOMPLETE_EMASC.has(c)) { s = 0.03 + 0.05 * rng.next(); selfAdd = 0.45 + 0.15 * rng.next() }
  else                              s = clamp(rng.normal(0.28, 0.06), 0.14, 0.42)
  const crossSeeds = Math.round(c.florets * s), selfSeeds = Math.round(c.florets * selfAdd)
  c.trueSeeds = Math.min(c.florets, crossSeeds + selfSeeds)
  c.seeds = UNENTERED.has(c) ? null : c.trueSeeds          // 화면 기본값
  c.pSelf = c.trueSeeds ? (selfSeeds + 0.02 * crossSeeds) / c.trueSeeds : 0   // 0.02 = 정상 제웅의 잔여 자식률(추정)
  c.harvest = addDays(c.date, EARLY_HARVEST_DAP)
  c.batch = c.harvest <= BATCH1_CUTOFF ? 1 : 2
  c.poly = MARKERS.filter((_, i) => PARENT_GENO[c.female][i] !== PARENT_GENO[c.male][i])
}
// 4) 1차 묶음 F1 개체 — ID 순서, 조합당 min(4, trueSeeds)주
for (const c of crosses) if (c.batch === 1)
  c.plants = Array.from({ length: Math.min(F1_PER_CROSS, c.trueSeeds) }, () => rng.next() < c.pSelf ? 'self' : 'F1')
// 개체 유전형(난수 없음): 다형 마커에서 'F1' → AB, 'self' → 모본 유전형. 다형이 아닌 마커는 부모 공통 유전형. 16마커 모두 호출(KSP-2609-09 실패 0)
```

## 상호작용

- **입력 검증**(입력하는 동안 바로 표시, 저장 직전 전체 재검사. 두 검사의 결과는 같다):
  - 오류(저장 차단): 결실 립수 > 교배 영화 수("결실 립수가 교배 영화 수(223)보다 많습니다"), 정수 아님·음수, 제웅 이삭 0 이하, 교배 영화 0 이하, 교배일이 회차 기간(2026-07-20~09-10) 밖.
  - 교배일은 MM-DD 텍스트로 입력한다(형식이 틀리면 오류 "MM-DD 형식의 날짜를 입력하세요").
  - 주의(저장 가능, 배지 표시): 교배일 < 모본 출수일, 또는 교배일 > 모본 출수일 + 7일(출수일 + 7일 당일은 허용, "모본 출수일 08-11 기준 범위 밖"), 이삭당 영화 수가 20~80 밖, 결실 저조(< 12%), 결실 과다(> 50%).
  - 결실률은 입력하지 않는다. 립수·영화 수를 바꾸면 즉시 다시 계산한다. 요약 줄·칩·차트도 편집 중인 값으로 바로 다시 계산하고, 오류가 있는 필드는 마지막 저장값으로 계산한다. 저장 후 수치는 아래 입력 예시와 같다.
- **F1 진위 상태 관리**: 상세 패널의 선택(대기 / 확인 / 자식 의심). 기본값은 KASP 결과에서 계산한 값이다. 사용자가 다르게 고르면 "수동 변경 · KASP 판정: 확인" 배지를 붙이고 사유(재판독 · F1 생육 특성 확인 · 기타)를 고르게 한다. 대기 조합을 확인/자식 의심으로 바꾸려 하면 "KASP 결과(11/03 예정) 전입니다"를 주의 문구로 알린다(막지는 않는다). KASP 결과가 없는 조합을 수동으로 확인하면 유효 F1 = 결실 립수다. 상태가 바뀌면 유효 F1·진행률·재교배가 다시 계산된다.
  - **KASP 결과가 있는 조합(1차 묶음)을 수동으로 '대기'로 바꾸는 경우**: "재판독 대기"로 본다. 상태 배지·진위 칩 숫자는 대기로 바뀌지만, 유효 F1과 재교배는 KASP 판정 기준 값을 그대로 쓴다. 이미 알려진 자식 개체를 무시해 진행률이 오르지 않게 하려는 규칙이다. **표시 규칙(정리 회차 3 확정)**: `Derived`에 `basis`(값의 근거 = KASP 판정 또는 수동 상태)와 `reread`(= status 'pending' 그리고 basis ≠ 'pending')를 둔다. ① 진행 차트 막대는 `basis` 종류의 색·투명도로 그리고(312 재판독 대기 → '확인' 색 55.5, 315 → '자식 의심' 0), 재판독 대기 행은 막대 테두리를 1px 점선(`theme.text`)으로 그리며 툴팁 진위 줄을 "F1 진위 대기(재판독 · KASP 판정 확인 값 유지)"로 쓴다. 막대 값 라벨 끝에 " · 재판독 대기"를 붙인다(예: "56 · 재판독 대기", "자식 의심(결실 215립) · 재판독 대기"). 유효 F1이 0이라 막대가 없는 행(315)은 점선 테두리가 보이지 않으므로 라벨이 유일한 표식이다. 범례에 "재판독 대기(KASP 판정 값 유지, 점선 테두리)" 항목은 재판독 대기 행이 있을 때만 보인다. '대기(결실 립수 그대로)' 색은 KASP 결과가 없는 대기 조합에만 쓴다. ② 요약 줄 달성 내역 `reachedBy`는 `basis`로 나눈다(312 재판독 대기여도 "확인 14 · 대기 5" 그대로). 재판독 대기가 있으면 달성 내역 뒤에 " · 재판독 대기 n"을 붙인다. ③ 진위 칩(확인·자식 의심·대기 수)은 지금처럼 `status`로 센다(사용자가 고른 상태). ④ 진행률 툴팁 정의에 "재판독 대기 조합은 KASP 판정 기준 값으로 셈"을 덧붙인다. 예: CR26-312 → 대기면 유효 F1 55.5 유지, 진행률 83.8%(804/960) 그대로, 진위 확인 14 · 자식 의심 1 · 대기 9.
