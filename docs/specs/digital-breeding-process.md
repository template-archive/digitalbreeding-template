## 가정

- 작물: 벼(*Oryza sativa*, 12개 염색체, 약 430 Mb, 자식성). 개량 대상 형질은 **쌀 수량(kg/10a, 백미 기준)** 하나다. ΔG·r·σA는 모두 수량 기준이다. "정조 수량"으로 쓰지 않는다(program-baseline, 2026-10-23 사용자 결정).
- 프로그램: program-overview와 같은 가상의 "중부 평야지 벼 육종 프로그램". 2019~2021년은 표현형 선발(전통 육종), **2022년부터 유전체 선발(GS)과 속성세대진전을 도입**했다.
- 화면이 비교하는 두 공정:
  - **전통 육종**: 2019년(GS 도입 전) 공정. 세대 간격 4.5년, 선발 정확도 0.45, ΔG 0.75%/년.
  - **디지털육종**: 2026년 현재 공정 설계값. 세대 간격 2.2년, 예측 정확도 0.57, ΔG 2.29%/년.
- 세대 간격 2.2년 근거: 카탈로그의 벼 GS 사이클 1~2년보다 약간 길다. 이 공정은 F1에서 바로 GEBV로 부모를 고르는 빠른 순환이 아니라, 속성세대진전(SSD)으로 F6 고정 계통까지 진전(1.3년)한 뒤 유전형 분석·GEBV 예측·선발(0.4년)을 거쳐 부모를 고르는 설계라서 교배~다음 교배 부모 선발이 2.2년이다. program-overview `L[2026]` = 2.2와 같다.
- 디지털 공정의 총 개발 기간 6.7년은 **현재 공정을 처음부터 끝까지 적용했을 때의 설계값(예상)**이다. 이 공정을 온전히 거친 계통은 아직 출원되지 않았다. 실제 출원 사례 중 가장 짧은 것은 program-overview의 R15 "별하랑"(2019 교배 → 2026 출원, 7년, 도입 과도기 계통)이다. 화면 각주에 이 점을 밝힌다.
- 사용자: 기관 홍보 담당자, 연구 관리자. 기관 소개 자료, 학회·성과 발표 슬라이드, 인쇄 브로슈어에 넣는다. 보는 사람은 외부 방문객, 정책 담당자, 비전공 연구자다.
- 사용 시나리오: 정적인 한 장 인포그래픽이다. 필터나 데이터 갱신 없이 화면 그대로 캡처하거나 인쇄한다.
- 캔버스: **16:9 고정 비율(기준 1920×1080 논리 픽셀)**. 인쇄는 A4 가로(297×210 mm)에 맞춘다(아래 「상호작용」 참고).
- 품종명·기관명은 모두 가상이다. 실존 품종·기관과 관계없다는 문구를 각주에 넣는다.

## 화면 목적과 핵심 질문

1. 디지털육종을 쓰면 벼 품종 하나를 만드는 데 얼마나 덜 걸리는가? → **11.0년 → 6.7년(4.3년, 39.1% 단축)**
2. 어느 단계에서 시간이 줄었고, 어떤 단계가 새로 생겼는가? → 세대 진전(속성세대진전)·선발·시험 단계가 줄었고, 유전형 분석·GEBV 예측이 새로 생겼다.
3. 단계마다 어떤 데이터가 쓰이고 얼마나 정확한가? → 2,000계통 유전형 분석, 예측 정확도 0.57, 세대 간격 2.2년, 연간 유전적 개량량 3.1배

검산:
- 전통 합 0.5 + 3.0 + 1.0 + 6.0 + 0.5 = 11.0. 디지털 합 0.5 + 1.3 + 0.1 + 0.1 + 0.2 + 4.0 + 0.5 = 6.7. 단계별 단축 합 1.7 + 0.8 + 2.0 − 0.1 − 0.1 = 4.3. 4.3 / 11.0 = 39.09% → 39.1%.
- 세대 간격: 전통 ①+②+⑤ = 0.5 + 3.0 + 1.0 = 4.5, 디지털 ①~⑤ = 0.5 + 1.3 + 0.1 + 0.1 + 0.2 = 2.2. program-overview L과 일치.
- ③④가 늘린 0.2년은 "신규 단계 +0.2년"으로 표시하고, 단축 합계에서 빼야 4.3이 맞는다. ③④를 0년으로 표시하지 않는다(실제로 시간이 든다).
- 교배+세대 진전: 디지털 1.8년. IRRI가 밝힌 속성세대진전 적용 시 1.5~2년 범위 안이다.
- 부동소수점 합계는 반드시 소수 1자리로 반올림해 표시한다(0.1+0.2 오차 방지). 단축률은 반올림 전 값으로 계산한다.

## 목업 데이터 생성 규칙

- 시드: **20261023**. 이 템플릿은 난수를 쓰지 않는다. 모든 값은 아래 상수이며, 합계·단축·단축률·L·ΔG·배율·평균 GEBV는 상수에서 **계산**한다(하드코딩 금지).
- program-overview 상수는 템플릿 간 결합을 피하려고 이 템플릿 `data.ts`에 복제하되, 주석으로 출처(`kpi/program-overview/data.ts`)를 남긴다.

```ts
export const MU = 560                         // kg/10a, program-overview MU
export const BASIS = { conventional: 2019, digital: 2026 } as const

export const PARAMS = {
  conventional: { i: 1.400, r: 0.45, sigmaA: 30.0 },   // program-overview 2019 (L은 단계 합으로 계산)
  digital:      { i: 1.755, r: 0.57, sigmaA: 28.2 },   // program-overview 2026
}

export type Stage = {
  id: 1|2|3|4|5|6|7; name: string
  conventional: number | null   // 년, null = 해당 없음
  digital: number               // 년
  inCycle: boolean              // 세대 간격(L)에 포함
  isNew: boolean                // 디지털 신규 단계
  digitalNote: string; kpi: { value: string; label: string; sub: string }
}
export const STAGES: Stage[] = [
  { id: 1, name: '교배',                     conventional: 0.5,  digital: 0.5, inCycle: true,  isNew: false, ... },
  { id: 2, name: '세대 진전(속성세대진전)', conventional: 3.0,  digital: 1.3, inCycle: true,  isNew: false, ... },
  { id: 3, name: '유전형 분석',              conventional: null, digital: 0.1, inCycle: true,  isNew: true,  ... },
  { id: 4, name: 'GEBV 예측',                conventional: null, digital: 0.1, inCycle: true,  isNew: true,  ... },
  { id: 5, name: '선발',                     conventional: 1.0,  digital: 0.2, inCycle: true,  isNew: false, ... },
  { id: 6, name: '생산력·지역 적응 시험',     conventional: 6.0,  digital: 4.0, inCycle: false, isNew: false, ... },
  { id: 7, name: '품종 출원',                conventional: 0.5,  digital: 0.5, inCycle: false, isNew: false, ... },
]

const r1 = (x: number) => Math.round(x * 10) / 10          // 표시 전 반올림(부동소수점 오차 제거)
const sum = (k: 'conventional'|'digital', f = (s: Stage) => true) =>
  r1(STAGES.filter(f).reduce((a, s) => a + (s[k] ?? 0), 0))

export const TOTAL = { conventional: sum('conventional'), digital: sum('digital') }            // 11.0, 6.7
export const SAVED = r1(TOTAL.conventional - TOTAL.digital)                                    // 4.3
export const SAVED_PCT = (TOTAL.conventional - TOTAL.digital) / TOTAL.conventional * 100       // 39.09 → "39.1%"
export const L = { conventional: sum('conventional', s => s.inCycle), digital: sum('digital', s => s.inCycle) } // 4.5, 2.2
export const stageSaved = (s: Stage) => s.conventional == null ? -s.digital : r1(s.conventional - s.digital)   // 신규 단계는 음수(+기간)
export const stageSavedPct = (s: Stage) => s.conventional == null ? null : (s.conventional - s.digital) / s.conventional * 100

export const dG = (k: 'conventional'|'digital') => PARAMS[k].i * PARAMS[k].r * PARAMS[k].sigmaA / L[k]  // 4.20, 12.82 kg/10a/년
export const dGpct = (k: 'conventional'|'digital') => dG(k) / MU * 100                                     // 0.75, 2.29 %/년
export const GAIN_RATIO = dG('digital') / dG('conventional')                                               // 3.053 → "3.1배(예측)"
// REALIZED·REALIZED_RATIO는 「ΔG 배율 표기」 절의 상수 블록을 출처 주석과 함께 그대로 둔다(정리 회차 2)

// 세대 진전 속도: F2~F6 = 5세대
export const GEN_RATE = { conventional: 5 / 3.0, digital: 5 / 1.3 }      // 1.67 → "1.7", 3.85 → "3.8"
// 주의: 3.846은 소수 1자리 반올림 시 3.8. toFixed(1) 사용

// 선발 단계
export const CANDIDATES = 2000, CROSSES = 400, LINES_PER_CROSS = 5        // CROSSES × LINES_PER_CROSS === CANDIDATES
export const SELECTED = 600
export const LINE_SEL_PCT = SELECTED / CANDIDATES * 100                   // 30.0 → 화면 "30.0%"(각주 포함, 하드코딩 금지)
export const I_LINE_SEL = 1.159                                           // p = 30% 정규 절단 강도
export const MEAN_GEBV_SELECTED = I_LINE_SEL * PARAMS.digital.r * PARAMS.digital.sigmaA   // 18.63 → "+18.6 kg/10a"

// 유전형 분석
export const GENOTYPING = { samples: 2000, chip: '6K SNP 칩', markersUsed: 4820, callRateMean: 98.9, qcPass: 1930, tatDays: 14 }
// QC 통과율 = 1930 / 2000 = 96.5%. 재분석 70샘플 후 GEBV 산출 2,000계통

export const TRAIN_N = 1850
export const TRIALS = { pyt: 120, ayt: 40, met: 18, metSites: 8, metYears: { conventional: 3, digital: 2 } }
export const CANDIDATES_FOR_RELEASE = 3
export const APPLICATIONS_2026 = { filed: 1, asOf: '2026-10-23', planned: 1 }
export const SHORTEST_ACTUAL_YEARS = 7        // 실제 최단 출원 사례(별하랑 YR19-0083, 2019 교배 → 2026 출원), 각주에 사용
export const NEW_STAGE_ADDED = 0.2            // ③④ 신규 단계가 더한 기간(타임라인 제목 "+0.2년 포함")
```

## 상호작용

- 정적 인포그래픽이다. 필터·툴팁·드릴다운은 두지 않는다(인쇄물과 화면이 같아야 한다). D 타임라인을 ECharts로 그리면 툴팁을 끄거나, 켜더라도 화면에 이미 보이는 값만 보여 준다.
- 캔버스: 1920×1080 논리 크기의 고정 비율(`aspect-ratio: 16 / 9`) 컨테이너. 부모 너비에 맞춰 비율을 유지하며 전체를 축소·확대한다(글자가 줄바꿈되며 레이아웃이 바뀌지 않게). 1440px 미리보기에서 잘림·가로 스크롤이 없어야 한다. 390px 폭에서도 비율을 유지한 채 축소 표시하면 된다.
- 인쇄: `@page { size: A4 landscape; margin: 10mm }`. 캔버스를 인쇄 가능 너비(277mm)에 맞춰 넣으면 높이 약 156mm로 한 쪽에 들어간다. 배경색·막대 색이 인쇄되도록 `print-color-adjust: exact`. 앱 내비게이션·사이드바 등 템플릿 바깥 요소는 인쇄에서 숨긴다.
- 흑백 인쇄 대비: 전통/디지털 구분과 단계 구분이 색 없이도 읽혀야 한다(단계 번호 라벨, "전통"/"디지털" 문자 라벨, 전통 막대는 옅은 회색 계열 또는 빗금).
- 최소 글자 크기: 1920 기준 본문 18px, 카드 보조 문구 17px, 캡션(타임라인 축·L 라벨·재순환 설명) 16px, 각주 15px 이상(A4 인쇄 시 약 2mm 이상). 1920×1080 한 장에 수용 기준 문구를 모두 넣기 위해 보조 문구·캡션 하한을 18px보다 낮췄다.
- 390px 폭에서는 캔버스가 비례 축소되어 글자가 읽기 어렵다. 공통 `ScaledCanvas`의 최소 배율(0.6)과 가로 스크롤은 그대로 두고, 캔버스가 최소 배율에 걸려 잘리는 폭(390·768, 2026-10-30부터 768 포함)에서 `ScaledCanvas summary`로 캔버스 위에 요약 카드(`MobileSummary`, 인쇄 제외)를 둔다(2026-10-30 H3 신설): 제목 "벼 디지털육종 프로세스 · 전통 2019 vs 디지털 2026", 카드 4개 ① 품종 개발 기간(교배 → 출원) "11.0 → 6.7"년 · 4.3년 단축 · 설계값(대표) ② 세대 간격(L) "4.5 → 2.2"년 · 2.3년 단축 ③ 예측 정확도(r) "0.57" · GBLUP · 전통 0.45 ④ 연간 유전적 개량량(ΔG) "0.75 → 2.29" %/년 · 3.1배(예측). footer "유전체 선발(GS)과 속성세대진전(RGA)으로 벼 품종 하나를 4.3년 더 빨리 만들 수 있습니다(설계값)". 전통 값은 작은 회색(conventional-vs-digital 요약 규격), 모든 숫자는 `TOTAL`·`L`·`PARAMS`·`dGpct`·`GAIN_RATIO`에서 생성. 좁은 카드라 배율은 "3.1배(예측)"만 쓰고 실현 2.6배는 캔버스 각주·ariaLabel에 있다. ③ 보조 "전통 0.45"는 표현형 선발 정확도이므로 캔버스 B 영역처럼 "전통(표현형 선발) 0.45"로 쓰기를 권장(도메인 검토 minor). 캔버스 제목은 h1
- 상태: 데이터가 상수이므로 로딩·빈 데이터·오류 상태는 없다.
- 숫자 표기: 기간 소수 1자리 + "년", 백분율 소수 1자리, 정확도 소수 2자리, ΔG %/년 소수 2자리, 천 단위 쉼표(2,000·1,850·4,820), 배율 소수 1자리 + "배".

## ΔG 배율 표기(2026-10-26 정리 회차 2, 사용자 결정)

- **표기 규칙(사용자 결정 2026-10-26)**: 헤드라인 ΔG 배율은 구성 요소(i · r · σA / L)로 계산한 **예측** 배율이므로 실현 배율과 병기한다.
  - 표준 문구: **"3.1배(예측) · 실현 2.6배"** — 문장·해설·각주·`ariaLabel`처럼 공간이 있는 곳.
  - 좁은 곳(배지, KPI 보조 줄, 큰 숫자, 모바일 요약 카드): **"3.1배(예측)"**만. 이때 같은 화면의 다른 위치(문장·각주)에 표준 문구나 실현 배율 설명이 있어야 한다.
  - 두 숫자는 상수에서 만든다: `${f1(GAIN_RATIO)}배(예측)`, `실현 ${f1(REALIZED_RATIO)}배`. 하드코딩 금지.
  - 실현 배율의 기준: genetic-gain-tracker 실현 추세 기울기 비(전통 2019~2021 코호트 3.439753, GS 2021~2026 코호트 9.097399 kg/10a/년 → 2.644783). 예측 배율 3.053(ΔG 2026 / 2019)과 기준 기간이 달라 나란히 쓸 때 "예측"·"실현"을 반드시 붙인다.
- **상수**(`data.ts`, `GAIN_RATIO` 아래):

```ts
// ───────── 출처: kpi/genetic-gain-tracker periodStats(쌀 수량, 2019~2026) — 실현 유전적 추세 기울기 ─────────
// 원 실행값(2026-10-26 정리 회차 2 재실행, REALIZATION_BIAS 0.90). 전통 = 2019~2021 코호트, GS = 2021~2026 코호트
export const REALIZED = { conventional: 3.439753, gs: 9.097399 } as const // kg/10a/년 → "3.4", "9.1"

export const REALIZED_RATIO = REALIZED.gs / REALIZED.conventional
```

## 수용 기준

- [ ] 핵심 숫자 띠의 개발 기간이 "11.0년 → 6.7년, 4.3년 단축(−39.1%)"이고, 이 값이 흐름도 7단계 카드의 전통·디지털 기간 합계, 그리고 타임라인 두 막대의 길이·끝 라벨과 모두 일치한다.

- [ ] 예측 정확도 0.57, 세대 간격 2.2년, GS 도입 2022, 훈련 집단 1,850계통, 파이프라인 2,000 → 600 → 120 → 40 → 18 → 3, 2026 출원 1건이 program-overview의 2026 값과 같다.
