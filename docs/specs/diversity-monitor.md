- 연결 템플릿: `program-overview`(L, i, r, σA, ΔG 2026 = 12.8 kg/10a/년, GS 도입 2022), `kinship-heatmap`(부모 후보 60계통 GRM: 평균 비대각 G 0.17 = f 0.0839, 그룹 내 평균 G, 대각 평균 F 0.970, 강한 근연 49쌍·근연 주의 29쌍·근연 군집 13개, H_e 0.40), `cross-planner`·`pedigree-explorer`(근연 등급 `kinLevel`, `KinBadge`), `gebv-selection`(부모 후보 = 600계통 중 p = 10% 60계통), `population-structure`(용어만 공유, 숫자 공유 없음)

## 가정

- 작물: 벼(*Oryza sativa*, 12개 염색체, 약 430 Mb, **자식성**). 가상 "중부 평야지 벼 육종 프로그램". **program-baseline 준수**.
- 사용자: 육종 프로그램 관리자(연 1회 다양성 점검·관리 조치 결정), 육종가(부모 선발 방식 결정).
- 사용 시나리오: ① 부모 재순환 집단의 다양성이 경보 기준 안에 있는지 3초 안에 확인 → ② GS 도입 뒤 다양성 손실이 왜 빨라졌는지(세대당 증가 vs 세대 간격 단축) 확인 → ③ 다음 교배 주기(2027 1차)에 최적 기여 선발(OCS)을 쓸지 시나리오로 비교한다.
- **대상 집단(부모 재순환 집단)**: 연도별 "부모 선발 후보 집단"(세대 진전 후보 중 GEBV 또는 표현형 상위 p로 고른 계통 = 다음 교배의 부모 풀). 2026은 program-baseline의 「부모 선발 후보 집단(2026 하반기)」 60계통이며 kinship-heatmap·cross-planner의 60계통과 같다. 연도별 후보 수는 화면에 쓰지 않는다(세대 간격 L년 동안 여러 연도 후보가 겹쳐 부모로 쓰이므로 연간 후보 수와 Ne를 직접 비교하면 오해를 부름).
- **자식성 벼의 근교 지표 해석(핵심)**: 부모 계통 자체의 근교계수 F(GRM 대각 − 1)는 고정 근교계라 0.94~0.99(kinship-heatmap 평균 0.970)로 늘 1에 가깝고, 다양성 판단에 쓰지 않는다. 집단의 근교 진행은 **부모 간 평균 공조계수 f̄**(= 무작위 교배 F₁ 자손의 기대 근교계수)와 그 증가율 ΔF로 본다. 화면에서 "근교 증가율 ΔF"는 "평균 공조계수 증가율"과 같은 뜻임을 툴팁에 밝힌다.
- **f̄의 기준**: kinship-heatmap과 같은 VanRaden GRM(6K SNP 칩 4,820 SNP, 대립유전자 빈도 p = 2026 훈련 집단 1,850계통)에서 f = G/2. 2019~2025 부모 후보도 보관 DNA 유전형으로 **같은 기준 빈도**로 소급 계산했다고 가정한다(연도 간 비교 가능). f̄는 기준 빈도에 대한 상대값이므로 절대 IBD 확률이 아니며 추이(증가율)를 본다. 2026 f̄ = **0.0839**(kinship-heatmap 평균 비대각 G 0.16777/2 = 0.08389, 화면 표기 0.084. 2026-10-26 정리 회차 1·2 후에도 4자리 0.0839 유지).
- **Ne 정의**: 실현 유효 집단 크기 Ne = 1/(2ΔF), ΔF = 세대당 평균 공조계수 증가율. 연도별 Ne는 상수로 정하고(추정) 나머지(ΔF, f̄, He)는 계산한다. 95% 구간은 마커 부트스트랩 결과를 흉내 낸 고정 배율(하한 × 0.85, 상한 × 1.18, 추정).
- **세대당 → 연간 환산**: ΔF연 = 1 − (1 − ΔF세대)^(1/L). L은 program-overview `L`(2019 4.5 → 2026 2.2년).
- **브리프 문구 보정**: 브리프의 "세대 간격 단축으로 세대당 다양성 손실이 빨라진다"는 정확히는 "세대 간격 단축으로 **연간(단위 시간당)** 손실이 빨라진다"이다. 세대당 손실도 커지지만 그 원인은 선발 강화(p 20% → 10%)와 GEBV 상위 가계 집중이다. 화면은 이 둘을 분리해 보인다(연간 3.8배 ≈ 세대당 1.8배 × L 단축 2.0배).
- **He 정의**: 기대 이형접합도 He = 1 − Σp²(이대립 SNP 평균 2pq). 기준 집단 대비 평균 공조계수 f̄만큼 이형접합도가 줄어든다는 관계(He_t = H_ref · (1 − f̄_t), Falconer & Mackay)로 계산한다. H_ref = 0.40(훈련 집단 평균 2pq, kinship-heatmap `H_E`, 추정). 그룹별 He(2026만) = 0.40 · (1 − 그룹 내 평균 f), 그룹 내 평균 f는 kinship-heatmap 그룹 평균 G/2(AA 0.29802, BB 0.31305, CC 0.10756 — 2026-10-26 정리 회차 2 개정, 정리 회차 1 AA 0.29825·BB 0.31263, 처음 AA 0.29646·BB 0.31453).
- **마커 고정·희소**: 6K 칩 QC 후 4,820 SNP를 부모 후보 집단 빈도로 센다. "고정"은 부모 집단에서 단형(MAF = 0), "희소(소실 위험)"는 0 < MAF < 0.05. 값은 드리프트 모의(아래 생성 규칙)의 실행값이다.
- **경보 기준(프로그램 내부 기준, 추정)**:
  - Ne: 경보 < 50(카탈로그 경보 기준, ΔF세대 > 1.0%와 동치), 주의 < 60.
  - 연간 ΔF: 경보 > 0.42%/년, 주의 > 0.38%/년(상한의 90%). 근거: 장기 계획 25년 동안 He 손실 10% 이내 → 1 − 0.9^(1/25) = 0.420%/년.
  - He: 하한 0.35(집단·그룹 공통).
  - 고정 마커 비율: 주의 ≥ 3.0%(4,820 중 145개 이상).
- **OCS 시나리오 모형(단순 모형, 추정)**: 다음 교배 주기(2027 1차) 한 세대, L = 2.2년 고정. 현행 절단 선발(상위 10%, i 1.755)의 ΔG0 = 12.82 kg/10a/년(program-overview 2026), ΔF0 = 0.962%/세대. OCS의 이득-다양성 경계: ΔG_OCS(ΔF) = 1.04 · ΔG0 · (ΔF/ΔF0)^0.2(같은 ΔF에서 OCS가 절단 선발보다 4% 높고, ΔF를 줄일수록 완만하게 감소. Woolliams et al. 2015 *Anim Front*, Gorjanc & Hickey 2018 *G3*의 정성적 결과를 단순화한 추정). 부모 수 확대 시나리오: p 15%(i = `selectionIntensity(0.15)` = 1.554), Ne는 부모 수에 비례해 52 × 1.5 = 78(추정).
- 2026 값은 진행 중 연도이며, 2026 하반기 부모 후보 GRM(계산 2026-10-22) 기준이다.
- 계통명·품종명은 모두 가상이다.

## 화면 목적과 핵심 질문

1. 지금(2026) 부모 재순환 집단의 다양성이 경보 기준 안에 있는가? 어떤 항목이 경보·주의인가?
2. GS 도입(2022) 뒤 다양성 손실이 얼마나, 왜 빨라졌는가(세대당 증가 vs 세대 간격 단축)?
3. 최적 기여 선발(OCS)로 근교 증가를 묶으면 유전적 개량량(ΔG)을 얼마나 잃는가?

- 마커 드리프트 모의(난수 소비 순서를 반드시 지킨다):

```ts
const rng = createRng(20261023)
const p = new Array(M)
for (let k = 0; k < M; k++) {                    // ① 초기 빈도(2019 부모 후보 집단)
  const rare = rng.next() < 0.06
  let q = rare ? rng.beta(0.35, 5) : rng.beta(1.6, 1.6)
  if (rng.next() < 0.5) q = 1 - q
  p[k] = q
}
const lo0 = 0.5 / 60                             // 60계통에서 단형으로 보이는 경계
for (k) { if (p[k] < lo0) p[k] = 0; else if (p[k] > 1 - lo0) p[k] = 1 }
count(2019)
for (const y of YEARS.slice(1)) {                // ② 연간 드리프트, 반수체 크기 n = 1/ΔF연
  const n = 1 / dFyr(y)
  for (let k = 0; k < M; k++) {
    const q = p[k]
    if (q === 0 || q === 1) continue             // 고정은 흡수 상태(난수 소비 없음)
    let q2 = q + Math.sqrt(q * (1 - q) / n) * rng.normal()
    if (q2 <= 0.5 / n) q2 = 0; else if (q2 >= 1 - 0.5 / n) q2 = 1
    p[k] = q2
  }
  count(y)
}
// count: maf = min(q, 1−q). fixed = maf === 0 개수, rare = 0 < maf < 0.05 개수
```
