# GEBV 기반 선발 — 명세

- slug: `gebv-selection` · category: `viz` · 기준일: 2026-10-23
- 지표 기준: `.claude/skills/breeding-metrics/references/metrics-catalog.md` (모든 값은 카탈로그 범위 안의 가상 목업)
- 연결 템플릿: `program-overview`(2026년 수량 기준 i = 1.755 @ p = 10%, r = 0.57, σA = 28.2 kg/10a, L = 2.2년, μ = 560 kg/10a, ΔG 12.8 kg/10a/년 = 2.29%/년), `cross-planner`(앵커 8계통의 수량 GEBV·신뢰도). 이 화면에서 p = 10%로 뽑은 60계통이 교배 조합 설계의 부모 후보 규모(60계통)와 같다.

## 가정

- 작물: 벼(*Oryza sativa*, 12개 염색체, 약 430 Mb, 자식성). 후보는 모두 고정 계통(F6 이상)이다.
- 사용자: 육종가. 2026년 하반기 **부모 선발(재순환 선발) 단계**에서 다음 교배(2027년 1차)에 쓸 부모 후보를 고른다. 이 단계의 선발 비율 p가 `program-overview` ΔG 식의 i를 정한다.
- 후보 집단: 유전형 분석과 GBLUP 예측을 마친 **600계통**(앵커 8 + 생성 592). 계통명 `YR19-xxxx`~`YR24-xxxx`, 모두 가상이다.
- 형질 4개(모두 GEBV, GBLUP, 훈련 집단 1,850계통): ① 쌀 수량(kg/10a, 백미 기준, 주 형질 — "정조 수량"으로 쓰지 않는다, program-baseline 2026-10-23 사용자 결정) ② 간장(cm, 낮을수록 좋음 — 도복) ③ 잎도열병 발병 지수(0~9 척도의 GEBV, 점, 낮을수록 저항성) ④ 식미치(식미계 점수, 점, 높을수록 좋음).
- GEBV 기준점: **훈련 집단 평균 = 0**. 후보 집단의 수량 GEBV 평균 +10.0 kg/10a는 훈련 집단 이후 세대의 개량분이다(**추정**·목업 설정).
- 수량 GEBV의 집단 표준편차는 σ_GEBV = r · σA = 0.57 × 28.2 = **16.074 kg/10a**로 맞춘다(평균 정확도 r를 갖는 GEBV의 기대 분산 = r²σA²).
- 앵커 8계통은 `cross-planner`와 같은 수량 GEBV·신뢰도를 쓴다. 생성 592계통은 `cross-planner`의 생성 52계통과 **독립**이다(같은 이름이 우연히 나와도 다른 목업). 일치를 보장하는 것은 앵커 8계통뿐이다.
- 선발 강도 i는 무한 집단 정규 절단식 i = φ(x_p)/p를 쓴다(유한 집단 보정 없음). 툴팁에 밝힌다.
- 유전자 이름(Pi-ta, Pib, Pi9, Pigm)은 앵커 설명 툴팁에만 쓰며, 보유 여부는 가상이다.
- 표기 예외: 용어집은 백분율을 소수 1자리로 쓰지만, ΔG %/년은 소수 2자리(2.29%/년)로 쓴다. `program-overview`·`digital-breeding-process`의 2.29%/년과 같은 숫자로 보여야 하고, 연간 개량량은 0.5~2.5% 범위라 1자리로는 차이가 뭉개지기 때문이다.

## 화면 목적과 핵심 질문

1. 선발 비율 p를 정하면 기준 GEBV(컷오프)가 어디에 그어지고 몇 계통이 뽑히며, 그때 선발 강도 i와 기대 연간 유전적 개량량(ΔG)은 얼마인가?
2. 뽑힌 계통은 누구이고, 각 계통의 GEBV는 얼마나 믿을 만한가(신뢰도)? 다른 형질에서 손해를 보는 계통은 없는가?
3. 경제적 가중치를 바꿔 다형질 선발 지수로 뽑으면 선발 명단과 형질별 선발 차가 어떻게 달라지는가(수량–식미 상충)?

## 목업 데이터 생성 규칙

- 시드: **20261023** (`createRng(20261023)` from `@/lib/rng`, `lineName`·`selectionIntensity`·`normPdf` from `@/lib/genomics`)
- 앵커 8계통은 위 표의 **상수**. 생성 592계통만 난수로 만든다. z·I·순위·컷오프·S·R·ΔG·KDE·상관은 모두 **계산**하고 하드코딩하지 않는다.
- 난수 소비 순서를 아래 그대로 지킨다(같은 시드 → 같은 화면).

```ts
const SEED = 20261023
const N = 600, N_GEN = 592
const R_ACC = 0.57, SIGMA_A = 28.2, L = 2.2, MU = 560          // program-overview 2026
const MEAN_Y = 10.0, SD_Y = R_ACC * SIGMA_A                     // 16.074
const TRAITS = {
  yield: { label: '쌀 수량', unit: 'kg/10a', d: +1, acc: 0.57, sigmaA: 28.2 },
  culm:  { label: '간장',     unit: 'cm',     d: -1, acc: 0.65, sigmaA: 4.8  },
  blast: { label: '잎도열병 발병 지수', unit: '점', d: -1, acc: 0.47, sigmaA: 1.10 },
  taste: { label: '식미치',   unit: '점',     d: +1, acc: 0.38, sigmaA: 2.6  },
}
const RHO_WITH_YIELD = { culm: +0.30, blast: +0.10, taste: -0.20 }   // 원 척도(부호 정렬 전) GEBV 상관
const PRESETS = {
  yieldFirst: { yield: 0.50, culm: 0.15, blast: 0.20, taste: 0.15 },  // 기본
  balanced:   { yield: 0.25, culm: 0.25, blast: 0.25, taste: 0.25 },
  resistance: { yield: 0.30, culm: 0.10, blast: 0.50, taste: 0.10 },
  quality:    { yield: 0.30, culm: 0.10, blast: 0.15, taste: 0.45 },
}

const rng = createRng(SEED)

// 1) 수량 z: 절단 정규(−3.0 ≤ z ≤ 2.05)를 거부 표집 → 표준화
//    상위 꼬리(> +45)를 앵커가 채우게 해 앵커 1~4가 전체 1~4위가 되도록 한다
const zRaw: number[] = []
while (zRaw.length < N_GEN) { const z = rng.normal(); if (z >= -3.0 && z <= 2.05) zRaw.push(z) }
const zm = mean(zRaw), zs = sdPop(zRaw)                         // sdPop: n으로 나눔
const zy = zRaw.map(z => (z - zm) / zs)

// 2) 앵커를 포함한 600계통의 평균 = 10.0, 모집단 SD = 16.074가 되도록 a, b를 푼다
const sumA = Σ anchor.yield                                      // 291.0
const ssA  = Σ (anchor.yield - MEAN_Y)²                          // 7557.40
const a = (N * MEAN_Y - sumA) / N_GEN                            // 9.6436
const b = Math.sqrt((N * SD_Y ** 2 - ssA) / N_GEN - (a - MEAN_Y) ** 2)   // 약 15.78
// 생성 수량 GEBV = round1(a + b * zy[i]). 개발 모드에서 max < 45.6을 assert(넘으면 44.9로 clamp + console.warn)

// 3) 생성 계통별(인덱스 i 순서) 나머지 값. 한 계통 안의 호출 순서:
for (let i = 0; i < N_GEN; i++) {
  const name    = uniqueLineName(rng, 'YR', rng.int(2019, 2024))   // 앵커 이름·기존 이름과 겹치면 다시 뽑기
  const relY    = relOf(rng, 0.57)
  const culm    = round1(TRAITS.culm.sigmaA  * 0.65 * (0.30 * zy[i] + Math.sqrt(1 - 0.30 ** 2) * rng.normal()))
  const blast   = round2(TRAITS.blast.sigmaA * 0.47 * (0.10 * zy[i] + Math.sqrt(1 - 0.10 ** 2) * rng.normal()))
  const taste   = round1(TRAITS.taste.sigmaA * 0.38 * (-0.20 * zy[i] + Math.sqrt(1 - 0.20 ** 2) * rng.normal()))
  const relCulm = relOf(rng, 0.65), relBlast = relOf(rng, 0.47), relTaste = relOf(rng, 0.38)
}
// 형질별 GEBV SD 기대값 = acc × σA: 간장 3.12 cm, 도열병 0.517점, 식미 0.988점
function relOf(rng, acc) { return round2(clamp(acc ** 2 * (0.4 + 1.2 * rng.beta(5, 5)), 0.08, 0.65)) }
// 수량 신뢰도 0.13~0.52(평균 ≈ 0.33 → √ ≈ 0.57). 식미는 h²가 낮아 하한 0.08까지 내려간다(카탈로그 0.1 미만, 의도)

// 4) 후보 배열 = 앵커 8 → 생성 592

// 5) 파생 계산(난수 없음)
const mean_t = mean(all.map(x => x[t])), sd_t = sdPop(all.map(x => x[t]))
const z = (x, t) => TRAITS[t].d * (x[t] - mean_t) / sd_t
const wNorm = w => { const s = Σ w; return s > 0 ? map(w, v => v / s) : null }   // null → 지수 모드 오류 상태
const index = (x, w) => Σ_t wNorm(w)[t] * z(x, t)
const iOf = p => round3(selectionIntensity(p))                 // p: 0.01~0.50
const nSel = p => Math.max(1, Math.round(p * N))
// 순위: 기준값 내림차순, 같으면 계통명 오름차순. 상위 nSel 계통 = 선발
const cutoff = sorted[nSel - 1].value
const S_t = mean(selected[t]) - mean_t                          // 원 단위, 표준화는 d * S_t / sd_t
const R = iOf(p) * R_ACC * SIGMA_A, dG = R / L, dGpct = dG / MU * 100
// KDE: 가우스 커널, 대역폭 h = 1.06 · sd · N^(−1/5)(수량 약 4.7), 200점 격자, 막대 높이에 맞춰 × N × binWidth
```

- 초기 상태: 수량 모드, p = 10%, 가중치 프리셋 "수량 중시", 산점도 y = 식미, 선택 계통 = YR22-0412.
- 통계 점검: 수량 GEBV 평균 10.0, 모집단 SD 16.07(표시 반올림 기준), 모든 신뢰도 ∈ [0.08, 0.65], 모든 상관 ∈ [−1, 1], 정규화 가중치 합 = 1.

## 상호작용

- **선발 비율 슬라이더**: 드래그·키보드(←→ 1%, PageUp/Down 5%) 즉시 반영. n_sel·i·컷오프·히스토그램 색·평균선·S·E 막대·산점도 강조·표 선발 열·KPI가 함께 갱신된다. `aria-valuetext` "선발 비율 10%, 60계통, 선발 강도 1.755".
- **선발 기준 전환**: 수량 GEBV ↔ 다형질 선발 지수. 지수 모드에서 D의 x축은 지수 I, 컷오프는 I 값, KPI ④는 수량 실현 선발 차 기반, 가중치 패널 활성. 표 기본 정렬도 현재 기준으로 바뀐다.
- **가중치**: 슬라이더·프리셋 변경 시 즉시 재계산. 프리셋과 다른 값이면 프리셋 표시 "사용자 지정". 모든 가중치 0이면 D·E·G 지수 관련 표시를 `EmptyState` "가중치를 하나 이상 0보다 크게 설정하세요"로 바꾸고 KPI는 "–".
- **툴팁**: 히스토그램 막대 "+28 ~ +32 kg/10a · 선발 9 · 비선발 31". 산점도 점 "YR22-0412 · 수량 +52.4 · 식미 −0.6 · 수량 신뢰도(r²) 0.58 · 순위 1 · 선발". 선발 강도 툴팁 "i = φ(x)/p, 무한 집단 정규 절단 가정".
- **연동 선택**: 표 행 클릭/Enter 또는 산점도 점 클릭 → I 상세 카드 갱신, 산점도 해당 점 강조(테두리 링), 히스토그램에 해당 계통 위치 markPoint(삼각형 + 계통명).
- **표**: 열 머리글 정렬(오름/내림 토글, `aria-sort`), 계통명 검색(부분 일치, 결과 0건이면 `emptyText` "일치하는 계통이 없습니다"), "선발만 보기" 토글.
- **상태**: 초기 400ms `Skeleton`(시뮬레이션). 오류 상태 토글은 두지 않아도 된다.
- **숫자 표기**: GEBV 부호 포함(수량·간장·식미 1자리, 도열병 2자리), 신뢰도·z·I·상관 2자리, i 3자리, p 정수 %, ΔG kg/10a/년 1자리(KPI) 또는 2자리(툴팁), %/년 2자리(용어집 1자리 규칙의 예외, 가정 절 참고), 천 단위 쉼표, 음수는 "−"(U+2212).

## 수용 기준

- [ ] 후보 600계통의 수량 GEBV 평균이 +10.0, 모집단 SD가 16.07 kg/10a(= 0.57 × 28.2)로 표시·계산되고, 수량 GEBV 내림차순 1~4위가 YR22-0412(+52.4), YR22-0415(+49.8), YR21-0877(+47.1), YR23-0136(+45.6)이다.
- [ ] 기본 상태(수량 모드, p = 10%)에서 KPI가 선발 60/600계통, 선발 강도(i) 1.755, ΔG 12.8 kg/10a/년(2.29%/년)을 보이고, 보조 식 "1.755 × 0.57 × 28.2 / 2.2"가 `program-overview`의 2026년 ΔG와 같은 값이다.
- [ ] 선발 비율을 5%·1%·20%·50%로 바꾸면 i가 2.063·2.665·1.400·0.798, 선발 수가 30·6·120·300으로 바뀌고 ΔG가 검산표(15.07·19.47·10.23·5.83 kg/10a/년)와 소수 2자리까지 일치한다. 선발 수 < 30(p ≤ 4%)일 때만 다양성 경고 배지가 보이고, ΔG %/년 > 2.5(p ≤ 5%)일 때 KPI ④에 "카탈로그 범위 초과" 배지가 보인다.
- [ ] 히스토그램의 선발 기준선이 순위 표 n_sel번째 계통의 값과 같고, 기준선 오른쪽(선발 계열) 막대 높이 합이 KPI 선발 수와 같다(구간을 걸치는 계통도 선발/비선발 누적 막대로 정확히 나뉜다).
- [ ] 히스토그램에 전체 평균선·선발 평균선과 실현 선발 차 S 라벨이 있고, 수량 모드 p = 10%에서 S = 27.1 kg/10a(기대 반응 R = 28.2의 96.2%), 기준 GEBV +30.4이다.
- [ ] 순위 표에 수량 GEBV와 함께 신뢰도(r²) 열이 있고, 형질별 표준화 GEBV(z) 4열·지수 I·선발 표시가 있으며 모든 열로 정렬된다. z는 간장·도열병의 부호가 뒤집혀 "양수 = 바람직한 방향"이다.
- [ ] 지수 모드에서 I = Σ w·z(정규화 가중치 합 1)가 상세 카드의 형질별 기여 w_t·z_t 합과 일치하고, 프리셋 "저항성 중시"를 고르면 YR20-1108과 YR19-0731이 p = 10% 선발에 들어온다(수량 모드에서는 둘 다 비선발).
- [ ] 형질별 선발 차 막대(E)가 수량 모드 p = 10%에서 수량은 양수, 식미는 음수(수량–식미 음의 상관으로 인한 손해)로 표시되고, 음수 막대에는 색과 함께 "손해" 문자가 붙는다.
- [ ] 두 형질 산점도에 600점이 그려지고 선발 계통은 채움 여부로도 구분되며, 수량 모드에서 x = 기준 GEBV 수직선, 지수 모드에서 부분 지수 등고선이 보이고, 부제의 GEBV 상관이 −1~1 범위의 실제 계산값(수량–식미 −0.23)이다.
- [ ] 용어가 첫 등장 시 한국어+약어로 표기된다: 유전체 추정 육종가(GEBV), 신뢰도(r²), 예측 정확도(r), 선발 비율(p), 선발 강도(i), 상가적 유전 표준편차(σA), 연간 유전적 개량량(ΔG), 세대 간격(L). 계통명 가상 고지 문구가 있고, 레이더 차트를 쓰지 않는다.
