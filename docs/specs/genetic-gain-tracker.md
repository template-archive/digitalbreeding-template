# 유전적 개량량 추적 — 명세

- slug: `genetic-gain-tracker` · category: `kpi` · 기준일: 2026-10-23
- 지표 기준: `.claude/skills/breeding-metrics/references/metrics-catalog.md`, 공유 기준값: `references/program-baseline.md`
- 모든 값은 가상 목업이다. 숫자는 「검산 기록」의 스크립트 실행값이다.

## 가정

- 작물: 벼(*Oryza sativa*, 12개 염색체, 약 430 Mb, 자식성). 가상 "중부 평야지 벼 육종 프로그램". **program-baseline 준수**.
- 사용자: 연구 관리자(사업 성과 점검·보고), 육종가(선발 전략 점검).
- 사용 시나리오: 형질과 기간을 고르고 ① 유전적 추세가 실제로 얼마나 올랐는지(실현), ② 육종가 방정식으로 예측한 ΔG와 맞는지, ③ ΔG가 늘어난 원인이 i·r·σA·L 중 무엇인지, ④ 전통 육종(2019~2021)과 유전체 선발(GS, 2022~)이 얼마나 다른지 확인한다.
- **연도별 구성 요소 i, r, σA, L은 program-overview `data.ts`의 상수(`I`, `R`, `SIGMA_A`, `L`)와 같은 값**을 쓴다. 쌀 수량 ΔG 2026 = 1.755 × 0.57 × 28.2 / 2.2 = 12.8 kg/10a/년 = 2.29%/년(program-overview KPI와 같음). μ = 560 kg/10a. GS 도입 2022.
- 수량 표기는 **"쌀 수량"(kg/10a, 백미 기준)**. "정조 수량"으로 쓰지 않는다.
- 부모 선발(재순환 선발)은 2019~2026 모두 **수량 GEBV(또는 2021년까지는 수량 표현형) 중심**이다(program-overview의 i는 수량 기준). 그래서 다른 형질의 개량량은 수량 선발에 따른 **상관 반응**으로 근사한다:
  CR형질 = i · r수량 · rg · σA,형질 / L. rg는 gebv-selection의 수량과의 GEBV 상관(`RHO_WITH_YIELD`: 간장 +0.30, 잎도열병 발병 지수 +0.10, 식미치 −0.20)을 유전 상관 근사값으로 쓴다(추정). σA,형질은 gebv-selection `TRAITS.sigmaA`(간장 4.8 cm, 발병 지수 1.1점, 식미치 2.6점)를 전 기간 고정(추정, 감소 무시).
- 유전적 추세의 **기준은 2019 코호트 평균 = 0**(코호트 = 세대 진전 후보로 유전형 분석된 연도). 화면 값은 "2019 코호트 대비 편차"다. gebv-selection·pedigree-explorer의 GEBV(훈련 집단 평균 0 기준)나 field-trial-layout의 시험 평균 수량과 **수준(절대값)을 비교할 수 없다**. 그래서 이 템플릿은 절대 수량(560 + 편차)을 표시하지 않고 기울기와 편차만 보여 주며, 차트 부제에 기준을 적는다.
- 2019~2021 코호트 GEBV는 보관 DNA로 소급 유전형 분석한 계통(410·455·520계통, 추정)의 2026-10 GBLUP 재추정값, 2022~2026은 세대 진전 후보 전체(program-overview `PIPELINE[y][0]`: 1,800·1,900·2,000·2,000·2,000)다.
- 표현형 추세 = 같은 코호트의 생산력 검정 평균의 2019 대비 편차. 연차 환경 효과가 섞여 있어 유전적 추세와 다르다(대비 품종 보정 전 값). 이 차이를 보여 주는 것이 화면 목적 중 하나다.
- 표현형 시점(보완 가정): 코호트는 유전형 분석 연도 기준이고 생산력 검정은 보통 몇 년 뒤에 하므로, 최근 코호트(2024~2026)의 표현형은 예비 시험(관찰 포장) 값으로 본다. 화면 부제나 툴팁에 이 설명을 한 줄 두는 것을 권장한다(현재 코드에는 없음, 다음 수정 때 반영).
- 2026년 값은 진행 중 연도(10/23 기준 잠정)다.
- 형질 기본 수준(2019 코호트, 대비 품종 가람솔과 같음): 간장 80 cm, 잎도열병 발병 지수 5점(0~9), 식미치 71점(variety-profile 대비 품종 값). 화면에는 쓰지 않고 툴팁 설명에만 쓴다.

## 화면 목적과 핵심 질문

1. 선택한 형질의 유전적 추세(연도별 평균 GEBV)가 GS 도입 뒤 얼마나 가팔라졌는가? 실현 기울기가 육종가 방정식 예측 ΔG와 맞는가?
2. ΔG가 늘어난 원인은 i, r, σA, L 중 무엇이며 각각 얼마나 기여했는가(전년 대비, 기간 전체)?
3. 수량 위주 선발이 다른 형질(간장·도열병·식미치)을 바람직하지 않은 방향으로 끌고 가고 있지는 않은가?

## 목업 데이터 생성 규칙

- 시드: **20261023** (`createRng(20261023)` from `@/lib/rng`). 난수는 유전적 추세 증분 잡음과 표현형 환경 효과에만 쓴다. 구성 요소·ΔG·분해는 상수에서 계산한다.
- **실현 편향(2026-10-26 정리 회차)**: 코호트 증분 = `REALIZATION_BIAS × 예측 ΔG(또는 상관 반응) + 잡음`, `REALIZATION_BIAS = 0.90`(추정, 모든 형질 공통). 예측 ΔG·LMDI·지수는 편향 없이 그대로다(육종가 방정식 예측은 바뀌지 않고 실현만 낮아짐). 난수 호출 수·순서는 그대로.
- 난수 소비 순서(반드시 지킨다): 형질 순서 `yield → culm → blast → taste`. 형질마다 ① 증분 잡음 2020~2026(7개) ② 환경 효과 2019~2026(8개). 총 60회 `rng.normal` 호출.

```ts
const YEARS = [2019, 2020, 2021, 2022, 2023, 2024, 2025, 2026]
const GS_START = 2022, MU = 560
// I, R, SIGMA_A, L: 위 표(program-overview와 같은 값)
const dG = (y) => I[y] * R[y] * SIGMA_A[y] / L[y]
const dGTrait = (t, y) => t.key === 'yield' ? dG(y) : I[y] * R[y] * t.rg * t.sigmaA / L[y]

const rng = createRng(20261023)
for (const t of TRAITS) {               // yield, culm, blast, taste
  const G = { 2019: 0 }
  for (const y of YEARS.slice(1)) G[y] = G[y - 1] + REALIZATION_BIAS * dGTrait(t, y) + rng.normal(0, t.noise)   // REALIZATION_BIAS = 0.90
  const E = {}
  for (const y of YEARS) E[y] = rng.normal(0, t.env)
  const P = {}
  for (const y of YEARS) P[y] = G[y] + E[y] - E[2019]   // 2019 표현형 편차 = 0
  trend[t.key] = { G, P }
}

// 기간 [start, end] (end − start ≥ 2 강제)
const tradCohorts = YEARS.filter(y => y >= start && y <= Math.min(end, GS_START - 1))
const gsCohorts   = end >= GS_START ? YEARS.filter(y => y >= Math.max(start, GS_START - 1) && y <= end) : []
const tradPredYears = YEARS.filter(y => y >= start && y <= end && y < GS_START)
const gsPredYears   = YEARS.filter(y => y >= start && y <= end && y >= GS_START)
// 회귀는 코호트 수 ≥ 2일 때만(2개면 두 점의 차). 기울기 = OLS(x = 연도, y = G)
// 실현율 = slope / mean(dGTrait over predYears) × 100
// 표현형 기울기 = OLS(기간 전체 코호트, P)

// LMDI(수량만)
function lmdi(y) {
  const g0 = dG(y - 1), g1 = dG(y)
  const w = Math.abs(g1 - g0) < 1e-12 ? g1 : (g1 - g0) / (Math.log(g1) - Math.log(g0))
  return { i: w * Math.log(I[y] / I[y - 1]), r: w * Math.log(R[y] / R[y - 1]),
           sigmaA: w * Math.log(SIGMA_A[y] / SIGMA_A[y - 1]), L: w * Math.log(L[y - 1] / L[y]) }
}
// 기간 분해 = Σ_{y=start+1..end} lmdi(y). 합 = dG(end) − dG(start) (DEV 검산 |차| < 1e-9)
```

## 상호작용

- 형질 `Select`: B·C·D·E·결론·I 강조 행이 바뀐다. F·G·H는 수량 고정(안내 문구).
- 기간: 시작 ≤ 종료 − 2 강제(3개 코호트 이상). 시작을 바꿔 조건이 깨지면 종료를 시작 + 2로 맞추고, 종료가 2026을 넘으면 시작을 2024로 맞춘다. 기본 2019~2026.
  - 기간이 2022 이후만(예: 2022~2026)이면 GS 회귀는 2022 코호트부터, 전통 회귀·타일 ③은 "—". 실행값: GS 기울기 9.6(9.626), 예측 평균 10.40, 실현율 92.6%.
  - 기간이 2021 이전만(2019~2021)이면 GS 회귀·타일 ②는 "—", "GS 도입 마크라인"은 숨긴다.
- 표현형 추세 `Switch`: 끄면 C의 표현형 계열과 그 기울기 라벨을 숨긴다(I의 표현형 열은 유지).
- 툴팁: C는 연도·유전적 추세·표현형·코호트 계통 수·그 해 예측 ΔG(수량은 kg과 %/년). F는 지수와 원값. G·H는 요소별 기여(kg/10a/년, 소수 2자리)와 비중. 연도는 axisValue가 아니라 dataIndex로 찾는다.
- 상태: 초기 600ms `Skeleton` → 데이터. 오류 상태 토글은 두지 않아도 된다.
- 숫자 표기: 수량 기울기·ΔG kg 소수 1자리(툴팁·분해는 2자리), %/년 소수 2자리(실현 기울기는 0.61처럼 2자리), 실현율·비중 소수 1자리, 배율 소수 1자리("2.6배", 표는 2자리), 정확도 소수 2자리, i 소수 3자리, 부호는 `formatSigned`(U+2212).
