# 유전체 분석실 운영 현황 — 명세

- slug: `genotyping-lab-ops` · category: `kpi` · 기준일: 2026-10-23
- 지표 기준: `.claude/skills/breeding-metrics/references/metrics-catalog.md` 4장(유전체 분석실·데이터 품질). 모든 값은 카탈로그 범위 안의 가상 목업이다.
- 연결 템플릿: `infographic/digital-breeding-process`(명세 `docs/specs/digital-breeding-process.md`), `kpi/program-overview`. 같은 가상 "중부 평야지 벼 육종 프로그램"의 분석실이다. 아래 「공유 수치」는 두 템플릿과 똑같아야 한다.

## 가정

- 작물: 벼(*Oryza sativa*, 12개 염색체, 약 430 Mb, 자식성).
- 사용자: 분석실 책임자. 주간 회의에서 처리 실적·품질·지연·재분석 현황을 점검하고 육종팀에 결과 제공 일정을 알려 준다.
- 사용 시나리오: 2026-10-23(목) 기준 연중 누계(2026-01-01~10-23) 화면. 10월은 진행 중인 달이다.
- 분석실은 육종 프로그램 전용(in-house) 분석실이며 플랫폼은 3개다.

| 플랫폼 | 용도 | 시료 | 마커 수 | 2026 누계 샘플 |
| --- | --- | --- | --- | --- |
| 6K SNP 칩(Illumina Infinium 계열) | 유전체 선발(GS) 후보 계통 유전형 분석 | F6 계통 잎 | 칩 6,000개, 마커 QC 후 사용 4,820개 | **2,000** |
| KASP 패널 | 유용 유전자 마커 보조 선발(MAS): 도열병(Pi9, Pita, Pib), 흰잎마름병(Xa21, xa5), 벼멸구(Bph18), 아밀로스(Wx) 등 | F2 개체 유묘 | 16개 | **8,366** |
| GBS(유전체 축소 표현 시퀀싱) | 교배 부모·훈련 집단 고밀도 보강 | 부모 계통 | 필터 후 약 50,000 SNP(추정) | **376** |

- **6K SNP 칩 수치는 인포그래픽 ③ 유전형 분석 단계와 같은 값이다.** 2026년 6K 캠페인(4~7월, 22개 플레이트)은 이미 끝났고, 연간 2,000샘플을 모두 처리했다.
- 플레이트: 모든 플랫폼에서 96웰 DNA 플레이트 1장 = 시료 94 + 대조 2(H11 양성 대조, H12 음성 대조(NTC)). 6K 마지막 플레이트 1장만 시료 26개다(21 × 94 + 26 = 2,000).
- 처리량은 **결과 제공일 기준의 신규 샘플 수**로 센다. 재분석 샘플은 처리량에 다시 넣지 않는다.
- 연 처리 목표 12,000샘플(월 1,000샘플 균등)이다. 카탈로그의 "소규모 1,000~5,000/월" 하한 수준인데, 단일 프로그램 전용 분석실이라 하한 쪽에 맞췄다.
- 계통·개체 ID는 가상이다(실존 품종명은 쓰지 않는다).

## 화면 목적과 핵심 질문

1. 올해 처리 실적이 목표를 따라가고 있는가? → 누계 10,742샘플, 진도 목표 대비 110.3%(연 목표 대비 89.5%). 다만 10월은 진도 76.0%로 늦다.
2. 데이터 품질은 기준을 넘는가? → 6K 평균 콜레이트 98.9%, 1차 QC 통과율 96.5%. 기준선(95%) 아래 샘플은 48개다.
3. 지금 손대야 할 실패·지연은 무엇인가? → KSP-2610-02 플레이트 실패율 14.9%(재분석 진행 중), GBS-2609-01 재시퀀싱 대기, KASP TAT가 4~6월에 목표(7일)를 넘었다. 6K TAT도 4월 15.0일·7월 14.4일로 목표(14일)를 조금 넘었지만 기간 평균은 14.0일로 목표 이내다(차트 표식만, 주의 사항 목록에는 넣지 않음).

## 목업 데이터 생성 규칙

- 시드: **20261023**. `createRng(SEED)` 인스턴스 하나를 아래 **순서대로** 쓴다(순서가 바뀌면 화면이 바뀐다).
- 모든 합계·비율·평균은 아래 상수와 생성 데이터에서 **계산**한다. KPI 숫자를 하드코딩하지 않는다.

```ts
export const SEED = 20261023
export const AS_OF = '2026-10-23'
export const ANNUAL_TARGET = 12000, MONTHLY_TARGET = 1000
export const PROGRESS_TARGET = 9 * 1000 + 1000 * 23 / 31          // 9,741.9 → 표시 9,742
export const CALL_RATE_THRESHOLD = 95, HET_THRESHOLD = 10, NONPARENT_THRESHOLD = 2
export const PLATE_ALERT_PCT = 10
export const TAT_TARGET = { '6K': 14, KASP: 7, GBS: 21 }
export const PLATFORMS = [
  { key: '6K',   name: '6K SNP 칩', markers: 6000, markersUsed: 4820 },
  { key: 'KASP', name: 'KASP 패널', markers: 16 },
  { key: 'GBS',  name: 'GBS',       markers: 50000 /* 필터 후 약, 추정 */ },
]
export const PREV_YEAR = { total: 9612, callRate6K: 98.7, qcPass6K: 95.9, tat6K: 16 }   // 2025-01-01~10-23 동기, 추정

// 월별 플레이트 수(「월별 확정 데이터」)
const KASP_PLATES = [10, 9, 12, 11, 9, 8, 7, 8, 9, 6]
const KASP_TAT_SUM = [66, 63, 82, 87, 75, 57, 42, 45, 53, 37]   // 합 607, 2월 63/9 = 7.0일(초과 아님)
const GBS = [ { month: 3, tat: 19, fail: 2 }, { month: 5, tat: 20, fail: 3 },
              { month: 7, tat: 18, fail: 2 }, { month: 9, tat: 22, fail: 4 } ]
const G6K = { 4: { tat: [16,15,15,14], fail: [2,3,1,2] },
              5: { tat: [15,14,14,13,14,13,14,15], fail: [3,2,17,1,2,3,2,1] },
              6: { tat: [13,13,14,12,14,13,14], fail: [2,4,1,3,2,2,3] },
              7: { tat: [15,14,14], fail: [7,5,2], size: [94,94,26] } }
```

1. **플레이트 목록**(115장 = 6K 22 + KASP 89 + GBS 4). ID 형식 `G6K-26MM-NN`, `KSP-26MM-NN`, `GBS-26MM-01`.
   - 결과일: 월 m에 플레이트 n장이면 k번째(0부터) 결과일 = `ceil((k + 1) × D / n)`일. D = 그 달 일수, 단 10월은 D = 23.
   - 접수일 = 결과일 − TAT.
   - KASP 플레이트 TAT: 월 n장, 합 S일이면 `base = floor(S / n)`, `extra = S − base × n`. `rng.shuffle`로 고른 extra장은 base + 1, 나머지는 base(월마다 순서대로 셔플 1회).
2. **6K 콜레이트**(2,000샘플): 「콜레이트 분포 확정 빈도」의 구간마다 개수만큼 `값 = 구간 중앙 + (rng.next() − 0.5) × 0.4`(±0.2, 구간 밖으로 나가지 않음), 소수 2자리. 2,000개 배열을 `rng.shuffle`한다.
   - 개발 중 단언: `round1(mean) === 98.9`, `count(<95) === 48`.
3. **6K 실패 샘플 배정**:
   - 95% 미만 48개 값을 오름차순으로 정렬하고, 가장 낮은 17개를 G6K-2605-03에 넣는다(원인 "콜레이트 미달 · DNA 농도 부족").
   - 나머지 실패 슬롯 53개(70 − 17, 플레이트 순서대로 펼침)에 `rng.shuffle([...31×'CR', ...14×'HET', ...8×'ID'])`를 차례로 배정한다. CR은 남은 31개 저콜레이트 값을 오름차순으로 받는다.
   - HET 샘플: 콜레이트는 95 이상 값 중 하나(셔플 배열 앞에서부터), 이형접합도 = `12 + rng.next() × 16`(12~28%).
   - ID 샘플: 콜레이트는 95 이상, 비부모 대립유전자 비율 = `3 + rng.next() × 6`(3~9%).
   - 정상 샘플 이형접합도 = `clamp(rng.normal(3.1, 1.2), 0.3, 8.5)`. 샘플 행 펼침용이며, 10% 이하라 실패가 생기지 않는다.
   - 웰: 플레이트마다 A01~H10 시료 웰 94개에서 `rng.shuffle` 후 앞에서부터 실패 수만큼.
   - 샘플 ID: 6K는 `YR24-0001` ~ `YR24-2000`(플레이트·웰 순서대로 부여).
4. **6K 재분석**(70샘플, 모두 완료·통과):
   - CR → 조치 "DNA 재추출 후 재분석", 완료일 = 결과일 + 7.
   - HET·ID → 조치 "잎 재채취 후 재분석", 완료일 = 결과일 + 21.
   - 재분석 콜레이트 = `97.5 + rng.next() × 2.1`(97.5~99.6). 이 값은 C 히스토그램(1차 분석)에 넣지 않는다.
5. **KASP 실패**(201샘플):
   - KSP-2610-02에 14개를 심는다(원인 "Pi9 마커 군집 분리 불량 · 프라이머 믹스 lot 문제", 상태 `진행 중`, 예정일 2026-10-27).
   - 나머지 187개는 다른 88장에 다항 배분한다: 실패 하나마다 `rng.int(0, 87)`로 플레이트를 고른다.
   - 원인: `rng.next() < 0.8` → "미호출 마커 2개 이상(DNA 품질)", 아니면 "형광 군집 불명확".
   - KASP 샘플 QC 기준: 16마커 중 미호출 1개 이하, 단 MAS 대상 유전자 마커(Pi9 등)가 하나라도 미호출이면 실패(각주에 명시). 샘플 행의 콜레이트 = 호출 마커/16. 일반 실패 샘플은 9/16~14/16, KSP-2610-02의 Pi9 단일 마커 실패 14샘플은 **15/16**(표기 "15/16(Pi9 미호출)"). RNG 소비 순서를 지키려고 Pi9 샘플도 호출 수를 뽑은 뒤 15로 덮어쓴다.
   - 샘플 ID 형식 `YR25-F2-0412-037`(조합 번호 `rng.int(1, 400)` 4자리, 개체 번호 `rng.int(1, 200)` 3자리).
   - 실패 수 > 9.4(= 10% × 94)인 플레이트가 KSP-2610-02 외에 생기면 시드가 바뀐 것이다. 개발 중 단언으로 막는다.
6. **KASP 재분석 상태**:
   - 결과일 ≤ 2026-09-30인 플레이트의 실패 샘플: `rng.next() < 0.55` → `재분석 통과`, 아니면 `폐기·대체 개체 사용`(F2 개체는 형제 개체로 대체하는 것이 현장 관행).
   - 10월 플레이트: 01 → 위와 같은 완료 규칙, 02 → `진행 중`(심은 14개), 03 → `진행 중`, 04·05 → `대기`, 06 → `대기`.
   - 예정일·완료일(명세에 없던 값, 빌더 결정을 확정): KASP 진행 중(02·03) 예정일 2026-10-27(`KASP_RERUN_DUE`), 대기 플레이트 예정일 = 다음 재분석 배치 2026-10-30(`NEXT_RERUN_BATCH`). 완료 KASP는 재분석 통과 = 결과일 + 7, 폐기·대체 = 결과일 + 3. KASP 재분석 콜레이트 15~16/16.
   - 이 추첨들은 1~7단계 RNG 순서 뒤에 실행해 앞 단계 결과를 바꾸지 않는다.
7. **GBS 실패**(11샘플):
   - 원인 "리드 수 부족(< 1M reads)" 또는 "결측률 > 20%"(`rng.next() < 0.5`).
   - 3·5·7월 플레이트는 `재분석 통과`(완료일 = 결과일 + 21). GBS-2609-01의 4개는 `재시퀀싱 대기`(예정일 2026-11-06, `GBS_RESEQ_DUE`). GBS 샘플 행 콜레이트 = 1 − 결측률.
   - 샘플 ID `P-001` ~ `P-376`.
8. **계산값**:
   - `QC_PASS[p] = samples[p] − fails[p]`, `qcPassPct = pass / samples × 100`.
   - `unresolved = count(status ∈ {대기, 진행 중, 재채취 요청, 재시퀀싱 대기})`. KPI ⑤의 N은 이 값(31)이고, M은 미해결 샘플이 있는 플레이트 수(6)다. `UNRESOLVED_BREAKDOWN` = 미해결 샘플을 (플랫폼, 상태, 예정일)로 묶은 개수. G 표 "미해결" 필터에서는 모든 플레이트를 자동으로 펼친다.
   - 월 TAT = Σ(시료 × TAT) / Σ시료(플랫폼별).
   - 상태 값 집합: `재분석 통과 | 폐기·대체 개체 사용 | 진행 중 | 대기 | 재채취 요청 | 재시퀀싱 대기`. 2026-10-23 기준 6K에는 미해결 상태가 없다.

## 상호작용

- **필터**: G 표 상단에 상태 칩(전체 / 미해결 / 완료)과 플랫폼 칩(전체 / 6K / KASP / GBS)을 둔다. 기본값은 "미해결"을 먼저 정렬한 전체 목록이다. 정렬 순서: 미해결 → 경보 → 결과일 내림차순.
- **B 막대 클릭**: G 표를 해당 월 결과일로 필터한다(해제 버튼 표시).
- **C 히스토그램**: 막대에 마우스를 올리면 툴팁 "95.0–95.5%: 10샘플(누적 0.5%)". 기준선 아래 구간을 클릭하면 G 표를 6K·콜레이트 미달로 필터한다. 로그 척도 토글을 둔다.
- **툴팁**: B는 월·플랫폼별 샘플·플레이트 수와 목표 대비 %, E는 월 평균 TAT·플레이트 수·목표, F는 샘플 수·비중·마커 수를 보여 준다.
- **상태**:
  - 로딩: 카드와 차트 자리에 스켈레톤을 둔다.
  - 빈 데이터: 필터 결과가 없으면 "조건에 맞는 실패 샘플이 없습니다"를 띄운다.
  - 오류: "데이터를 불러오지 못했습니다" 문구와 다시 시도 버튼을 둔다. 목업에서는 개발용 토글로 확인한다.
- **숫자 표기**:
  - 샘플 수는 천 단위 쉼표를 쓴다.
  - 백분율은 소수 1자리, 콜레이트는 소수 1자리로 표시한다(샘플 행은 2자리).
  - TAT 카드 값은 정수 일, 추이와 보조 값은 소수 1자리로 표시한다.
  - 날짜 형식은 YYYY-MM-DD다.
- **각주**:
  - "모든 수치는 가상 분석실의 목업 데이터입니다."
  - "처리량은 결과 제공일 기준 신규 샘플(재분석 제외)입니다."
  - "6K 콜레이트는 칩 전체 6,000마커 기준이며, 마커 QC 후 GEBV 계산에는 4,820마커를 씁니다."
  - "F6 이형접합도 기준 10%는 잔여 이형접합 기대값 3.1%를 감안한 혼입 판정 기준입니다."

## 수용 기준

- [ ] KPI의 6K 값이 인포그래픽과 같다: 분석 샘플 2,000, 평균 콜레이트 98.9%, 1차 QC 통과율 96.5%(1,930/2,000), TAT 14일. 이 값들은 생성 데이터에서 계산되어 나온다.
- [ ] C 히스토그램의 막대 합이 2,000이고, 95% 기준선 왼쪽 막대 합이 48이다. 이 48은 G 표의 6K "콜레이트 미달" 실패 수와 같고, 6K 실패 합계(48 + 14 + 8 = 70)는 2,000 − 1,930과 같다.
- [ ] B의 1~10월 누적 막대 합이 KPI 누계 10,742와 같다. 플랫폼별 합(2,000 / 8,366 / 376)은 F의 막대 값과 같고, 비중 18.6 / 77.9 / 3.5%의 합은 100.0%다.
- [ ] B에 월 목표선 1,000이 그려지고 y축이 0에서 시작한다. 10월은 "진행 중(10/23)"으로 구분된다. KPI의 진도 달성률은 10,742 / 9,742 = 110.3%다.
- [ ] E에서 6K 월 평균 TAT가 15.0, 14.0, 13.3, 14.4(4~7월)이고 샘플 가중 전체 평균이 14.0일이다. KASP 월 평균은 6.6, 7.0, 6.8, 7.9, 8.3, 7.1, 6.0, 5.6, 5.9, 6.2이고 전체 평균은 6.8일이다. 목표 초과 표식은 6K 4·7월, KASP 4·5·6월, GBS 9월에만 있다. 처리가 없는 달은 선이 끊기며 0으로 그려지지 않는다. 플랫폼별 목표선(14, 7, 21일)이 표시된다.
- [ ] TAT 카드의 전년 대비 감소(16 → 14일)는 개선으로 표시된다(▼ 기호 + 개선 색). 다른 카드의 증감도 기호와 색을 함께 쓴다.
- [ ] G 표에서 실패율이 10%를 넘는 플레이트는 2026년 중 G6K-2605-03(18.1%, 재분석 완료)과 KSP-2610-02(14.9%, 진행 중) 두 장뿐이다. 두 행 모두 "플레이트 경보"가 문자로 표시된다.
- [ ] KPI ⑤의 미해결 재분석 샘플 수(31)가 G 표 "미해결" 필터의 샘플 행 수와 같고, 타일의 상태별 분해(16 + 11 + 4) 합과도 같다. KSP-2610-02 실패 샘플은 모두 "15/16(Pi9 미호출)"로 표시된다. 6K 70샘플은 모두 "재분석 통과"이며 최종 확보 2,000/2,000으로 표시된다.
- [ ] 모든 값이 카탈로그 범위 안에 있다. QC 통과율은 92~98%(6K 96.5, KASP 97.6, GBS 97.1), 평균 콜레이트는 98~99.5%, 6K·GBS TAT는 7~21일이다. KASP TAT 6.8일이 하한 아래인 이유(16마커 소규모 패널)는 명세 지표 표에 적혀 있다.
- [ ] 용어가 첫 등장 시 한국어와 약어로 함께 표기된다(콜레이트(call rate), 처리 소요 시간(TAT), 마커 보조 선발(MAS) 등). 각주에 목업 고지, 처리량 산정 기준, 이형접합도 10% 기준 근거가 있다.
