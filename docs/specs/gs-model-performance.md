## 가정

- 작물: 벼(*Oryza sativa*, 12개 염색체, 약 430 Mb, 자식성). 가상 "중부 평야지 벼 육종 프로그램". **program-baseline 준수**.
- 사용자: 유전체 분석가(모델 비교·재학습 설계), 육종 관리자(정확도 목표 달성 여부, 훈련 집단 확대 투자 판단).
- 사용 시나리오: 2026-02 재학습한 운영 모델(GBLUP)과 대안 모델 3종을 같은 교차 검증 분할로 비교한 결과(벤치마크 실행 2026-10-15, 추정)를 보고 ① 지금 정확도가 목표에 닿았는지, ② 훈련 집단을 얼마나 늘려야 목표에 닿는지, ③ 다음 재학습(2027-02)에서 형질별로 어떤 모델을 쓸지 정한다.
- **program-baseline·program-overview와 같은 값**
  - 운영 모델 GBLUP, 훈련 집단 2026 **1,850계통**, 교차 검증 **5-fold × 10회(반복 50)**.
  - 쌀 수량 예측 정확도 r(연도별, program-overview `R`): 2022 0.46, 2023 0.50, 2024 0.53, 2025 0.55, **2026 0.57**. 목표(`R_T`): 0.45 / 0.50 / 0.52 / 0.55 / **0.58**.
  - 훈련 집단(`TRAIN_N`): 2022 620, 2023 950, 2024 1,280, 2025 1,560, 2026 1,850계통.
  - 형질별 GBLUP 정확도와 교차 검증 SD(program-overview `TRAITS`, 같은 순서·같은 이름): 쌀 수량 0.57 ± 0.04, 출수기 0.68 ± 0.03, 간장 0.65 ± 0.03, 천립중 0.61 ± 0.04, 도열병 저항성 0.47 ± 0.05, 밥맛(식미치) 0.38 ± 0.06. 반복값 생성도 program-overview와 같은 난수 소비 순서라 수량 GBLUP 반복값 범위(0.50~0.69)가 program-overview 툴팁과 같다.
  - 쌀 수량 계통평균 h² = 0.36(√h² = 0.60), 예측 능력 = 0.57 × 0.60 = 0.34(program-overview `SQRT_H2_LINE_MEAN`).
  - GS 모델 재학습은 매년 2월(program-baseline 2026 연간 일정). GS 도입 2022.
  - 마커: 6K SNP 칩 QC 후 4,820 SNP(program-baseline 유전체 분석실).
  - 유전자 위치: Hd1 Chr06 9.34 Mb, Pi9 Chr06 10.4 Mb, Pi-ta Chr12 10.6 Mb(program-baseline), Ghd7 Chr07 약 9.15 Mb(gwas-manhattan).
- program-overview는 수량 외 형질의 정확도를 2022~2026 모두 같은 값으로 둔다. 그래서 이 템플릿의 **연도별 추이는 쌀 수량만** 보여 준다(다른 형질의 연도별 값을 새로 만들면 program-overview와 어긋난다).
- **이 템플릿에서 새로 정하는 값(추정)**
  - 훈련 집단 계통평균 협의 유전력 h²(2026 REML, 추정): 쌀 수량 0.36(고정), 출수기 0.72, 간장 0.62, 천립중 0.55, 도열병 저항성 0.30, 밥맛(식미치) 0.18. gwas-manhattan의 h²(다양성 패널 412계통: 출수기 0.75, 간장 0.65, 천립중 0.70, 도열병 0.45)보다 모두 낮게 둔다. 엘리트 육종 계통은 다양성 패널보다 유전 분산이 작기 때문이다. 화면 부제에 "훈련 집단 1,850계통 기준"을 적어 패널 h²와 구분한다.
  - 대안 모델 BayesB, BayesCπ, RKHS의 GBLUP 대비 차이(카탈로그 "모델 간 차이 0.01~0.05" 안), 학습 곡선 계수, 전진 검증 정확도, 모델 학습 시간.
- 운영 모델은 2026년 현재 **모든 형질 GBLUP**이다(program-overview "GBLUP" 표기와 일치). 이 화면의 모델 교체는 "다음 재학습(2027-02) 권장"으로만 표시하고, 현재 운영 값을 바꾸지 않는다.
- 2027 재학습 훈련 집단 계획: 2,150계통(2026 작기 표현형 계통 +300, 추정).

"최대 Δr 대안"은 모델 순서(BayesB → BayesCπ → RKHS)에서 처음 나온 최댓값이다. 간장·천립중은 BayesB와 BayesCπ가 동률(+0.010)이라 BayesB로 표시하고 "(BayesCπ 동률)"을 덧붙인다. 둘 다 기준 미달이라 판정에는 영향이 없다.

근거 문장은 `data.ts`의 상수·계산값에서 아래 규칙으로 자동 생성한다(숫자를 문자열에 직접 쓰지 않는다).
- 교체 형질: `{유전 구조} — 큰 효과 마커를 덜 수축하는 {권장 모델}가 유리.` 뒤에, 기준을 충족한 다른 대안이 있으면 `{모델}도 {Δr} {CI}으로 기준 충족하나 {권장 모델}가 더 높음`(출수기·도열병 같은 문형).
- 유지 형질: 유전 구조 설명이 있고 CI 하한 > 0이면 `{유전 구조}. {모델} 우위는 통계적으로 유의하지만 실용 기준 0.02 미달`(쌀 수량). 그 밖에는 `실용 기준 0.02 미달`에 괄호로 동률 모델(`{모델} 동률 +0.010`)과, CI 하한이 0 초과 0.001 미만이면 `CI 하한이 0에 근접`을 붙인다(밥맛 CI 하한 0.00045). 4자리 표기 금지 규칙 때문에 하한 값을 숫자로 쓰지 않는다.
- 유전 구조 설명(`arch`)은 쌀 수량 "다유전자 형질", 출수기 "Hd1(Chr06)·Ghd7(Chr07) 주효 QTL", 도열병 저항성 "Pi9(Chr06)·Pi-ta(Chr12) 주동 저항성 유전자"에만 둔다.

## 목업 데이터 생성 규칙

- 시드: 20261023 (`createRng(SEED)` 하나를 아래 순서로만 소비한다)
- 상수(위 표 그대로): `TRAITS`(program-overview와 같은 순서·이름·mean·sd, 수량 mean = `R[2026]` 0.57) + `h2`, `MODELS = ['GBLUP','BayesB','BayesCπ','RKHS']`, `SD_ADD = {GBLUP:0, BayesB:0.005, BayesCπ:0.005, RKHS:0}`, `DELTA`(아래), `R`, `R_T`, `TRAIN_N`(program-overview와 같음), `FORWARD = {2022:0.40, 2023:0.43, 2024:0.47, 2025:0.48}`, `ME = 250`, `RHO = 0.85`, `CV_REPS = 50`, `N_TRAIN = 1850`, `N_PLAN_2027 = 2150`, `PRACTICAL_DELTA = 0.02`, `T975_DF49 = 2.0096`, `FIT_MIN = {GBLUP:0.4, BayesB:38, 'BayesCπ':35, RKHS:1.2}`.

```
DELTA (GBLUP 대비, N = 1,850)
           BayesB  BayesCπ  RKHS
yield      -0.01    0.00    +0.01
heading    +0.03   +0.02     0.00
height     +0.01   +0.01     0.00
tgw        +0.01   +0.01     0.00
blast      +0.04   +0.03    -0.01
taste      -0.01    0.00    +0.01
```

```
standardize(xs) = (xs - mean(xs)) / sd(xs)        // 표본 SD(n-1)
rng = createRng(20261023)

// 1) GBLUP 표준화 점수 — program-overview data.ts의 Z와 같은 소비 순서
for t in TRAITS:                                   // yield, heading, height, tgw, blast, taste
  Z.GBLUP[t] = standardize([rng.normal(0,1) × 50])

// 2) 대안 모델 — 같은 rng를 이어서, 모델 순서 × 형질 순서
for m in [BayesB, BayesCπ, RKHS]:
  for t in TRAITS:
    e = standardize([rng.normal(0,1) × 50])
    Z[m][t] = standardize(RHO·Z.GBLUP[t] + √(1−RHO²)·e)   // 같은 분할의 쌍체 반복(상관 0.85)

// 3) 반복값·요약
mu[t][m]  = t.mean + (m == GBLUP ? 0 : DELTA[t][m])
sd[t][m]  = t.sd + SD_ADD[m]
folds[t][m][k] = clamp(mu + sd·Z[m][t][k], 0, 1)          // 실행 결과 clamp 발동 없음(0.195~0.794)
mean·SD는 표준화 때문에 정확히 mu·sd가 된다
predAbility[t][m] = mu[t][m] · √h²[t]

// 4) 쌍체 차이와 권장
for t, m≠GBLUP: d_k = folds[t][m][k] − folds[t][GBLUP][k]
  Δ = mean(d), half = 2.0096·sd(d)/√50, ok = Δ ≥ 0.02 − 1e-9 && (Δ − half) > 0
rec[t] = ok인 m 중 Δ 최대(동률이면 모델 순서상 앞), 없으면 GBLUP

// 5) 학습 곡선(결정적, 난수 없음)
g(N, h2) = √(N·h2 / (N·h2 + 250))
a[t] = t.mean / g(1850, h2[t])
curve(t, m, N) = a[t]·g(N, h2[t]) + (m == GBLUP ? 0 : DELTA[t][m])·√(N/1850)
curveSd(t, m, N) = (t.sd + SD_ADD[m])·(1850/N)^0.25       // 작은 N일수록 검증 fold가 작아 SD 증가
GRID = [300, 600, 900, 1200, 1500, 1850], EXTRA = [2150, 2500](GBLUP만, 점선)
N* = curve(yield, GBLUP, N) = 0.58을 이분법으로 푼 값(1850~100000)

// 6) h²–r 회귀(GBLUP 6점 OLS): slope, intercept, R², 잔차

// 7) KPI: R[2026], R_T[2026], 달성률 = R/R_T·100, R[2026]−R[2025], TRAIN_N 차, mean(GBLUP 6형질),
//    교체 권장 수 = count(rec ≠ GBLUP), FORWARD[2025], R[2025]−FORWARD[2025], FORWARD[2025]/R[2025]
```

- DEV 검산(`console.assert` + `[검산]` 태그): ① 수량 GBLUP mean = R[2026], ② 모든 folds ∈ [0,1], ③ 권장 결과 = {heading: BayesB, blast: BayesB, 나머지 GBLUP}, ④ N* ∈ [2,100, 2,130], ⑤ 연도별 |R[y] − curve(yield, GBLUP, TRAIN_N[y])| ≤ 0.01, ⑥ 모든 predAbility ≤ √h², ⑦ 수량 GBLUP 반복 범위 0.49628~0.68901, ⑧ h²–r 회귀 slope 0.529·intercept 0.319.

## 상호작용

- 상단 필터: **형질 선택**(기본 "쌀 수량") — C 학습 곡선의 형질, A의 해당 형질 묶음 배경 강조, E의 점 강조, B의 해당 카드 강조. 지표 토글 **예측 정확도 r / 예측 능력 r·√h²**(기본 정확도) — A에만 적용(y축은 0~1 유지). 모델 범례 클릭으로 A·C에서 모델 숨기기(최소 1개 남김).
- 툴팁
  - A: 형질 단위(axis 트리거)로 띄우고 머리줄에 형질명·h²·반복 50회, 그 아래 표시 중인 모델마다 r ± SD(SD 3자리), 반복 범위(최소~최대), 예측 능력, GBLUP 대비 Δr, "★ 권장" 여부.
  - C: N, 모델별 r ± SD, N > 1,850이면 "외삽(추정)". 쌀 수량 연도별 점은 "2024-02 재학습 운영 모델 · N 1,280 · r 0.53".
  - D: 연도, 재학습 월, 훈련 집단, CV r, 목표, 달성률, 전진 검증(있으면), CV − 전진.
  - E: 형질, h², r, 예측 능력, 회귀 예측값, 잔차.
- 상태: 로딩(스켈레톤, `data-chart-ready` 계약), 빈 데이터(모든 모델 숨김 불가 — 마지막 모델 범례는 비활성), 오류(차트 영역별 "벤치마크 결과를 불러오지 못했습니다" + 다시 시도 버튼).
- 접근성: A·C·D·E 각각 sr-only 표(형질 × 모델 평균·SD, 학습 곡선 점, 연도별 표, h²–r 표).

## 수용 기준

- [ ] KPI ①이 쌀 수량 GBLUP 예측 정확도 0.57, 목표 0.58, 달성률 98.3%(주의 상태), 전년 대비 ▲0.02를 표시하고, 같은 값이 A의 쌀 수량 GBLUP 막대·D의 2026 점과 일치한다(program-overview KPI와 같음).
- [ ] A가 형질 6 × 모델 4 = 24개 막대를 y축 0~1로 그리고 모든 막대에 ±SD 오차 막대가 있으며, 쌀 수량 GBLUP 툴팁의 반복 범위가 0.50~0.69다.
- [ ] 지표 토글을 예측 능력으로 바꾸면 쌀 수량 GBLUP 막대가 0.34(= 0.57 × 0.60)가 되고, 모든 막대가 해당 형질의 √h² 이하다.
- [ ] B와 KPI ④가 같은 판정을 보인다: 교체 권장 2/6(출수기 BayesB +0.030 [0.025, 0.035], 도열병 저항성 BayesB +0.040 [0.031, 0.049]), 나머지 4형질 GBLUP 유지. 쌀 수량은 RKHS +0.010이 실용 기준 0.02 미달이라 유지로 표시된다.
- [ ] 기본 상태(쌀 수량) C에서 GBLUP 곡선이 N = 1,850에서 0.57을 지나고, 목표선 0.58과 "목표 도달 약 2,115계통", 2027 계획 2,150의 예상 r 0.58이 표시되며, 1,850 초과 구간은 점선(외삽)이다.
