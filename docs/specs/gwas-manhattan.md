# GWAS 결과 뷰어 — 명세

- slug: `gwas-manhattan` / category: `viz` / 기준일: 2026-10-23
- 기준 문서: `breeding-metrics` 스킬(metrics-catalog §5, organisms 벼 염색체 길이, visualization-guide GWAS·QQ 행, glossary-ko)

## 가정

- **작물**: 벼(*Oryza sativa*), 12개 염색체, 게놈 약 430 Mb. 맨해튼 x축은 IRGSP-1.0 근사 길이(합계 373.0 Mb)를 쓴다(`ORGANISMS.rice`).
- **사용자**: 유전체 분석가(GWAS를 직접 돌리고 결과를 해석·보고하는 사람).
- **사용 시나리오**: 가상의 "YR 다양성 패널" 412계통을 2025년 시험포장에서 표현형 조사하고, 36,420개 SNP로 형질 4개에 대해 GWAS를 수행했다. 분석가는 형질을 바꿔 가며 (1) 유의 좌위가 어디 있는지, (2) 집단 구조 보정이 적절했는지(λGC, QQ), (3) 리드 SNP의 효과와 후보 유전자를 확인한다.
- **분석 조건(화면 상단 메타 줄에 표기)**: 412계통 · 36,420 SNP(MAF ≥ 0.05, 마커 콜레이트 ≥ 90% 필터 후) · 혼합선형모형(MLM, 주성분 3개 + GRM) · 표현형 2025년 · 분석일 2026-10-20.
- **유전형 부호화**: 벼 근교계 패널이므로 이형접합을 결측 처리하고 x ∈ {0, 1}(주 대립유전자 동형 / 소수 대립유전자 동형)로 둔다. 따라서 Var(x) = MAF·(1−MAF).
- **후보 유전자**: 실존 벼 유전자 기호(sd1, Hd1, GS3 등)를 쓴다. 유전자는 공개 과학 지식이라 써도 되지만, 유전자 위치는 RAP-DB/IRGSP-1.0 기준으로 **추정한 근사값**이다(웹 검증 안 함). 계통·패널 이름은 모두 가상이다. 실존 품종명은 쓰지 않는다.
- **전장 유전체 유의선 기본값**: 본페로니 0.05/M(M = 36,420 → −log10 = 5.86). 화면에서 관례 기준 5×10⁻⁸(7.30)로 바꿀 수 있다.
- **λGC 계산 범위**: 형질별 본페로니 유의 리드 SNP의 ±1 Mb 안 SNP(알려진 연관 구간)를 빼고 계산한다. 화면에 제외 기준("피크 ±1 Mb 제외, n=…")을 표기한다. QQ 플롯은 전체 SNP를 그린다(program-baseline, 2026-10-23 사용자 결정).

## 화면 목적과 핵심 질문

1. 선택한 형질에서 전장 유전체 유의선을 넘는 좌위가 몇 개이고, 어느 염색체 어디에 있는가?
2. 집단 구조 보정이 적절한가? (λGC가 0.95~1.10이고, QQ 플롯이 피크를 빼면 대각선을 따르는가)
3. 각 리드 SNP의 p값, MAF, 효과(β), 설명 분산(PVE), 근처 후보 유전자는 무엇인가?

### 형질 정의(형질 선택 목록)

`목표 λ`는 귀무 z의 분산(생성 파라미터)이다. 화면 λ는 아래 규칙으로 계산한 값만 쓴다(목표와 같지 않다).

| key | 화면 표기 | 단위 | 평균 | σP | h²(참고) | 목표 λ | 효과 방향 설명 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| `dth` | 출수기(파종 후 일수) | 일 | 112 | 7.5 | 0.75 | 1.04 | +는 출수 지연 |
| `cl` | 간장 | cm | 92 | 11.0 | 0.65 | 1.02 | −는 단간 |
| `tgw` | 천립중 | g | 23.8 | 2.1 | 0.70 | 0.99 | +는 무거운 낟알 |
| `blast` | 도열병 저항성(병반 점수 0~9) | 점 | 4.6 | 2.0 | 0.45 | **1.04**(2026-10-26 정리 회차, 이전 1.08) | −는 저항성(점수 낮을수록 강함) |

도열병 점수는 낮을수록 좋다. β 열에 툴팁 "음수 = 저항성 증가"를 단다.

### 심을 피크(리드 SNP) — 계산 완료 값

PVE는 N = 412에서 χ²(1) = N·PVE/(1−PVE)가 표의 −log10(p)와 맞도록 역산했고, |β| = σP·√(PVE / (MAF(1−MAF)))로 구했다. 빌더는 이 값을 그대로 쓴다. **MAF는 ld-decay·haplotype-viewer 목업 유전형에서 리드 SNP의 실현 빈도(412계통)를 소수 2자리로 반올림한 값이다**(2026-10-27 정리 회차 3, 실현값과 차 ≤ 0.005). β는 새 MAF로 다시 계산해 C3·G2·B1·B2 네 행만 0.1씩 바뀌었고 −log10(p)·PVE는 그대로다.

유의 판정 미리 보기(빌더·검토자 확인용):
- 본페로니 5.86 기준: H1·H2·H3·H4 유의(H4 6.2 ≥ 5.86) / C1·C2·C3 유의 / G1·G2·G3 유의 / B1·B2·B3 유의. 제안 좌위는 4형질 모두 0.

## 목업 데이터 생성 규칙

- 시드: **20261023**. 패널은 `createRng(20261023)`, 형질 k(0=dth, 1=cl, 2=tgw, 3=blast)의 p값은 `createRng(20261023 + k + 1 + P_SEED_OFFSET[key])`, `P_SEED_OFFSET = { dth: 10, cl: 0, tgw: 0, blast: 0 }`. 출수기 오프셋 +10은 오프셋 0에서 귀무 SNP S6_460967(Chr06 0.46 Mb)이 −log10 p = 6.66으로 본페로니 유의선을 넘었기 때문이다(+10에서 귀무 최대 4.80, S1_4379252). 숫자를 손으로 고치지 않고 시드만 바꿨다.
- 파일: `src/templates/viz/gwas-manhattan/data.ts`. `simulateGwas`는 λ와 피크 리드 위치를 정확히 제어할 수 없고, 반환하는 λ가 피크 덮어쓰기 전 χ²로 계산되므로 쓰지 않는다. 대신 아래 생성기를 템플릿 안에서 구현한다. `ORGANISMS.rice`, `createRng`, `formatPValue`는 재사용한다.

### 1) SNP 패널(모든 형질 공통: 위치·MAF가 형질마다 같아야 한다)

```
SEED = 20261023; M = 36420; N = 412
chrs = ORGANISMS.rice.chromosomes            // 합계 373.0 Mb
GAP = 373.0 * 0.01                            // 염색체 사이 간격 3.73 Mb
PLANTED = 위 피크 표 13개 (chr, bp, maf, trait, ...)
rng = createRng(SEED)

// 염색체별 SNP 수: 길이 비례, 합이 정확히 M이 되도록 마지막 염색체에서 보정
n[c] = round(M * len[c] / 373.0);  n[Chr12] += M - sum(n)

offset = 0
for c in chrs:
  planted_c = PLANTED.filter(p => p.chr == c.id)
  k = n[c] - planted_c.length                 // 심은 리드 SNP도 M에 포함
  positions = k개의 round(rng.next() * len[c] * 1e6) (bp), 정렬, 중복 제거 후 부족분 재추첨
  for bp in positions:
    maf = 0.05 + 0.45 * rng.beta(0.8, 1.6)    // 낮은 MAF 쪽으로 치우침
    push {id:`S${chrNum}_${bp}`, chr:c.id, bp, posMb:bp/1e6, cumPos:offset+bp/1e6, maf:round3(maf)}
  for p in planted_c:
    push {id:`S${chrNum}_${p.bp}`, chr:c.id, bp:p.bp, posMb, cumPos, maf:p.maf, plantedId:p.id}
  sort by bp
  chrOffsets.push({chr:c.id, start:offset, end:offset+len[c], mid:offset+len[c]/2})
  offset += len[c] + GAP
```

### 2) 형질별 p값

```
TAU = 0.15   // Mb, LD 신호 감소 상수
for trait k:
  r = createRng(SEED + k + 1 + P_SEED_OFFSET[TRAITS[k].key])   // dth +10
  lambdaT = TRAITS[k].lambda                  // 1.04 / 1.02 / 0.99 / 1.04 (blast 1.08 → 1.04, 정리 회차)
  peaks = PLANTED.filter(p => p.trait == TRAITS[k].key)
  for snp in panel (패널 순서대로):
    z = r.normal(0, sqrt(lambdaT))
    logP = logPFromZ(z); chi2 = z*z
    for pk in peaks with pk.chr == snp.chr:
      if snp.plantedId == pk.id: logP = pk.logP; chi2 = pk.chi2; continue
      d = |snp.posMb - pk.bp/1e6|
      if d < 1.0:
        s = pk.logP * exp(-d / TAU) * (0.60 + 0.35 * r.next())   // 최대 0.95배 → 리드가 항상 최댓값
        if s > logP: logP = s; chi2 = chi2FromLogP(s)
    // 다른 형질의 심은 SNP(plantedId가 다른 형질)는 이 형질에선 귀무 SNP로 취급
    store logP(소수 3자리), chi2
```

보조 함수:
- `logPFromZ(z)`: |z| < 4이면 −log10(2·(1 − Φ(|z|)))(라이브러리 A–S 근사 사용 가능). |z| ≥ 4이면 A–S 근사의 절대오차(1.5×10⁻⁷) 때문에 꼬리 근사를 쓴다: ln p = −z²/2 − 0.2258 − ln z + ln(1 − 1/z² + 3/z⁴), logP = −ln p / ln 10.
- `chi2FromLogP(L)`: 위 꼬리 식을 z에 대해 이분법(z ∈ [0.5, 15], 40회)으로 풀고 χ² = z². L < 1.5면 정확도가 떨어지므로 그 구간에선 쓸 일이 없다(리드 SNP는 모두 ≥ 5).
- 심은 피크의 χ²(검산용): H1 72.6, H2 52.7, H3 36.9, H4 24.8, C1 98.6, C2 31.1, C3 28.4, G1 79.4, G2 47.2, G3 25.7, B1 62.6, B2 40.5, B3 30.2.
- `Φ⁻¹`(λ 계산용)은 `genomics.ts`에서 export되지 않는다. data.ts에 Acklam 근사를 두거나, λ 계산에는 p_med가 0.4~0.6 근처라서 정밀도 문제가 없다.

### 3) 파생 값(형질·유의 기준이 바뀔 때마다 다시 계산)

```
sigLine = (기준 == 'bonferroni') ? -log10(0.05 / M) : -log10(5e-8)   // 5.862 / 7.301
sugLine = 5

// λGC: 표시한 값으로 계산(목표값 lambdaT를 그대로 쓰지 않는다)
// 알려진 연관 구간 제외: 본페로니(5.862) 이상 리드 SNP(clumping 후)의 ±1 Mb(LAMBDA_EXCLUDE_BP = 1_000_000) 안 SNP를 뺀다.
// 유의 기준 Segmented를 바꿔도 제외 집합은 본페로니 기준으로 고정.
exPeaks = leads.filter(l => l.logP >= 5.862)
lambdaInput = logP of SNP s where !exPeaks.some(l => l.chr == s.chr && |l.bp - s.bp| <= 1_000_000)
lambda = lambdaGC(lambdaInput)      // 화면 값, 소수 2자리 표시
lambdaAll = lambdaGC(logP)          // 툴팁 참고값
// 상태 판정은 소수 2자리로 반올림한 값으로: round2(λ) > 1.10 경고, < 0.95 과보정

sigSnpCount = count(logP >= sigLine)

// clumping
cand = SNP where logP >= sugLine, logP 내림차순
leads = []
while cand not empty:
  top = cand.shift(); leads.push(top)
  cand = cand.filter(s => !(s.chr == top.chr && |s.bp - top.bp| <= 500_000))
lead.status = logP >= sigLine ? '유의' : '제안'
lead.pve  = chi2 / (N + chi2)
lead.beta = sign * σP * sqrt(pve / (maf * (1 - maf)))     // 심은 SNP는 표의 β를 그대로. 그 외는 sign = (bp % 2 == 0) ? +1 : -1 (RNG를 소비하지 않아 결정적)
lead.qtl  = [posMb - 0.2, posMb + 0.2] (염색체 경계로 자름)
lead.gene = 리드에서 500 kb 안에 같은 형질의 심은 피크가 있으면 그 유전자와 거리(|bp - geneBp|/1000, kb 반올림), 없으면 '—'
sigLociCount = leads.filter(유의).length
```

### 4) QQ 플롯 데이터

```
obs = logP 내림차순 정렬
exp_i = -log10((i - 0.5) / M), i = 1..M
점 솎아내기: exp_i < 2 구간은 20개마다 1개만 남김(상위 약 364개 점은 모두 유지). 시각적으로 같고 렌더가 가볍다.
95% 신뢰 띠: 순위 i의 p(i) ~ Beta(i, M−i+1) ≈ Gamma(i,1)/M
  i = 1: q_lo = -ln(0.975), q_hi = -ln(0.025)           // 지수분포 정확값
  i ≥ 2: Wilson–Hilferty  q_α = i·(1 − 1/(9i) + z_α/(3√i))³,  z_0.025 = −1.96, z_0.975 = +1.96
  band_upper(exp_i) = -log10(q_lo / M), band_lower(exp_i) = -log10(q_hi / M)
  i는 1..M에서 로그 간격 약 200개만 계산해 area로 그린다.
```

## 상호작용

- **형질 선택**(`Select`, 기본 `dth`): 맨해튼·QQ·KPI·표가 함께 바뀐다. 확대 상태였다면 같은 염색체 확대를 유지한다.
- **유의 기준 전환**(`Segmented`): 유의선 위치·라벨, 유의 SNP 수, 유의 좌위 수, 표의 상태 배지, 맨해튼 라벨 대상이 함께 바뀐다. 제안선은 그대로.
- **염색체 확대**: 맨해튼에서 점을 클릭하면 그 점의 염색체로 확대한다(빈 공간 클릭은 선택 사항이며 현재 구현에는 없다 — 공통 `EChart`가 인스턴스를 노출하지 않음). 표 행 클릭도 해당 염색체로 확대하고 그 리드 SNP를 강조한다. "전체 유전체로" 버튼과 `Esc` 키로 복귀. 확대 상태는 차트 카드 제목에 "Chr06 확대"로 표시.
- **툴팁**(맨해튼): SNP ID, `Chr06:9,310,452`, p값(3.2×10⁻⁹ 형식), −log10(p) 소수 2자리, MAF 소수 2자리. 리드 SNP면 후보 유전자 추가. QQ 툴팁: 기대·관측 −log10(p), SNP ID.
- **키보드·접근성**: `EChart`의 `aria-label`에 "출수기 맨해튼 플롯, 36,420 SNP, 유의 좌위 4개(Chr06 Hd1, Chr07 Ghd7, Chr08 DTH8, Chr03 Hd6), 유의선 5.86"처럼 요약을 넣는다. `fallbackTable`은 리드 SNP 표로 충분하다(3만 행을 넣지 않는다).
- **상태**: 데이터 생성 중 `Skeleton`(KPI·차트·표). 제안선을 넘는 SNP가 없으면 표에 `emptyText` "제안선(−log10 p = 5)을 넘는 SNP가 없습니다", 맨해튼에는 라벨 없이 표시. 데이터 오류 시 `ErrorState`. 현재 목업 4형질은 모두 결과가 있으므로 빈 상태는 코드 경로로만 존재한다.
- **성능**: 형질별 결과는 `useMemo`로 형질 key 단위 캐시. 맨해튼 시리즈는 `large: true`, `largeThreshold` 기본값, `progressive: 0`(점진 렌더를 끄지 않으면 스크린샷에 일부 염색체만 그려진다), 캔버스 렌더러.

## 수용 기준

- [ ] 맨해튼 x축에 Chr01~Chr12가 IRGSP-1.0 근사 길이에 비례해 누적 배치되고(Chr01이 가장 넓음), 인접 염색체는 두 색이 번갈아 나온다(12색 무지개가 아니다).
- [ ] 유의선이 본페로니 기준에서 −log10(p) = 5.86(0.05/36,420)으로, 5×10⁻⁸ 기준에서 7.30으로 그려지고 라벨에 값과 기준이 적혀 있다. 제안선 5.00은 점선으로 항상 표시된다.
- [ ] KPI "유의 SNP 수"는 맨해튼에서 유의선 이상인 점의 수와 같고, KPI "유의 좌위 수"는 피크 SNP 표의 "유의" 행 수와 같다. 유의 기준을 바꾸면 둘 다 함께 바뀐다(예: 출수기 4 → 3, 간장 3 → 2 좌위).
- [ ] λGC는 본페로니 유의 리드 SNP ±1 Mb 안 SNP를 뺀 p값의 중앙값으로 계산한 값이며, 소수 2자리로 KPI와 QQ 플롯에 같은 숫자(출수기 1.03, 간장 1.02, 천립중 0.99, 도열병 1.06)로 표기되고 제외 기준("피크 ±1 Mb 제외, n=…")이 함께 보인다. 4형질 모두 "정상" 배지가 붙는다.
- [ ] QQ 플롯(전체 SNP)에 y = x 대각선과 95% 신뢰 띠가 있고, 기대 −log10(p) < 2 구간의 점은 대각선·띠를 따르며(띠 상한 초과는 최대 0.08~0.24로 화면에서 띠에 붙어 보임 — 전체 SNP λ > 1의 완만한 팽창), 기대 약 2.4 이상에서 LD 이웃·피크 SNP가 위로 벗어난다. QQ aria 문구도 "2 미만"을 쓴다.
- [ ] 피크 SNP 표는 ±500 kb clumping으로 고른 리드 SNP만 보여 주며, 각 행에 염색체·위치(bp)·p값(a.b×10⁻ⁿ 형식)·MAF(0.05~0.50)·효과 β(형질 단위와 부호)·PVE·후보 유전자가 있다. 심은 피크 행의 값은 명세 피크 표(예: 출수기 Hd1 행 p = 1.6×10⁻¹⁷, MAF 0.30, β +6.3일, PVE 15.0%; 도열병 Pi-ta 행 MAF 0.21, β −1.8점, PVE 13.2%)와 같다.
- [ ] 모든 표 행에서 PVE ≈ MAF·(1−MAF)·β²/σP²가 반올림 오차(±0.5%p) 안에서 성립하고, PVE는 모두 25% 이하다.
- [ ] 형질을 바꾸면 맨해튼·QQ·KPI·표가 모두 갱신되며, 같은 SNP ID의 위치와 MAF는 형질이 달라도 같다(같은 유전형 패널).
- [ ] 맨해튼의 점이나 표 행을 클릭하면 해당 염색체 확대 뷰(x축 "ChrNN 위치(Mb)")로 바뀌고, 유의선·제안선과 리드 SNP의 QTL 구간(±200 kb) 음영이 보이며, "전체 유전체로" 버튼으로 돌아온다.
- [ ] 같은 시드(20261023)로 다시 렌더하면 같은 화면이 나오고, 분석 SNP 수는 정확히 36,420, 계통 수는 412로 표시된다. 화면 어디에도 실존 품종명이 없다.
