## 가정

- **작물**: 벼(*Oryza sativa*), 12개 염색체, 게놈 약 430 Mb. 좌표는 IRGSP-1.0 근사(`ORGANISMS.rice`).
- **program-baseline 준수**: YR 다양성 패널 412계통, 36,420 SNP(MAF ≥ 0.05, 마커 콜레이트 ≥ 90%), 분석일 2026-10-20. 하위 집단 온대 자포니카(TEJ) 176 · 열대 자포니카(TRJ) 54 · 인디카(IND) 112 · 아우스(AUS) 30 · 혼합형(ADM) 40(population-structure의 K = 4, 최대 Q ≥ 0.70 소속, 계통 ID까지 같다). 유전자 위치 sd1 Chr01 38.4, Hd1 Chr06 9.34, Pi9 Chr06 10.4, Pi-ta Chr12 10.6, GS3 Chr03 16.7 Mb. 리드 SNP·−log10 p·β·PVE는 gwas-manhattan「심을 피크」표, LD 블록·리드 블록·프록시는 ld-decay(패널 전체 기준)와 같다. 부모 후보 60계통(ID·그룹·가계·수량 GEBV·출수기·간장·도열병 저항성 유전자 기록)은 cross-planner `CANDIDATES`와 같다.
- **사용자**: 유전체 분석가(구간의 하플로타입 구조 확인), 육종가(교배 부모가 유리 대립유전자를 갖는지 확인).
- **사용 시나리오**: gwas-manhattan에서 유의 좌위를, ld-decay에서 블록을 확인한 뒤 이 화면에서 (1) 리드 블록의 하플로타입이 몇 개이고 하위 집단마다 빈도가 어떤지, (2) 효과 대립유전자가 어느 하플로타입에 실리는지, (3) 부모 후보·출원 후보·대비 품종이 어떤 하플로타입을 갖는지 본다. 결과는 2027년 1차 교배 계획(cross-planner)의 부모 조합 판단에 쓴다.
- **유전형 부호화**: 근교계라 SNP는 0/1 동형 유전형이고 이형접합은 결측 처리한다(gwas-manhattan·ld-decay와 같음). 화면은 0/1 대신 "주 대립유전자 / 소수 대립유전자"(패널 412계통 관측 빈도 기준)로 표기한다. 염기(A/C/G/T)는 표시하지 않는다(gwas-manhattan도 표시하지 않음).
- **좌위 5개와 표적 대립유전자**: 모든 좌위에서 리드 SNP의 **소수 대립유전자**가 GWAS β의 대상(β = 소수 동형 − 주 동형 평균 차)이다. 좌위를 두 종류로 나눈다.
  - **유리형**(sd1, Pi-ta, Pi9): 소수 대립유전자가 육종 목표 방향(간장 감소, 도열병 병반 점수 감소)이라 "유리 대립유전자"라 부르고 보유 수를 센다. variety-profile의 "저항성·반왜성 유전자" 보유 개념과 같다.
  - **방향 선택형**(Hd1, GS3): 출수기·천립중은 variety-profile에서도 `dir: 'neutral'`(목표 범위형)이다. 소수 대립유전자를 "출수 지연형(+6.3일)", "천립중 증가형(+1.9 g)"이라는 **효과 대립유전자**로만 표시하고 유리 판정·보유 수에 넣지 않는다. Hd1 블록에는 간장 리드 C2(S6_9291038, β +6.4 cm)도 같은 하플로타입(H2)으로 실린다. GS3 천립중 증가형은 장립화와 연관될 수 있어 자포니카 단원립 품질 기준과 함께 판단한다(각주, 일반 지식). **GS3 하위 집단 분포**(2026-10-27 정리 회차 3): 실제 GS3 장립·대립형(C165A 기능 상실, GS3A)은 인디카에 많고 온대 자포니카는 주로 GS3C(단원립)를 갖는다(Takano-Kai et al. 2009 Genetics, https://pmc.ncbi.nlm.nih.gov/articles/PMC2728869/ ; Fan et al. 2009 TAG, https://doi.org/10.1007/s00122-008-0913-1 — 도메인 검토 r0 근거, 원문 재확인 안 함). 공유 생성 규칙(ld-decay GS3 창의 인디카 편향 리드 마스크 `LEAD_BIAS`)으로 이 목업의 GS3 표적 하플로타입(H2·H3)도 인디카 50.9%(57/112) · 온대 자포니카 12.5%(22/176)로 인디카에 많다. 온대 자포니카의 소수 보유 계통에 늘솔찬·별하랑(천립중 증가형, 별하랑 천립중 23.1 g > 가람솔 22.0 g)이 들어간다. 효과 카드 GS3 각주는 "알려진 한계"가 아니라 이 분포 사실을 쓴다.
- **육종 계통 67**: 부모 후보 60(cross-planner) + 출원 후보 3(met-gxe-stability: YR19-0118, YR20-0342, YR20-0527) + 대비 품종 2(가람솔 YR07-0231, 온새미로 YR13-0819) + 참고 품종 2(별하랑 YR19-0083, 늘솔찬 YR14-0472). 이 가운데 6계통(YR20-1108, YR19-0731, 가람솔, 온새미로, 별하랑, 늘솔찬)은 다양성 패널 구성원이라 패널 유전형을 그대로 쓴다. 나머지 61계통은 "6K SNP 칩(4,820 SNP) 유전형을 YR 다양성 패널 412계통 참조로 임퓨테이션한 값(추정)"이라 결측이 없다. 부모 후보 60계통의 GBS(GBS-2611-01)는 11/06 분석 예정(program-baseline)이라 아직 쓰지 않는다.
- **GEBV**: 부모 후보는 cross-planner 수량 GEBV, 대비·참고 품종은 pedigree-explorer 2026-10 GBLUP 재추정값(가람솔 −2.4, 온새미로 +11.6, 별하랑 +36.4, 늘솔찬 −8.9, "표현형 포함"), 출원 후보 3계통은 기준값이 없어 "—"(대신 MET 수량 지수 106.6 / 104.8 / 103.5%를 비고에 표시). 다양성 패널 412계통은 훈련 집단 밖이라 GEBV가 없다(GEBV 정렬 비활성).
- **다른 템플릿을 import하지 않는다**: ld-decay·population-structure·cross-planner 코드는 아래 「목업 데이터 생성 규칙」대로 **복사**한다.
- **사실 확인**: 유전자 이름·기능(sd1 반왜성, Hd1 출수, GS3 낟알 크기, Pi-ta·Pi9 도열병 저항성, Pigm이 Pi2/Pi9와 같은 Chr06 좌위의 다른 대립유전자군이라는 점)은 일반 지식이고 이번에 웹으로 확인하지 않았다(**미확인 일반 지식**). 계통별 보유 여부는 모두 가상이다.

## 화면 목적과 핵심 질문

1. 선택한 유전자 구간의 리드 블록에는 하플로타입이 몇 개 있고, 효과(유리) 대립유전자는 어느 하플로타입에 실리며, 하위 집단마다 빈도가 어떻게 다른가?
2. 부모 후보·출원 후보·대비 품종 가운데 누가 유리 하플로타입을 갖고 있는가?
3. sd1·Pi-ta·Pi9 세 유리 좌위를 한 계통에 모으려면 어떤 계통을 교배해야 하는가? (기본 상태 답: 세 좌위를 모두 가진 부모 후보는 없다. sd1+Pi-ta 10계통(모두 A 그룹), Pi9는 C 그룹 3계통에만 있다)

### 3) 패널 결측(표시용)

```
r = createRng(SEED + 3000 + pi)        // 좌위마다
for j = 0..nSnp−1 (창 SNP 순서):
  m = 0.002 + 0.03 · r.beta(1, 4)     // SNP별 결측률
  for l = 0..411 (ld 인덱스 순서): miss[j][l] = r.next() < m
```

결측은 ld 인덱스(슬롯)에 붙는다. 결측은 하플로타입 배정과 표시에만 쓰고 블록 계산(ld-decay 값)에는 쓰지 않는다. 주/소수 대립유전자 판정은 SNP마다 결측 제외 관측 빈도로 한다(5개 창 모두 참값 기준 판정과 같음, 불일치 0).

```
           'N' 있음 → 'N' 아닌 자리가 모두 같은 named가 1개면 그 이름(결측 보정), 0개 '희귀', 2개 이상 '미정'

status: obs[leadPos] ≠ 'N' → 보유 = (값 == target);  'N'이면 배정 하플로타입의 target(추정), 희귀·미정이면 판정 불가(null)
```

```
    Pi-ta이고 need == 'carry'이고 group ≠ 'C' 이면 pool = [slot[별하랑], slot[늘솔찬]]   // 프로그램의 Pi-ta는 늘솔찬 → 별하랑 계열
    need ≠ 'any'이면 pool을 참값 리드 대립유전자로 거름(빈 풀이면 오류)
    donor = (Pi-ta이고 family == 'F01') ? slot[별하랑] : pool[floor(u2 · pool.length)]   // YR22-0412·0415 = 별하랑/해솔가온
logistic(x) = 1 / (1 + e^(−x))
```

### 6) 정렬

- **하플로타입**(기본): 하플로타입 순위(H1…Hk, 희귀, 미정) → 패널은 하위 집단 순(TEJ, TRJ, IND, AUS, ADM) → ID 오름차순. 육종 계통은 역할 순(출원 후보, 대비 품종, 참고 품종, 부모 후보) → GEBV 내림차순(없으면 뒤) → ID.
