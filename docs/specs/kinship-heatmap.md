# 유전적 관계 히트맵 — 명세

- slug: `kinship-heatmap` · category: `viz` · 기준일: 2026-10-23
- 지표 기준: `.claude/skills/breeding-metrics/references/metrics-catalog.md`. 프로그램 공통 사실은 `references/program-baseline.md`를 따른다.
- 연결 템플릿: `cross-planner`(후보 60계통, 계통 속성, 공조계수 f 전부), `gebv-selection`(p = 10%로 뽑은 60계통 = 부모 후보 규모, 앵커 8계통 GEBV), `pedigree-explorer`(계보 공조계수 YR22-0412 × YR22-0415 = 0.5195, YR22-0412 부모 간 f = 0.0390625)

## 가정

- 작물: 벼(*Oryza sativa*, 12개 염색체, 약 430 Mb, **자식성**). 후보는 모두 F₆ 이상의 고정 근교계다(F ≈ 1).
- **program-baseline 준수**: 대상 집단은 「2027년 1차 교배 계획」 부모 후보 60계통이다. 계통명, 그룹(A 중만생 다수성 30 / B 조생 고품질 20 / C 저항성 공여 10), 가계, 수량 GEBV, 신뢰도는 `cross-planner` `CANDIDATES`와 같다. 부모 간 공조계수 f는 `cross-planner` `kinship()`과 **모든 쌍에서 같다**. 근연 등급은 f ≥ 0.375 "강한 근연", 0.25 ≤ f < 0.375 "근연 주의"를 쓰고 "근교 경고"는 쓰지 않는다.
- 템플릿끼리는 서로 import하지 않으므로(template-authoring 규칙), 이 템플릿 `data.ts`에 cross-planner의 생성 규칙을 **같은 시드·같은 난수 호출 순서로 그대로 옮긴다**(아래 「목업 데이터 생성 규칙」 1단계). 이 화면에서 새로 만드는 값(대각 원소용 잔여 이형접합도)은 **별도 RNG**(`createRng(SEED + 1)`)로 만들어 cross-planner 난수열을 건드리지 않는다.
- **척도(이 템플릿의 핵심 주의점)**: 화면의 관계 계수 G는 VanRaden 유전체 관계 행렬(GRM) 값이다. 근교계 사이에서 G의 비대각 원소는 **2f 척도**(G_PQ = 2·f_PQ)이고 대각 원소는 1 + F(≈ 2)다. 계보 공조계수(pedigree-explorer)와 cross-planner의 f는 **f 척도**다. 그래서 화면은 G와 f(= G/2)를 항상 함께 보이고, 근연 등급과 계보 비교는 f 척도로 한다.
- GRM 계산 조건(이 화면에서 새로 정하는 사실, **추정**): 6K SNP 칩 마커 QC 후 4,820 SNP(program-baseline 유전체 분석실 값), 대립유전자 빈도 p는 훈련 집단 1,850계통(program-baseline) 추정치, 계산일 2026-10-22.
- 계보 비교 대상: 같은 가계(같은 교배 조합에서 나온 형제 계통)와 반형제 가계(F05·F09, F02·F03, F06·F07, F13·F14 — cross-planner `HALF_SIB`) 쌍만 계보에 공통 조상이 기록돼 있다고 본다. F01 가계는 별하랑/해솔가온(2022 교배)으로 pedigree-explorer와 같다. 다른 가계의 양친은 계보 DB에서 기초 개체(부모 간 f = 0)로 둔다. 그 밖의 쌍은 "계보상 공통 조상 미기록"이다.
- 계통명 연도: cross-planner 생성 계통의 이름 연도(예: F01의 YR23-6127)는 교배 연도가 아니라 계통 번호 부여 연도로 해석한다. 이 화면은 이름을 바꾸지 않는다.
- 사용자: 육종가(교배 부모 고를 때 근연 쌍 확인), 유전체 분석가(GRM 품질·집단 구조 확인).
- 시나리오: 히트맵에서 근연 블록(가계·반형제 가계)과 그룹 구조를 보고 → 정렬을 바꿔 GEBV 상위 계통끼리 얼마나 가까운지 보고 → 셀이나 표 행을 골라 두 계통의 관계 계수와 계보 기대값을 비교한다.
- 기본 상태: 정렬 **군집 순**, 대각 **마스킹**, 덴드로그램 표시, 선택 셀 **YR22-0412 × YR22-0415**, 근연 쌍 표 필터 **근연 주의 이상**.
- 계통명·품종명은 모두 가상이다. 화면 하단에 "계통명은 모두 가상이며 실존 계통·품종과 관계없습니다"를 넣는다.

## 화면 목적과 핵심 질문

1. 후보 60계통 안에 서로 아주 가까운 계통 묶음(근연 군집)이 몇 개이고, 어느 계통끼리인가?
2. 이 두 계통의 유전체 관계 계수는 얼마이고(G와 f = G/2), 근연 등급은 무엇이며, 계보 기대값과 얼마나 다른가?
3. 그룹 안·그룹 사이 평균 관계는 어떤가(어느 그룹 조합이 유전적으로 먼가)?

| 유전체 관계 행렬(GRM, G) | VanRaden 방법 1: G = ZZ′ / (2 Σ_k p_k(1 − p_k)), Z = M − 2p, M은 대체 대립유전자 수(0/1/2). p는 훈련 집단 빈도 | 무차원 | 60 × 60, 대칭 | VanRaden 2008(J Dairy Sci 91:4414). 카탈로그 6장 |
| 관계 계수 G_PQ(비대각) | 근교계 두 계통 사이: **G_PQ = 2·f_PQ**(2f 척도). f_PQ는 cross-planner 공조계수(소수 2자리) 그대로. VanRaden 방법 1은 훈련 집단 빈도를 기준으로 하므로 기준 집단 평균보다 덜 가까운 쌍은 **음수**다. 이 후보 집단에서는 C 저항성 공여(인디카 성분이 섞인 계통, population-structure YR20-1108 IND 0.36)와 A·B 사이 쌍이 대부분 음수다 | 무차원, 소수 2자리(음수는 U+2212 "−") | **−0.10 ~ 1.28**, 평균 0.16777 → **0.17**. 음수 420쌍(A–C 252, B–C 168), G = 0.00인 쌍 67개 | 카탈로그 6장(전형제 ~0.5는 비근교 척도. 근교계 형제는 G ≈ 1.0) |

### 2단계 — GRM

```ts
const H_E = 0.40
const rng2 = createRng(SEED + 1)
for (const c of candidates) {             // idx 순서
  c.het = round1(0.5 + 2.5 * rng2.beta(2, 5))          // 잔여 이형접합도 %, 실행값 0.6~2.3

}
```
