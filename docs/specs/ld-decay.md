# LD 구조 — 명세

- slug: `ld-decay` / category: `viz` / 기준일: 2026-10-23
- 기준 문서: `breeding-metrics` 스킬(metrics-catalog §LD, organisms 벼, visualization-guide「LD 구조」행, glossary-ko, program-baseline「GWAS 패널」)

## 가정

- **작물**: 벼(*Oryza sativa*), 12개 염색체, 게놈 약 430 Mb. 좌표는 IRGSP-1.0 근사(`ORGANISMS.rice`, 합계 373.0 Mb).
- **program-baseline 준수**: YR 다양성 패널 412계통, 36,420 SNP(MAF ≥ 0.05, 마커 콜레이트 ≥ 90%), 분석일 2026-10-20. 하위 집단 구성은 population-structure와 같다: 온대 자포니카(TEJ) 176 · 열대 자포니카(TRJ) 54 · 인디카(IND) 112 · 아우스(AUS) 30 · 혼합형(ADM) 40(K = 4, 최대 Q ≥ 0.70). GWAS 피크 13개는 gwas-manhattan「심을 피크」표와 같은 리드 SNP(ID·위치·−log10 p·후보 유전자)를 쓴다.
- **사용자**: 유전체 분석가. GWAS 피크의 연관 구간 폭을 정하고(파인 매핑 범위, 마커 밀도 설계), 하위 집단별 LD 차이를 확인한다.
- **사용 시나리오**: gwas-manhattan에서 유의 좌위를 찾은 뒤 이 화면으로 와서 (1) 패널 전체와 집단별 LD 감소 거리, (2) 피크 구간의 블록 구조와 리드 SNP 프록시를 본다.
- **자식성 벼의 긴 LD**: 근교계 패널이라 유전형은 동형 0/1(이형접합 결측 처리, gwas-manhattan과 같은 부호화)이고, r²는 계통 단위 하플로타입 r²다. 온대 자포니카 LD가 가장 길고 인디카가 가장 짧다는 순서는 문헌과 같다(Mather 등 2007, Genetics: 온대 자포니카 > 500 kb, 열대 자포니카 약 150 kb, 인디카 약 75 kb — https://pmc.ncbi.nlm.nih.gov/articles/PMC2219496 ; 191계통 패널 전체 r² = 0.2에서 191 kb, 인디카 최단·온대 자포니카 최장 — https://www.researchsquare.com/article/rs-12779/v1 ; 다른 패널 인디카 101 kb·자포니카 425 kb는 검색 요약으로만 확인, 원문 미확인). 목업의 실제 값은 아래 생성 규칙의 실행값이다.
- **카탈로그 범위 초과(의도)**: 카탈로그의 벼 LD 감소 거리 100~200 kb는 패널 전체 기준이다. 패널 전체 151 kb는 범위 안이다. 온대 자포니카 411 kb와 일부 염색체(패널 전체 Chr05 242 kb, Chr11 204 kb)는 범위를 넘지만 문헌의 하위 집단·염색체 변이 폭 안이라 그대로 둔다. 화면에서는 집단 표 각주로 "온대 자포니카는 자식성·병목으로 LD가 길다(문헌 > 400 kb, Mather 등 2007)"를 적는다.
- **gwas-manhattan과의 관계**: gwas-manhattan의 QTL 구간 "리드 ± 200 kb"는 이 화면의 패널 전체 감소 거리 151 kb보다 넓은 보수적 근사다. 서로 모순되지 않는다(각주 1줄).
- **다른 템플릿을 import하지 않는다**: gwas-manhattan `data.ts`의 `PLANTED` 표와 `buildPanel()`을 이 템플릿 `data.ts`로 **복사**한다(RNG 소비 순서까지 같아야 SNP ID·위치가 같다). population-structure에서는 집단별 계통 수만 쓴다(계통별 소속·ID는 재현하지 않는다).
- **MAF는 표시하지 않는다**: LD 목업 유전형은 하플로타입 모형으로 새로 만든 것이라 SNP별 실현 MAF가 gwas-manhattan의 MAF와 다르다. 리드 SNP만 패널 MAF에 맞췄고(2026-10-27 정리 회차 3부터 gwas-manhattan 피크 표 MAF가 리드 실현 빈도의 소수 2자리 값이라 차 ≤ 0.005, 실현 0.083~0.437), 나머지 SNP는 패널 MAF를 따르지 않는다(실현 패널 MAF는 모두 ≥ 0.05, 최소 0.051 — QC 필터와 모순 없음). 화면에 SNP별 MAF를 쓰지 않는다. 예외: 집단 안 단형 안내 문구의 "집단 내 MAF"(이 화면 자체 값).

## 화면 목적과 핵심 질문

1. 이 패널에서 LD는 몇 kb에서 r² = 0.2 아래로 떨어지는가? 하위 집단마다 얼마나 다른가?
2. 선택한 GWAS 피크 구간에서 리드 SNP는 어떤 블록에 있고, 블록 폭과 프록시(r² ≥ 0.8) SNP는 몇 개인가? 후보 유전자가 블록 안에 있는가?
3. 집단 구조가 장거리 LD를 얼마나 부풀리는가(패널 전체 배경 r² vs 1/n)?

### 2) 창 하나의 유전형 생성 `simulateWindow(chr, startBp, endBp, seed, rate, lead)`

```
snps = PANEL.snps.filter(s => s.chr == chr && startBp <= s.bp <= endBp)   // 위치 순
rng = createRng(seed)
dirichlet(H, a): 막대 나누기 — k = 0..H-2: b = rng.beta(a, (H-1-k)·a); out.push(rest·b); rest *= (1-b); 마지막 out.push(rest)
mix(a, b, w) = w·a + (1−w)·b (원소별)
sub(lo) = 길이 K 0벡터의 lo..lo+4 자리에 dirichlet(5, ALPHA)
J = mix(sub(0), sub(5), 1 − XMIX);  I = mix(sub(5), sub(0), 1 − XMIX)       // 호출 순서: sub(0), sub(5), sub(5), sub(0)
own = [sub(0), sub(0), sub(5), sub(5)]
f = [mix(own0, J, 0.25), mix(own1, J, 0.5), mix(own2, I, 0.25), mix(own3, I, 0.5)];  f.push(mix(f[0], f[2], 0.55))
drawCat(f): u = rng.next(); 누적합이 u를 넘는 첫 인덱스(없으면 마지막)
state[l] = drawCat(f[LINE_GROUP[l]])  for l = 0..411
randomClades(): nodes = [1<<0 … 1<<9], clades = nodes 복사
   while nodes.length > 2: i = rng.int(0, len−1); j = rng.int(0, len−2); if j ≥ i: j++
                           m = nodes[i] | nodes[j]; nodes에서 i, j 제거 후 m 추가; clades.push(m)
freqOf(m) = state가 m에 속한 계통 비율(412 기준)
eligible() = rng.shuffle(randomClades()) 중 0.08 ≤ freqOf ≤ 0.92 인 것(없으면 섞인 전체)
e0 = eligible(); major = [e0[0], e0[1], e0[2]]; cur = 0; zoneSet = false; leadMask = 0
prevBp = snps[0].bp
for snp in snps:
  gap = (snp.bp − prevBp)/1000; prevBp = snp.bp
  if gap > 0:
    for l in 0..411: if rng.next() < 1 − exp(−gap·rate / lamKb[group(l)]): state[l] = drawCat(f[group(l)])
    if rng.next() < 1 − exp(−gap·rate / TREE_KB):
      slot = rng.int(0, 2); nm = eligible()[0]
      if !(zoneSet && major[slot] == leadMask && |snp.bp − lead.bp| ≤ 50,000): major[slot] = nm
  inZone = lead != null && |snp.bp − lead.bp| ≤ 50,000
  if inZone && !zoneSet:                 // 리드 구간 진입: 목표 빈도에 가장 가까운 클레이드
    zoneSet = true
    clist = randomClades()               // RNG 소비는 이 한 번뿐(아래 선택은 결정적)
    leadMask = pickLeadMask(clist, state, lead)
    cur = rng.int(0, 2); major[cur] = leadMask
  else if rng.next() ≥ (inZone ? 0.95 : 0.6): cur = rng.int(0, 2)
  mask = (lead && snp.bp == lead.bp) ? leadMask : major[cur]
  for l in 0..411: a = (mask >> state[l]) & 1; if rng.next() < EPS: a ^= 1; geno[snp][l] = a
return { snps, geno }
```

리드 클레이드 선택(2026-10-27 정리 회차 3):

```
CLADE_TARGET = { H1 0.31, H2 0.22, H3 0.14, H4 0.41, C1 0.36, C2 0.30, C3 0.18, G1 0.27, G2 0.19, G3 0.08, B1 0.24, B2 0.16, B3 0.12 }
                 // 생성용 목표 빈도 = 정리 회차 3 이전 gwas 표 MAF. 표 MAF(PLANTED.maf)가 실현값으로 바뀌어도 창 유전형이 바뀌지 않게 분리
LEAD_BIAS = { G1: 'IND' };  IND_RATIO = 3;  TEJ_MIN = 0.02
pickLeadMask(clist, state, lead):
  target = CLADE_TARGET[lead.id]
  cands = clist
  if LEAD_BIAS[lead.id] == 'IND':
    u = clist 순서 그대로 + (i < j, clist[i] & clist[j] == 0 인 쌍의 합집합 clist[i] | clist[j], i·j 오름차순)
    minor(m) = freqOf(m) < 0.5 ? m : (2^K − 1) & ~m
    gf(m, g) = 생성 집단 g(0 TEJ, 2 IND)에 속한 계통 중 (minor(m) >> state[l]) & 1 인 비율   // 진입 시점 state
    ok = u 중 gf(·, IND) ≥ IND_RATIO · gf(·, TEJ) 그리고 gf(·, TEJ) ≥ TEJ_MIN
    if ok 비어 있지 않음: cands = ok
  best = cands[0]; bd = 9
  for m in cands: d = |min(freqOf(m), 1 − freqOf(m)) − target|; if d < bd: bd = d; best = m   // 동률은 먼저 나온 것
  return best
```

GS3 창(pi 6) 결과: 후보 115개(클레이드 18 + 서로소 합집합 97) 중 조건을 만족하는 9개에서 상태 {2, 6, 8}(진입 시점 패널 빈도 0.2597, 소수 대립유전자 보유 TEJ 0.108 · IND 0.545)을 고른다. 나머지 11개 창은 `LEAD_BIAS`가 없어 이전과 같은 클레이드를 고른다(창 유전형·블록·프록시 불변). 실제 GS3 장립·대립형(C165A, GS3A)이 인디카에 많고 온대 자포니카는 주로 GS3C라는 문헌(Takano-Kai et al. 2009, https://pmc.ncbi.nlm.nih.gov/articles/PMC2728869/ ; Fan et al. 2009, https://doi.org/10.1007/s00122-008-0913-1 — haplotype-viewer 도메인 검토 근거, 이번 회차에 원문 재확인 안 함)에 맞추기 위한 규칙이다. 클레이드 두 개의 합집합은 같은 대립유전자가 두 계보에 있는 경우(반복 돌연변이·유전자 전환을 단순화)로 해석한다.

### 3) 감소 곡선 창(12개 염색체 × 6 = 72창)

```
wr = createRng(SEED + 500)
chrMult[c] = exp(wr.normal(0, 0.2))  for c = 0..11            // 먼저 12개 모두
for c = 0..11, w = 0..5 (이 순서):
  start = round(wr.next() · (len[c]·1e6 − 1e6))
  rate  = chrMult[c] · exp(wr.normal(0, 0.4))
  simulateWindow(chrId, start, start + 1e6, SEED + 1000 + c·10 + w, rate, null)
  집단 g ∈ {전체(412), TEJ, TRJ, IND, AUS}마다: 집단 안 MAF ≥ 0.05인 SNP의 모든 쌍 i<j의 r²(null 제외)를
    bin = min(99, floor(d_kb / 10))에 누적(n, Σd, Σr²) — 통합 bins와 염색체별 bins 둘 다
비연관 쌍: 창 (c, w)와 창 ((c+1) mod 12, w)의 SNP를 각각 짝수 인덱스(0, 2, 4…)만 골라 모든 조합의 r²(집단 MAF ≥ 0.05) 평균 = 배경 b[g]
적합: bins를 (n, d = Σd/n, r = Σr²/n)로 바꾸고 fitDecay(bins, b[g])
  h_k = 5 · (3000/5)^(k/400), k = 0..400
  a = Σ n·x·(r − b) / Σ n·x²  (x = 1/(1 + d/h_k)),  SSE = Σ n·(r − b − a·x)²  → SSE 최소 h
  r0 = a + b;  d02 = (b < 0.2 < r0) ? h·(a/(0.2 − b) − 1) : null
염색체별 적합도 같은 함수, b는 통합 배경 b[g]를 쓴다.
```

**성능**: 72창 × 5집단 r² 계산을 단순 루프로 하면 Node 24에서 약 1.3초다. 412계통 유전형을 `Uint32Array(13)` 비트셋으로 묶고 집단 마스크와 AND 후 popcount로 n_A, n_B, n_AB를 세면 결과는 같고 수십 ms로 줄어든다. 비트셋 구현을 권장한다(구현 실측: 감소 곡선 + 프리셋 전체 Node 약 0.5초). 계산은 모듈 최상위가 아니라 마운트 후 `useEffect` 안의 `setTimeout`(약 30 ms)으로 한 번 해서 첫 화면 `Skeleton`이 먼저 그려지게 하고, 예외는 `ErrorState`로 보인다. 차트에는 구간 평균·적합선만 넘긴다(원자료 쌍은 "쌍별 점" 스위치용으로 선택 집단 약 4,000개만 솎아 보관: 생성 순서에서 `ceil(N/4000)`번째마다).
