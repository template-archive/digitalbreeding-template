- 연결 템플릿(숫자가 같아야 함): `kpi/genotyping-lab-ops`·`workflow/sample-tracking`(KASP 16마커 패널, 6K 칩 4,820 마커, TAT 목표 KASP 7일·6K 14일), `workflow/crossing-record`·`viz/kinship-heatmap`·`workflow/cross-planner`(YR20-1108 = C 그룹, Pi9, 출수 124일, 간장 95 cm), `viz/population-structure`(YR20-1108 Q 0.610/0.030/0.360/0, 가람솔 0.970/0.020/0.010/0), `infographic/variety-profile`(가람솔 출수 117일, 간장 80 cm, 잎도열병 발병 지수 5, 0~9 척도), `viz/gwas-manhattan`(Pi9 Chr06 10.4 Mb).

## 가정

- 작물: 벼(*Oryza sativa*, 12개 염색체, 조립 염색체 길이 합 373.0 Mb, 게놈 약 430 Mb, 자식성). 염색체 길이는 organisms.md 벼 표(IRGSP-1.0 근사).
- 사례: 대비 품종 **가람솔**(YR07-0231, 중만생 다수성, 반복친)에 도열병 저항성 유전자 **Pi9**(Chr06 10.4 Mb)를 저항성 공여 계통 **YR20-1108**(C 그룹, 공여친)에서 도입하는 **마커 보조 여교배(MABC)**. 조합 번호 **BC24-03**, 계보 표기 **가람솔\*4/YR20-1108**(반복친을 교배 1회 + 여교배 3회, 모두 4회 사용 = BC3).
- 교배 방향: 가람솔(♀, 제웅) × YR20-1108(♂). 여교배는 가람솔(♀) × 선발 개체(♂).
- 흐름: 교배(2024-08-12) → F1 → BC1F1 → BC2F1 → BC3F1 → BC3F2(Pi9 동형 선발) → BC3F3 계통 3개 확보(2026-04-10) → 2026 관찰 포장 검증(완료, 기준일 시점). 2027 생산력 검정(AYT) 편입은 예정.
- 선발 3단계(MABC 표준):
  1. **전경 선발(foreground)**: 표적 유전자 Pi9 KASP 마커(유전체 분석실 KASP 16마커 패널에 포함된 Pi9 마커). BC 세대는 이형(보인자), 자식 세대(BC3F2)는 공여친형 동형.
  2. **재조합 선발(recombinant)**: Pi9 양쪽 **측면 마커(flanking marker)** 2개(Pi9-F1 Chr06 9.60 Mb, Pi9-F2 Chr06 11.20 Mb, 각각 표적에서 0.80 Mb ≈ 3.2 cM, 이 과제용 추가 KASP)로 표적 바깥 공여친 단편을 잘라 낸 개체를 고른다 → **연관 끌림(linkage drag)** 축소. BC1에서 한쪽, BC2에서 나머지 쪽.
  3. **배경 선발(background)**: 전경·재조합을 통과한 개체만 6K SNP 칩으로 분석해 **반복친 게놈 회복률(RPG)**이 가장 높은 개체를 다음 세대 부모로 쓴다.
- 분석 플랫폼 수치는 program-baseline 유전체 분석실 값을 따른다: 6K 칩 마커 QC 후 사용 **4,820**개, KASP **16마커 패널**, TAT 목표 KASP 7일 · 6K 14일. 이 중 가람솔과 YR20-1108 사이 **다형성 SNP 1,523개(31.6%)**를 배경 선발에 쓴다(**추정**: 온대 자포니카 대 인디카 성분 36% 혼합형 조합으로 설정). 평균 간격 244.9 kb.
- 재조합률: 벼 게놈 평균 **4.0 cM/Mb**(약 1,500 cM / 373 Mb, **추정**), Haldane(교차 간섭 없음). 측면 마커 0.80 Mb ≈ 3.2 cM.
- 세대 주기: 온실 단일(短日) 처리 + 조기 수확으로 세대당 105~113일(평균 4.0개월). 시료는 파종 2주 뒤 유묘에서 채취해 개화 전에 KASP·6K 결과를 받는다. **KASP 결과 파종 28일 = 채취 14일 + 시료 준비(DNA 추출·발송) 7일 + TAT 7일**, 6K 결과는 KASP 회신 **21일 뒤 = 시료 준비(칩 플레이트 구성) 7일 + TAT 14일**(파종 49일), 여교배는 파종 76일 무렵. 화면 문장은 이 분해를 모두 밝힌다(KASP 쪽 시료 준비 7일을 빼면 14 + 7 ≠ 28로 읽힌다).
- **기존 여교배(비교 기준, 추정)**: 표현형(도열병 접종 검정) 전경 선발, 배경 선발 없음, 반복친 회복은 여교배 횟수에 의존 → BC6F2까지 **8세대**, 세대당 **6개월**(접종 검정 약 4주와 검정 후 이식·포장 관찰 때문에 연 2세대) = **48개월**. MABC는 **5세대 20개월**.
- 2026 관찰 포장 검증(BC3F3): 파종 2026-04-22(2026 AYT와 같은 날), 비반복 관찰 포장, 대비 가람솔·공여친 YR20-1108 옆줄 배치. 잎도열병 발병 지수는 밭못자리 검정(0~9, 낮을수록 저항성, variety-profile과 같은 척도). 형질값은 **추정**(가상).
- 이 템플릿의 KASP 1,046개체는 분석실 처리이고 2026년분(BC3F2 188)은 program-baseline 2026 KASP 누계 8,366에 포함된다. **6K 153샘플(2026년분 BC3F2 38 포함)은 전량 외부 위탁**이다 — 세대마다 개화 전에 배경 선발 결과가 필요해 분석실 6K 캠페인(4~7월, GS 후보 F6 2,000)과 시기가 맞지 않는다(BC1F1 6K 접수 2025-02-19, BC3F1 10-02, BC3F2 2026-01-24). 위탁 TAT는 분석실 목표와 같은 14일로 계약(추정), 비용은 BC24-03 과제비. 분석실 6K 누계 2,000에 넣지 않는다(정리 회차 5 개정).
- 사용자: 외부 청중(방문객, 정책·예산 담당자, 언론)과 연구 관리자. 비전공자도 "익숙한 품종에 저항성만 더한다"를 3초 안에 이해해야 한다.
- 사용 시나리오: 정적인 한 장 인포그래픽. 화면용 16:9(1920 × 1080), A4 가로 인쇄, 390px 모바일 요약.
- 품종명·계통명·기관명은 모두 가상이다. 유전자 이름(Pi9)은 실제이지만 계통별 보유·모의 결과는 가상이다.

## 화면 목적과 핵심 질문

1. 무엇을 했나? → 익숙한 대비 품종 **가람솔**에 도열병 저항성 유전자 **Pi9** 하나만 옮겼다. 최종 계통 BC24-03-053은 **반복친 게놈 회복률 99.3%**, 잎도열병 발병 지수 **1**(가람솔 5), 출수 **117일**(가람솔과 같음).
2. 왜 빨랐나? → 마커로 세 번 고른다(전경 → 재조합 → 배경). 기존 여교배 **BC6F2 8세대 48개월 → MABC BC3F2 5세대 20개월, 3세대 · 28개월 단축**. 3세대 적게 쓰고도 회복률이 기존 BC6 이론값(99.2%)과 같은 수준.
3. 원치 않는 공여친 형질이 딸려 오지 않았나? → 재조합 선발로 Pi9 주변 공여친 단편이 **1.2 Mb**(재조합 선발 없이 BC3 기대 13.6 Mb, 기존 BC6 기대 7.9 Mb). 공여친의 만생(124일)·장간(95 cm) 형질이 따라오지 않았다.

유전자 기호 표기: 유전자 이름 *Pi9*(그리고 Hd1 등 다른 유전자 기호)은 화면의 모든 보이는 텍스트(제목·큰 숫자·깔때기 "전경(*Pi9* 이형/동형)"·검증 카드·흐름 하단 문구·캡션·각주·모바일 요약·SVG 라벨)에서 **기울임**으로 쓴다. 마커 이름(Pi9-F1·Pi9-F2, "Pi9 마커"의 마커 패널 항목명)과 aria·sr-only 문자열은 바로 쓴다.

type Iv = [number, number]; type Hap = Iv[][]; type Ind = [Hap, Hap]
export function generate(seed = SEED) {
  const rng = createRng(seed)
  // 1) 다형성 SNP: 길이 비례 최대 잔여 배분(동률은 염색체 번호 순), 위치 = round(next()·len·1000)/1000, 정렬
  const raw = CHR_LEN_MB.map(l => (N_POLY * l) / GENOME_MB)
  const cnt = raw.map(Math.floor)
  const rest = N_POLY - cnt.reduce((a, b) => a + b, 0)
  raw.map((r, i) => [r - Math.floor(r), i] as const).sort((a, b) => b[0] - a[0] || a[1] - b[1])
     .slice(0, rest).forEach(([, i]) => cnt[i]++)
  const markers = CHR_LEN_MB.map((l, c) => {
    const xs: number[] = []
    for (let k = 0; k < cnt[c]; k++) xs.push(Math.round(rng.next() * l * 1000) / 1000)
    return xs.sort((a, b) => a - b)
  })
  const poisson = (lam: number) => { const e = Math.exp(-lam); let k = 0, p = 1; do { k++; p *= rng.next() } while (p > e); return k - 1 }
  const R_HAP: Hap = CHR_LEN_MB.map(() => [])
  const D_HAP: Hap = CHR_LEN_MB.map(l => [[0, l]])
  const clip = (ivs: Iv[], a: number, b: number): Iv[] => ivs.filter(([s, e]) => e > a && s < b).map(([s, e]) => [Math.max(s, a), Math.min(e, b)])
  const merge = (ivs: Iv[]): Iv[] => { const out: Iv[] = []; for (const iv of ivs) { const last = out[out.length - 1]; if (last && Math.abs(last[1] - iv[0]) < 1e-12) last[1] = iv[1]; else out.push([iv[0], iv[1]]) } return out }
  // 감수분열: 염색체마다 교차 수 ~ Poisson(길이(M) = len × 4.0 / 100), 위치 균등 → 정렬, 시작 가닥 next() < 0.5 ? 0 : 1
  const meiosis = (ind: Ind): Hap => CHR_LEN_MB.map((l, c) => {
    const k = poisson((l * CM_PER_MB) / 100)
    const xs: number[] = []
    for (let j = 0; j < k; j++) xs.push(rng.next() * l)
    xs.sort((a, b) => a - b)
    let strand = rng.next() < 0.5 ? 0 : 1
    const b = [0, ...xs, l]
    const out: Iv[] = []
    for (let j = 0; j < b.length - 1; j++) { out.push(...clip(ind[strand][c], b[j], b[j + 1])); strand = 1 - strand }
    return merge(out)
  })
  const has = (ivs: Iv[], x: number) => ivs.some(([s, e]) => x >= s && x < e)
  const dose = (ind: Ind, c: number, x: number) => (has(ind[0][c], x) ? 1 : 0) + (has(ind[1][c], x) ? 1 : 0)   // 공여친 대립유전자 수
  const rpg = (ind: Ind) => { let d = 0; markers.forEach((xs, c) => xs.forEach(x => { d += dose(ind, c, x) })); return (1 - d / (2 * N_POLY)) * 100 }
  const tc = TARGET.chr - 1

  const gens = []
  let parent: Ind = [D_HAP, R_HAP]                       // F1
  for (const step of PLAN) {
    if (step.kind === 'f1') { gens.push({ gen: step.gen, n: step.n, carriers: step.n, recL: null, recR: null, chip: [], selected: [] }); continue }
    const plants = []
    for (let i = 0; i < step.n; i++) {
      const ind: Ind = step.kind === 'self' ? [meiosis(parent), meiosis(parent)] : [meiosis(parent), R_HAP]
      plants.push({ id: `${step.gen}-${String(i + 1).padStart(3, '0')}`, ind })
    }
    const want = step.kind === 'self' ? 2 : 1            // 전경: BC 이형, 자식 세대 공여친형 동형
    const carriers = plants.filter(p => dose(p.ind, tc, TARGET.mb) === want)
    const isRL = (p) => dose(p.ind, tc, FLANK.left) === 0
    const isRR = (p) => dose(p.ind, tc, FLANK.right) === 0
    const pool = carriers.filter(p => step.rule === 'either' ? isRL(p) || isRR(p) : isRL(p) && isRR(p))   // 재조합 → 6K 대상
    if (pool.length === 0) throw new Error(`[검산] ${step.gen} 재조합 개체 0`)
    for (const p of pool) p.rpg = rpg(p.ind)
    const ranked = pool.slice().sort((a, b) => b.rpg - a.rpg || (a.id < b.id ? -1 : 1))
    const selected = ranked.slice(0, step.kind === 'self' ? N_FINAL_LINES : 1)
    gens.push({ gen: step.gen, n: step.n, carriers: carriers.length, recL: carriers.filter(isRL).length, recR: carriers.filter(isRR).length,
                chip: pool.map(p => ({ id: p.id, rpg: p.rpg })), selected: selected.map(p => ({ id: p.id, rpg: p.rpg, ind: p.ind })) })
    parent = selected[0].ind
  }
  return { markers, gens, dose, rpg }
}

// 6K + KASP 판독 공여친 단편(그래픽 유전형): Chr06에는 FLANK.left·TARGET.mb·FLANK.right 위치를 마커로 끼워 넣는다.
// 같은 dose가 이어지는 구간, 경계 = 이웃 마커 중점(첫·끝 마커면 염색체 끝)
export function inferSegments(markers: number[][], ind: Ind, dose: (ind: Ind, c: number, x: number) => number) {
  const segs: { chr: number; start: number; end: number; dose: number; nMarkers: number }[] = []
  markers.forEach((xs0, c) => {
    const xs = c === TARGET.chr - 1 ? [...xs0, FLANK.left, TARGET.mb, FLANK.right].sort((a, b) => a - b) : xs0
    const ds = xs.map(x => dose(ind, c, x))
    let j = 0
    while (j < xs.length) {
      if (ds[j] === 0) { j++; continue }
      let k = j
      while (k + 1 < xs.length && ds[k + 1] === ds[j]) k++
      const start = j === 0 ? 0 : (xs[j - 1] + xs[j]) / 2
      const end = k === xs.length - 1 ? CHR_LEN_MB[c] : (xs[k] + xs[k + 1]) / 2
      segs.push({ chr: c + 1, start, end, dose: ds[j], nMarkers: k - j + 1 })
      j = k + 1
    }
  })
  return segs
}
