# 다환경 시험 GxE·안정성 — 명세

slug `met-gxe-stability` · category `viz` · 기준일 2026-10-23 · 시드 20261023

## 가정
- 작물: 벼(*Oryza sativa*, 12개 염색체, 약 430 Mb), 중부 평야지 프로그램. **program-baseline 준수**.
- 형질: 쌀 수량(kg/10a, 백미 기준). "정조 수량"으로 쓰지 않는다(baseline 수량 표기 결정).
- 사용자: 육종가, 품종 출원·심사 준비 담당자.
- 사용 시나리오: 2026 지역 적응 시험(MET) 2년차 수확·분석이 끝난 시점(2026-10-23)에, 출원 후보 3계통을 왜 골랐는지 근거(평균·안정성·메가 환경 적응)를 정리해 보고서와 출원 서류에 옮긴다.
- 시험 집합(baseline 파이프라인 2026 MET 18계통): **시험 계통 18 + 대비 품종 2(가람솔·온새미로) = 20 유전자형**. baseline의 파이프라인 계통 수는 대비 품종을 세지 않는다(AYT "40계통 + 대비 2"와 같은 관행), 연간 직접비 모델도 "대비 2개"다.
- 지역(variety-profile `SITES`와 같은 8곳): 경기 화성·경기 이천·충남 당진·충남 예산·충북 청주(중부 평야지), 전북 김제·경남 밀양(남부 평야지), 강원 철원(중북부지). 연도 2025·2026, 지역마다 난괴법 3반복 → 환경 16개, 시험구 960개(20 × 16 × 3).
- 이 18계통은 2025년에 MET에 처음 들어와 2026년 2년차를 마친 집합이다. program-overview `PIPELINE[2025]`의 MET 21계통 = 이 18계통(1년차) + 2년차 3계통(별하랑 포함, 별하랑 MET는 2024~2025). 별하랑은 이 시험에 없다.
- 대비 품종 가람솔 수량: 2025 연 평균 568.0, 2026 552.0, 2년 평균 560.0 kg/10a(= 프로그램 μ 560. 2025 568은 variety-profile `YIELD_BY_YEAR` 2025 c와 같은 해 같은 대비 품종이라 일치시킨다).
- 출원 후보 3계통: **YR19-0118**(2026-12 출원 예정, baseline `PLANNED_APPLICATION`), **YR20-0342**, **YR20-0527**(새 계통명, 기존 템플릿 이름과 겹치지 않음을 확인). 비교용 "평균은 높지만 불안정한 계통" **YR20-0815**.
- 나머지 14계통 이름은 아래 표대로 고정한다(난수로 만들지 않음). baseline의 다른 계통(YR19-0083, YR19-0731, YR20-1108, YR21-0594, YR21-0877, YR22-*)과 겹치지 않는다.
- GGE 바이플롯은 2년 평균 지역 값(20 × 8)으로 그린다. 연도별 GGE는 그리지 않는다(2025 단년 GGE는 남부 구역이 YR19-0902로 바뀌는 등 단년 노이즈가 커서 메가 환경 판단은 2년 평균으로 하고, 연도별 재현성은 "실측 1위 횟수"로 보인다).
- 웹 검색으로 확인한 수치는 없다. 분산 성분 비율의 "현실 범위"(E 60~80%, G 5~15%, GxE 15~30%)는 벼·밀 MET 문헌의 일반적 범위에 따른 **추정**이다.

## 화면 목적과 핵심 질문
1. 출원 후보 3계통은 왜 골랐나? — YR19-0118은 평균 1위·가장 안정(ASV 1위)·중부 평야지 메가 환경 승자, YR20-0342는 남부 평야지 특정 적응, YR20-0527은 철원(중북부 냉량지) 특정 적응.
2. 이 시험에서 GxE는 얼마나 큰가? — 수량 변동의 68.6%가 환경, 22.7%가 GxE, 8.8%가 유전자형(GxE가 G의 2.6배) → 지역별 추천이 필요하다.
3. 평균이 높은데 왜 빠졌나? — YR20-0815는 평균 4위(103.4%)지만 생태가 W 11.7%(19위), 반응 기울기 b 1.52, 철원 20위(470.5, 91.1%)로 비선발.

```
rng = createRng(20261023)
// 1) 지역×연도 효과: 연도마다 지역 8개, 연도 안에서 중심화
sy[t][j]     = center([rng.normal(0, 22) for j in sites])           for t in years
// 2) 반복(블록) 효과: 연도→지역→반복 3, 환경 안에서 중심화
rep[t][j][r] = center([rng.normal(0, 8) for r in 0..2])             for t, j
// 3) G×L 잡음: 유전자형→지역, 유전자형 안에서 중심화
gs[i][j]     = center([rng.normal(0, 4) for j])                     for i
// 4) G×L×Y 잡음: 유전자형→연도→지역, (i,t) 안에서 중심화
gst[i][t][j] = center([rng.normal(0, 7) for j])                     for i, t
// 5) 시험구 값: 유전자형→연도→지역→반복 순으로 오차 1개씩
y[i][t][j][r] = MU + g_i + E_j + YEAR_EFF[t] + sy[t][j] + rep[t][j][r]
              + a_i·A_j + c_i·B_j + d_i·E_j + gs[i][j] + gst[i][t][j] + rng.normal(0, 28)
// 6) 가람솔(i=0) 연도 보정: 연도 t의 24구 평균이 CHECK_YEAR_MEAN[t]가 되도록 같은 값을 더함
// 7) 모든 시험구 값을 소수 1자리로 반올림(보정 뒤)
```

계산 규칙:
- 셀 평균 = 반복 3구 평균. 환경 인덱스 e = t·8 + j(2025 지역 8개, 2026 지역 8개 순).
- 분산분석(시험구 기준): SS_G = 48·Σ(ȳ_i. − ȳ..)², SS_E = 60·Σ(ȳ_.e − ȳ..)², SS_GE = 3·Σ(ȳ_ie − ȳ_i. − ȳ_.e + ȳ..)², SS_Rep(E) = 20·Σ(반복 평균 − 환경 평균)², SS_오차 = 총 − 나머지. E = L + Y + L×Y, GE = G×L + G×Y + G×L×Y. F = MS / MS_오차, p는 F 분포 상측 확률(정규화 불완전 베타).
- GGE: X = 2년 평균 지역 행렬(20 × 8)에서 열(지역) 평균을 뺀 값. XᵀX(8 × 8) 고윳값 분해(Jacobi 등)로 SVD. 유전자형 점수 = Uk·√λk, 지역 점수 = Vk·√λk(k = 1, 2). **부호 규칙**: PC1은 지역 점수 합 > 0, PC2는 강원 철원 점수 > 0이 되게 뒤집는다.
- which-won-where: 유전자형 점수의 볼록 껍질(monotone chain). 각 지역의 승자 = 꼭짓점 중 (유전자형 점수 · 지역 점수) 내적이 최대인 유전자형(= 수선으로 나눈 구역과 같다). 같은 승자를 갖는 지역 묶음 = 메가 환경. 지역이 없는 구역은 칠하지 않는다.
- Finlay–Wilkinson: I_e = ȳ_.e − ȳ..(20 유전자형 평균), b_i = Σ(y_ie − ȳ_i.)·I_e / ΣI_e², SE_b = √(SS잔차/(16 − 2) / ΣI_e²).
- Wricke W: 위 정의(셀 평균 기준), 비율 = W_i / ΣW · 100.
- ASV: GE = 이중 중심화 셀 평균 행렬(20 × 16), SVD, IPCAk 점수 = Uk·√λk, SS 비 = λ1²/λ2².
- 출원 후보 판정(대비 품종 제외): 지수 ≥ 103.0 **그리고** (W% ≤ 100/20 = 5.0 **또는** 메가 환경 승자). 대비 대비 차가 LSD보다 큰지도 표시한다(판정 조건은 아님).
- 표시 자릿수: 수량 소수 1자리, 지수 1자리, b·R²·ASV 2자리, W% 1자리, PC·분산 % 1자리. 원 실행값에서 한 번만 반올림하고 `formatFixed`/`formatNumber`(Math.round 방식)를 쓴다. `toFixed`는 쓰지 않는다: 2년 평균 지역 값은 1/60 단위라 정확히 .x5가 나오며(YR20-0815 청주 581.55, 가람솔 밀양 495.85) `toFixed(1)`은 581.5, `formatFixed`는 581.6을 낸다. 이 명세의 표시값은 `formatFixed` 기준이다. 문장·aria·각주의 숫자도 상수에서 생성한다.
