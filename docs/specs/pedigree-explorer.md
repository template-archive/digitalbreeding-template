# 계통도 탐색기 — 명세

- slug: `pedigree-explorer` · category: `viz` · 기준일: 2026-10-23
- 지표 기준: `.claude/skills/breeding-metrics/references/metrics-catalog.md`, 프로그램 공통 사실은 `references/program-baseline.md`
- 연결 템플릿: `variety-profile`(별하랑 교배 조합·보유 유전자), `program-overview`(출원 목록 R1·R3·R6·R8·R10·R12·R15), `cross-planner`(YR22-0412·YR22-0415 GEBV·신뢰도·형제 계통 공조계수 0.52)

## 가정

- 작물: 벼(*Oryza sativa*, 12개 염색체, 약 430 Mb, **자식성**). 모든 계통·품종·유전자원은 고정된 근교계(F ≈ 1)로 본다.
- **program-baseline 준수**: 별하랑(YR19-0083) = 가람솔(YR07-0231) ♀ / 늘솔찬(YR14-0472) ♂, 2019 교배·2026-06-09 출원, Pi-ta·Pib는 부본 유래, 가람솔은 sd1만 보유. 품종명·계통명·교배 연도·출원/등록 연도·주요 형질 문구는 program-overview `APPLICATIONS`와 같다. YR22-0412 +52.4(r² 0.58), YR22-0415 +49.8(r² 0.55)은 cross-planner 앵커와 같다.
- 사용자: 육종가(교배 부모 이력 확인), 연구 관리자(품종 계보 설명 자료).
- 시나리오: 기준 계통을 고르고 → 3~5세대 조상을 세대별로 보고 → 부모 양쪽에 같은 조상이 나타나는 근연 루프와 부모 간 공조계수(f)를 확인하고 → 조상 노드를 눌러 상세를 보거나 그 조상을 새 기준으로 다시 그린다.
- 기본 상태: 기준 **별하랑(YR19-0083)**, 표시 세대 **4**, 근연 루프 강조 켬.
- 계보 데이터는 **24개체 상수**(아래 표)다. 난수를 쓰지 않는다(시드 20261023은 규약상 기재만 한다). 계보 기록이 없는 기초 계통·도입 유전자원은 서로 무관(공조계수 0)하다고 가정한다.
- 공조계수는 **계보 기대값**(자식성 작물의 혈연계수 COP 방식: 모든 개체 근교계, 자손은 양친에서 절반씩)이다. cross-planner의 f는 유전체(GRM) 실현값이지만 YR22-0412 × YR22-0415는 두 값이 같게(0.52) 맞췄다.
- 근연 표기는 program-baseline 규칙을 따른다: f ≥ 0.375 "강한 근연", 0.25 ≤ f < 0.375 "근연 주의", 그 외 "정상". "근교 경고"는 쓰지 않는다(자식성 벼에서 근연 조합의 문제는 근교 약세가 아니라 자손 분리 분산 축소).
- 수량은 "쌀 수량"(kg/10a, 백미 기준), GEBV는 2026-10 GBLUP 재추정값(훈련 집단 평균 0 기준 편차, gebv-selection과 같은 기준점).
- 계통명(`YR##-####`), 유전자원 번호(`GR-####`), 품종명은 모두 가상이다. 유전자 이름(Pi-ta, Pib, Xa21, sd1)은 실제 유전자 이름이지만 보유 여부는 가상이다. 화면 하단에 이 문구를 넣는다.

## 화면 목적과 핵심 질문

1. 이 계통의 부모는 누구이고, 부모 양쪽에 공통으로 들어간 조상(근연 루프)은 무엇인가?
2. 부모가 얼마나 가까운가(부모 간 공조계수 f와 근연 등급), 그 값은 어느 조상에서 왔는가?
3. 특정 조상(예: 늘솔찬)은 어떤 형질·유전자를 가졌고, 그 조상의 계보는 어떤가(다시 그리기)?

## 목업 데이터 생성 규칙

- 시드: 20261023 (난수 미사용. 위 「계보 상수」가 전부다. 모든 파생값은 아래 함수로 계산하고 하드코딩하지 않는다)

```ts
// 공조계수(메모이즈). order = 연도*10000 + 일련번호(뒤 4자리)
function f(x, y) {
  if (x === y) return 1                       // 근교계: (1+F)/2 = 1
  let [a, b] = order(x) >= order(y) ? [x, y] : [y, x]
  if (!N[a].dam) [a, b] = [b, a]              // 부모 기록 있는 쪽을 펼친다
  return N[a].dam ? 0.5 * (f(N[a].dam, b) + f(N[a].sire, b)) : 0
}
fParents(r) = N[r].dam ? f(N[r].dam, N[r].sire) : null      // 기초·도입이면 null → "해당 없음"
Ffixed(r)   = fParents(r) == null ? null : 1 - (1 - fParents(r)) * 0.5 ** 6
kinLevel(v) = v >= 0.375 ? '강한 근연' : v >= 0.25 ? '근연 주의' : '정상'

// 경로 펼침 인스턴스(계통도 노드). path: 'D'=모본, 'S'=부본 문자열, 노드 키로 쓴다
function instances(root, D) {
  out = []; leaves = 0
  go(id, g, path) {
    if (g > 0) out.push({ id, g, path, truncated: g === D && !!N[id].dam })
    if (g === D || !N[id].dam) { leaves++; return }
    go(N[id].dam, g + 1, path + 'D'); go(N[id].sire, g + 1, path + 'S')
  }
  go(root, 0, ''); return { out, leaves }        // 세로 위치 = 잎 순번(모본 먼저), 내부 노드 = 자식 잎들의 가운데
}

// 근연 루프: 모본·부본에서 각각 위로 가는 모든 경로를 열거해 끝 개체가 같은 쌍 중
// 끝 개체 외에 공유 개체가 없는 쌍만 센다
function loops(root) {
  for a of paths(dam), b of paths(sire):   // 경로 = [dam, ..., A]
    if last(a) !== last(b) continue
    if a[:-1] ∩ b[:-1] ≠ ∅ continue
    n = (a.length-1) + (b.length-1); c = 0.5 ** n; gen = max(a.length, b.length)  // 기준 계통에서 본 세대
    byA[A].contrib += c; byA[A].pairs.push({a, b, n, gen})
  return 기여 내림차순(같으면 계통명)
}
// 검산 조건: Σ loops.contrib === fParents(root) (부동소수 1e-12)
visibleLoops(root, D) = loops(root).filter(l => l.pairs.some(p => p.gen <= D))

// 조상 기여율
contrib(root): go(id, w) { m[id] += w; if dam: go(dam, w/2), go(sire, w/2) }, go(root, 1), m.delete(root)
// 검산 조건: 기초 조상(부모 기록 없음) 기여율 합 = 1
```

- 루프 번호(①~④)는 `loops()` 정렬 순서로 매긴다. 루프 색은 4개를 쓰고, 5번째부터는 번호 배지만(이 데이터에서 루프는 최대 4개).
- 이 데이터의 일관성 규칙(빌더가 상수를 바꿀 때 지킬 것): 자식의 연도 > 부모 연도, 자식의 보유 유전자는 부모 중 한쪽에 있음, |GEBV − 중간 부모값| ≤ 2.5σA(70.5).

## 상호작용

- **기준 계통 선택**: 콤보박스(검색: 계통명·품종명). 선택하면 계통도·KPI·루프·기여율이 모두 다시 계산된다. 브레드크럼에 이력이 쌓이고 "뒤로"로 이전 기준으로 돌아간다.
- **표시 세대 3/4/5**: 계통도 열 수와 "표시 세대 안 루프 수"만 바뀐다. f·F·루프 목록 전체·기여율은 표시 세대와 무관(전체 계보 기준)하다는 것을 f 카드 보조 문구로 알린다.
- **노드 클릭/Enter**: 상세 패널을 연다. 같은 개체의 다른 인스턴스도 함께 강조(테두리). 패널의 "이 계통을 기준으로 다시 그리기"는 그 개체를 기준으로 바꾼다. 기준 계통 자신을 누르면 패널만 연다.
- **노드 호버 툴팁**: 계통명(품종명), 구분, 연도, GEBV(r²), 등장 횟수 "이 계통도에서 ×n". GEBV가 없으면 상세 패널·KPI와 같은 상수 `NO_GENO_REASON`("유전형 없음(종자 미보존)")을 쓴다. 툴팁만 다른 문구를 쓰지 않는다.
- **루프 행 호버/선택**: 해당 경로쌍 간선과 노드만 강조, 나머지는 흐리게. 토글을 끄면 루프 색·배지를 모두 끄고 중립 표시.
- **키보드**: 노드는 Tab으로 이동(세대 → 위에서 아래 순), Enter로 패널, Esc로 닫기. 루프 표 행도 포커스 가능.
- **빈 상태**: 부모 기록이 없는 개체(B·G 8개)를 기준으로 고르면 계통도 자리에 "부모 기록이 없는 기초 계통(또는 도입 유전자원)입니다. 계보를 그릴 수 없습니다." + f·F·루프 카드 "해당 없음". 루프가 없는 기준(예: 청여울)은 루프 표에 "부모 간 공통 조상이 없습니다(f = 0.00)".
- **로딩/오류**: 스켈레톤(열 4개), 오류 시 "계보 데이터를 불러오지 못했습니다" + 다시 시도. 갤러리 확인용 `?state=loading|empty|error`. `empty`는 "계보 기록이 없습니다" 빈 상태다.
- **좁은 화면**(< 768px): 계통도는 가로 스크롤 컨테이너 안에서 유지한다(열 간격 최소 46 px, 세대 열이 겹치지 않게). 390px 폭 초기 화면에는 1세대까지만 보이므로 계통도 위에 "좌우로 밀어 상위 세대 보기" 안내(글자 + 화살표 아이콘)를 둔다. 근연 루프 표도 가로 스크롤 컨테이너에 넣고 첫 열(번호·공통 조상)을 고정한다. 조상 이름은 줄바꿈하지 않는다. 합계 행 설명은 잘리지 않게 표 아래 별도 줄로 내린다. 페이지 전체 가로 넘침은 없어야 한다. 상세 패널은 아래 시트.
