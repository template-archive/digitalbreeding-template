# 집단 구조 분석 — 명세

- 기준 문서: `breeding-metrics` 스킬(metrics-catalog §6 집단 구조 "PCA PC1 설명 분산 5~25%, ADMIXTURE K=2~6", visualization-guide 집단 구조 행, glossary-ko, **program-baseline**)
- 연결 템플릿: `gwas-manhattan`(같은 YR 다양성 패널 412계통, MLM에 PC 3개 + GRM), `variety-profile`·`program-overview`(가람솔·온새미로·늘솔찬·별하랑), `cross-planner`·`gebv-selection`(저항성 공여 YR20-1108·YR19-0731)

## 가정

- **program-baseline 준수.** 패널·분석 조건은 baseline 「GWAS 패널」 행을 그대로 쓴다: YR 다양성 패널 **412계통**, 36,420 SNP(MAF ≥ 0.05, 마커 콜레이트 ≥ 90%), GWAS 모형 **MLM(PC 3개 + GRM)**, 분석일 2026-10-20. 품종·계통 이름과 교배 관계(별하랑 = 가람솔 / 늘솔찬)는 baseline 「계통·품종」 표를 따른다.
- **작물**: 벼(*Oryza sativa*), 12개 염색체, 게놈 약 430 Mb. 자식성 근교계 패널.
- **사용자**: 유전체 분석가. GWAS 전에 집단 구조를 확인하고, GWAS 모형에 넣을 주성분(PC) 수가 적절한지 판단하고, 하위 집단별 구성과 혼합형 계통을 파악한다.
- **사용 시나리오**: gwas-manhattan과 같은 날(2026-10-20) 같은 패널로 돌린 PCA·ADMIXTURE 결과를 본다. 분석가는 (1) 하위 집단이 몇 개이고 각각 어떤 계통으로 이루어졌는지, (2) GWAS에 넣은 PC 3개가 집단 구조를 충분히 잡는지, (3) 혼합형 계통이 어디에 있는지를 확인한다.
- **하위 집단 체계**: 벼의 대표 하위 집단 중 4개를 쓴다 — 온대 자포니카(TEJ), 열대 자포니카(TRJ), 인디카(IND, 통일형 육성 계통 포함), 아우스(AUS). 향미(aromatic) 집단은 이 패널에 없다고 가정한다(국내 프로그램 패널이라 표본이 거의 없음, **가정**).
- **PCA/ADMIXTURE 입력 SNP**: 36,420개 중 LD 가지치기(창 50 SNP, 이동 5, r² > 0.2 제거) 후 **9,184개**(25.2%). 벼는 LD가 길어 가지치기 후 남는 비율이 낮다. 값은 목업 설정(**추정**).
- **PCA 좌표**: plink `--pca` 형식의 **고유벡터**(열마다 평균 0, 제곱합 1, 서로 직교). 그래서 축 눈금 값은 ±0.2 안이고, 점이 퍼진 폭은 설명 분산 크기에 비례하지 않는다. 축 제목의 설명 분산 %가 각 PC의 비중을 나타낸다.
- **설명 분산 %와 ADMIXTURE 교차 검증(CV) 오차**는 유전형 행렬에서 계산하지 않은 **목업 설정값**이다(아래 표). 고유벡터 점수와 Q 행렬은 시드 생성 규칙으로 만든다.
- **ADMIXTURE 가정 위반 고지**: ADMIXTURE는 하디-바인베르크 평형을 가정하지만 자식성 근교계는 이를 만족하지 않는다. Q는 "조상 성분 비율의 근사"로 읽는다고 화면 각주에 적는다(벼 GWAS 문헌의 관행).
- **통일형 소수 성분(2026-10-26 정리 회차 1·2)**: 통일형 YR 인디카 38계통은 인디카 × 자포니카 3원 교배 유래이므로 (1) 소수 성분 가중을 온대 자포니카(TEJ) 6, 열대 자포니카·아우스 1로 두고, (2) 자포니카 유입 폭이 큰 점을 반영해 주 성분 폭을 넓힌다: main = 1 − 0.50 · Beta(1, 6)(다른 순수 계통은 0.30). 다른 계통은 같은 계열 가중 3 규칙 그대로. 결과 YR 인디카 평균 Q4 = TEJ **0.036** / TRJ 0.013 / IND 0.938 / AUS 0.013(정리 회차 1 0.017 / 0.010 / 0.963 / 0.010, 처음 0.007 / 0.010 / 0.963 / 0.020), 38계통 중 29계통이 TEJ > AUS, TEJ 최대 0.168, TEJ ≥ 0.05인 계통 11개. 통일 품종(IR667-98-1-2) 유전체는 자포니카 부모 유래가 7.9%(염색체별 0~25.9%)로 보고됐다(Kim et al. 2014, Rice 7:22, https://doi.org/10.1186/s12284-014-0022-5). 이 패널의 YR 인디카 자포니카 성분 합(TEJ + TRJ) 0.049, 최대 TEJ 0.168은 그 범위 안이다. ADMIXTURE Q와 부모 유래 비율은 같은 양이 아니므로 근사 비교다. 도입 인디카(YRG 74계통)는 0.013 / 0.011 / 0.954 / 0.022로 아우스 쪽 소수 성분을 유지한다.
- **이름**: 육성 계통 `YRyy-nnnn`(yy = 05~18), 도입 유전자원 `YRG-nnnn`(가상의 유전자원 번호). 모두 가상이다. 실존 품종명·자원 번호를 쓰지 않는다.

## 화면 목적과 핵심 질문

1. 패널은 몇 개의 하위 집단으로 나뉘고, 각 집단에 몇 계통이 있으며 대표 계통은 무엇인가? → K=4, 온대 자포니카 176 · 열대 자포니카 54 · 인디카 112 · 아우스 30 · 혼합형 40
2. GWAS 모형에 넣은 PC 3개가 집단 구조를 충분히 잡는가? → PC1이 자포니카/인디카형, PC2가 온대/열대 자포니카, PC3가 아우스/인디카를 가른다. PC1~PC3 누적 33.9%, PC4부터는 1.9% 이하로 평평하다. 최적 K=4이므로 K − 1 = 3개 PC면 4개 집단을 구분할 수 있다.
3. 혼합형 계통은 어디에 있는가? → PCA에서 집단 사이에 놓인 40계통(최대 Q < 0.70). 저항성 공여 계통 YR20-1108·YR19-0731이 여기에 든다.

## 목업 데이터 생성 규칙

- 시드: **20261023** (`createRng(20261023)` 한 인스턴스를 아래 순서대로 사용한다. 호출 순서를 바꾸면 실행값이 바뀐다)
- 공통: `@/lib/rng`의 `createRng`. Q는 정수 천분율(milli, 합 1000)로 다뤄 반올림 합 오차를 없앤다.

```ts
const SEED = 20261023
const rng = createRng(SEED)
const G = ['TEJ', 'TRJ', 'IND', 'AUS']                      // K=4 성분 순서
const AFF = (g, j, origin) =>                                 // 2026-10-26 정리 회차 개정
  g === 2 && origin === 'YR' ? (j === 0 ? 6 : 1)                // YR 인디카(통일형): TEJ 6(정리 회차 2, 이전 3), TRJ·AUS 1
  : ((g < 2) === (j < 2) ? 3 : 1)                               // 그 밖: 같은 계열(자포니카 0·1 / 인디카형 2·3)이면 가중 3
const C = [[1.00, 0.70, 0.05], [0.75, -0.95, -0.05], [-1.05, 0.05, 0.55], [-0.85, -0.05, -1.10]] // 집단 중심(원점수 PC1~3)
const NOISE = 0.10
const RESERVED = new Set(['YR07-0231','YR13-0819','YR14-0472','YR19-0083','YR20-1108','YR19-0731',
  'YR22-0412','YR22-0415','YR21-0877','YR23-0136','YR22-0263','YR21-0594'])   // baseline 이름 재사용 금지
const toMilli = q => { m = q.map(x => Math.round(x*1000)); d = 1000 - sum(m); m[argmax(m)] += d; return m }  // argmax: 동률이면 앞 인덱스

// 1) 생성 목록(이 순서 그대로, 총 406)
spec = [
  116 × {g:0,'YR'}, 56 × {g:0,'YRG'}, 54 × {g:1,'YRG'}, 38 × {g:2,'YR'}, 74 × {g:2,'YRG'}, 30 × {g:3,'YRG'},
  14 × {ADM,'YR',pair:[0,2]}, 4 × {ADM,'YR',pair:[0,1]},
  4 × {ADM,'YRG',[0,2]}, 6 × {ADM,'YRG',[0,1]}, 6 × {ADM,'YRG',[2,3]}, 4 × {ADM,'YRG',[1,2]} ]

// 2) 계통마다 Q4, s, t (목록 순서대로)
for sp of spec:
  q = [0,0,0,0]
  if sp.g !== 'ADM':
    main = 1 - (g === 2 && YR ? 0.50 : 0.30) * rng.beta(1, 6)   // 정리 회차 2: YR 인디카(통일형)만 0.50(MAIN_SPREAD_YR_IND). 난수 호출 수 그대로
    others = [0..3] \ {g};  w_j = -ln(1 - rng.next()) * AFF(g, j, sp.origin)   // others 순서대로(난수 호출 수 변화 없음)
    q[g] = main;  q[j] = (1 - main) * w_j / Σw
  else:
    [g1, g2] = sp.pair
    q1 = 0.40 + 0.28 * rng.next()                          // 0.40~0.68
    q2 = (1 - q1) * (0.80 + 0.15 * rng.next())
    others = [0..3] \ {g1,g2};  w_j = -ln(1 - rng.next())   // 두 개, 순서대로
    q[g1] = q1; q[g2] = q2; q[j] = (1 - q1 - q2) * w_j / Σw
  s = YR ? 1 - 0.25*rng.beta(1,4) : 0.25*rng.beta(1,4)    // TEJ 성분 중 '국내 육성' 몫(K5·K6)
  t = YR ? 1 - 0.25*rng.beta(1,4) : 0.25*rng.beta(1,4)    // IND 성분 중 '통일형' 몫(K6)
  line = { origin, q4m: toMilli(q), s, t }

// 3) 이름: YR 계통(목록 순서대로) → YRG 번호
for line of lines where origin==='YR':
  do id = `YR${pad2(rng.int(5,18))}-${pad4(rng.int(1,1999))}` while (used.has(id))   // used = RESERVED 포함
perm = rng.shuffle([1..234]);  YRG 계통 i번째(목록 순서) → `YRG-${pad4(perm[i])}`

// 4) 앵커 6계통을 목록 끝에 추가(고정값): [id, 이름, q4m, s, t]
['YR07-0231','가람솔',[970,20,10,0],0.96,0.90], ['YR13-0819','온새미로',[910,30,60,0],0.94,0.80],
['YR14-0472','늘솔찬',[790,30,180,0],0.93,0.20], ['YR19-0083','별하랑',[880,25,95,0],0.95,0.24],
['YR20-1108',null,[610,30,360,0],0.90,0.15],   ['YR19-0731',null,[560,0,410,30],0.90,0.10]

// 5) PC 원점수(412계통, 앵커 포함 목록 순서대로)
z = [rng.normal(0,NOISE), rng.normal(0,NOISE), rng.normal(0,NOISE)]
raw_d = Σ_k (q4m[k]/1000) * C[k][d] + z[d]

// 6) 판정·K별 Q(milli)
[a,b,c,d] = q4m;  maxQ = max/1000;  dom = 최대 성분 인덱스(동률이면 앞)
group = max >= 700 ? G[dom] : 'ADM'
tD = round(a * s);  iT = round(c * t)
Q[2] = [a+b, c+d];  Q[3] = [a+b, c, d];  Q[4] = [a,b,c,d]
Q[5] = [tD, a-tD, b, c, d];  Q[6] = [tD, a-tD, b, iT, c-iT, d]

// 7) PCA 후처리(고유벡터 형식)
열 PC1~PC3: 평균을 빼 중심화 → 그람-슈미트(PC2에서 PC1 성분 제거, PC3에서 PC1·PC2 성분 제거) → 각 열 제곱합 1로 정규화
부호: PC1·PC2는 TEJ 평균이 양수, PC3은 IND 평균이 양수가 되도록 필요하면 열 전체 부호 반전
표시: 소수 4자리
```

## 상호작용

- **PC 쌍 전환**: 축 제목과 데이터가 함께 바뀐다. 브러시 선택은 유지한다(선택은 계통 ID 집합).
- **브러시**: PCA에서 사각형·자유형으로 고르면(숨긴 집단의 계통은 선택에 들지 않는다) (1) ADMIXTURE 막대에서 선택 계통은 원래 불투명도, 나머지는 0.25로 흐리게(PCA 점도 같은 방식으로 선택 밖을 흐리게), (2) 요약 표 "선택" 열이 "n / 집단 계통 수"로 바뀌고, (3) 선택 계통 목록이 나타난다. 카드 위에 "412계통 중 n계통 선택 · 선택 해제" 칩. Esc 또는 해제 버튼으로 초기화.
- **요약 표 행 클릭**: 그 집단 전체를 선택(브러시와 같은 상태로). 다시 클릭하면 해제.
- **범례(토글 칩) 클릭**: PCA에서 집단 표시/숨김(이미 만든 선택 상태는 바꾸지 않는다. 숨긴 상태에서 새로 브러시하면 숨긴 집단은 빠진다).
- **툴팁**: PCA 점 "YR19-0083 별하랑 · 온대 자포니카 · Q(K=4) 0.880 · PC1 0.0359 · PC2 0.0267". 막대 "YR19-0083 별하랑 · 소속 온대 자포니카 · 온대 자포니카 0.880 / 열대 자포니카 0.025 / 인디카 0.095 / 아우스 0.000"(현재 K의 성분 전부, 소수 3자리). 앵커 6계통은 PCA·막대 툴팁 모두에 앵커 표의 비고 한 줄을 붙인다(예: 별하랑 "교배: 가람솔 / 늘솔찬 — K = 4 Q는 두 부모 평균과 같음", YR20-1108 "Pi9 공여"). scree 막대 "PC3 · 4.6% · 누적 33.9% · GWAS 공변량".
- **상태**: 로딩(차트 스켈레톤), 빈 데이터("분석 결과가 없습니다"), 오류(재시도 버튼), 빈 선택(선택 목록 자리에 "PCA에서 점을 드래그해 계통을 고르세요").
- **키보드·접근성**: 요약 표 행은 Enter로 선택 토글. PCA 브러시를 쓰지 못하는 사용자를 위해 요약 표 행 선택이 같은 기능을 한다.
