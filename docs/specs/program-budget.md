# 육종 프로그램 예산·효율 — 명세

slug `program-budget` · 카테고리 `kpi` · 기준일 2026-10-23 · 시드 20261023(기록용, **난수 미사용** — 모든 값은 아래 확정 상수에서 계산)

## 가정
- 작물: 벼(*Oryza sativa*), 중부 평야지 가상 프로그램. **program-baseline 준수**(직접비·계통당 선발 평가비·ΔG·비용 효율·파이프라인·유전체 분석실 샘플 수).
- 사용자: 연구 관리자·기획 담당자. 사용 시나리오: 10월 말 집행 점검(불용·초과 위험 확인)과 2027 예산안 설명 자료 준비.
- 금액 단위: 내부 계산은 **만 원**, 표시 큰 숫자는 억 원(소수 2자리). 모든 금액은 **추정**이며 2026 불변가격(물가 미반영)이다. 환율은 1 USD = 1,390원(baseline, 칩 단가 환산에만 씀).
- 집행 인식 시점: 유전형 분석은 결과 납품(검수) 월, 나머지는 전표 월. 10월은 기준일 23일까지(계획 누계도 10월분을 23/31로 일할).
- **직접비 정의 두 가지를 섞지 않는다(브리프·사용자 결정).**
  - 「비교 기준 직접비」 = conventional-vs-digital 정의. 계통당 선발 평가비 × 세대 진전 후보 수 + 시험구 수 × 8만 원. 시험구는 **단계별 1세트 × 1년**(PYT·AYT·MET 각 그해 완료 세트만, 겹쳐 심는 세트 제외 — 2026-10-30 사용자 결정). 인건비·시설 감가상각·교배 작업비 제외. 2026 = 18,800만 원.
  - 「직접비(소모성 경비)」 = 이 화면의 예산 비목 구분. 비교 기준 항목(A) + 비교 기준 외 소모성 경비(B: MET 1년차 세트 포장, KASP, GBS, 교배 작업비, 종자 관리·연구 활동비). 2026 = 31,574만 원.
  - 인건비·시설 감가상각(C)은 두 직접비 정의 어디에도 넣지 않고 **"직접비 정의 밖(별도 집계)"**으로 표시한다. 국가 R&D 회계에서는 인건비가 직접비에 속하므로 각주로 차이를 밝힌다.
  - 간접비(D) = 기관 공통 경비, (직접비(소모성 경비) + 인건비) × 10%(추정).
- 2019~2025 연도별 추이는 **비교 기준 직접비 정의로만** 계산한다(전체 예산의 연도별 값은 만들지 않는다). 2019·2026 값은 baseline, 2020~2025 계통당 단가는 이 템플릿의 추정.
- 2027 예산안은 초안(추정). 2027 GS 후보 2,000계통(rga-scheduler `gs27.lines`), MET 완료 세트 20(= 2026 1년차 세트), MET 1년차 목표 18(advancement-decision), PYT 120·AYT 40(2026과 같다고 가정).

## 화면 목적과 핵심 질문
1. 올해 예산은 계획대로 쓰이고 있는가? → 집행률 82.6%(계획 누계 82.6%, 계획 대비 100.0%), 연말 전망 100.1%.
2. 어느 비목이 넘치거나 남는가? → KASP 패널 연말 전망 105.0%(경보, +211.5만 원), 종자 관리·연구 활동비 83.8%(불용 주의).
3. 디지털 전환이 돈값을 하는가? → 비교 기준 직접비는 1.30억 → 1.88억 원(1.45배)으로 늘었지만 개량 1 kg/10a당 연간 직접비는 3,096만 → 1,466만 원(예측 기준 −52.6%, 실현 기준 −45.3%).

## 목업 데이터 생성 규칙
- 시드 20261023(기록용). 난수 호출 없음. 위 「확정 상수」로 모든 값을 계산한다(하드코딩 금지, 문장·aria·각주 숫자도 상수에서 생성).
- 연도별 추이(2019~2027):
  ```
  perLine(y) = Σ PER_LINE[y]
  plots(y)   = (PYT+2)·2 + (AYT+2)·3 + (MET완료+2)·3·8      // 2027은 PIPELINE_2027_PLAN
  annual(y)  = PIPELINE[y][0] · perLine(y) + plots(y) · 8
  dG(y)      = I·R·σA/L  (2027 = PLAN_2027로 계산, "계획" 라벨)
  cpg(y)     = annual(y) / dG(y)
  cpgRealized = { 2019: annual(2019)/REALIZED.conventional, 2026: annual(2026)/REALIZED.gs }
  ```
- 2026 비목: 「비목 표」대로 예산을 만들고, 간접비는 직접비(A+B) 합이 정해진 뒤 `Math.round` 한 번.
- 월별 계획 = 가중 × 예산(플레이트 품목은 플레이트 계획 × 94 × 단가). 실적 1~9월 = 계획(× 실적 계수), 10월 = 10월 계획 × 23/31(× 실적 계수). 플레이트 품목 실적은 `*_ACT_*` 상수.
- 계획 누계(10/23) = 1~9월 계획 + 10월 계획 × 23/31(플레이트 품목도 같은 방식: KASP 계획 84.9355장).
- 연말 전망 = 실적 누계 + (예산 − 계획 누계). 예외: 6K = 5,000(완료), KASP = 105장 × 94 × 0.45 = 4,441.5, GBS = 6장 = 2,820.
- 경보 판정: 전망 ÷ 예산 > 100% → `critical`, < 90% → `warning`, 그 밖 정상. 총액도 같은 규칙.

## 상호작용
- 불릿 차트 행 hover/focus 툴팁: 예산·실적·전망(만 원)·집행률·계획 대비. 경보 목록 항목 클릭 → KASP·종자 관리 항목은 해당 불릿 행 강조 + 스크롤, 총액 항목은 C(비목별 구성·집행) 카드로, 환율 항목은 G(2027안 표)로 이동.
- B 차트 토글 없음(단순). D 패널 툴팁: 연도, 계통당 구성 요소별 금액, 비교 기준 직접비, ΔG, 개량 1 kg/10a당 비용.
- G 표: 증감률 정렬 가능(`DataTable` 제어형 정렬, 기본 = 비목 순서). 증감률 정렬 중에는 그룹 소계·합계 행을 숨기고 비목 12행만 보이며, 표 위 안내 문구가 이 사실과 합계(93,411 → 95,256)를 알린다(소계가 정렬에 섞이지 않게).
- QA 상태(`qa-states.json`): `kasp-focus`(KASP 경보 클릭 → 행 강조), `plan-sorted`(G 증감률 정렬).
- 상태: 로딩(스켈레톤), 빈 데이터("2026 예산 데이터가 없습니다"), 오류(재시도 버튼). 다크 모드에서 빗금·틱 대비 확인.
- 390px: KPI 2열, B·C·D 세로 쌓기, 불릿 차트는 비목명 줄바꿈 허용(Badge에 가변 문구 금지)하고 경보·주의 "전망 n%" 문구는 트랙 안이 아니라 비목명 아래 줄에 둔다(트랙이 좁아 잘림). D 우 패널 값 라벨은 한 칸씩 건너 표시(전체 값은 툴팁·숨김 표). G 표는 가로 스크롤 + 비목 열 sticky.
- 접근성: 차트마다 `aria-label`에 핵심 숫자(상수에서 생성), 불릿 차트는 같은 값을 담은 시각 숨김 표.
