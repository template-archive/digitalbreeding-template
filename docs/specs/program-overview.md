# 육종 프로그램 KPI 개요 — 명세

- slug: `program-overview` · category: `kpi` · 기준일: 2026-10-23
- 지표 기준: `.claude/skills/breeding-metrics/references/metrics-catalog.md` (모든 값은 카탈로그 범위 안의 가상 목업)

## 가정

- 작물: 벼(*Oryza sativa*, 12개 염색체, 약 430 Mb, 자식성). 대상 형질은 **쌀 수량(kg/10a, 백미 기준)** 하나로 고정한다. ΔG·r·σA는 모두 수량 기준이다. 560~605 kg/10a 수준은 국내 성적 관행상 쌀 수량이므로 "정조 수량"으로 쓰지 않는다(program-baseline, 2026-10-23 사용자 결정).
- 프로그램: 가상의 "중부 평야지 벼 육종 프로그램". 2019~2021년은 표현형 선발(전통), **2022년부터 유전체 선발(GS)과 속성세대진전을 도입**했다.
- 기준 평균 μ = 560 kg/10a(2019년 코호트 평균). ΔG %/년 = ΔG(kg/10a/년) / 560 × 100.
- 사용자: 연구 관리자(기관 육종 사업 책임자). 분기 보고와 연간 목표 점검에 쓴다.
- 사용 시나리오: 연도 범위를 고르고, 종료 연도의 KPI가 목표에 얼마나 도달했는지와 기준 미달 지표가 무엇인지 확인한다.
- 2026년은 진행 중인 연도다(2026-10-23 기준 잠정). 신품종 출원 실적은 연중 누계다.
- 세대 간격 근거: 2026년 L = 2.2년(목표 2.1년)은 카탈로그의 벼 GS 1~2년보다 약간 길다. 중부 평야지 온대 1기작이라 포장 평가(PYT 이후)가 연 1회로 묶이고, 2022년 도입한 속성세대진전(세대 진전 단계 단축)이 아직 과도기여서 부모 선발~다음 부모 선발 사이클이 2년을 조금 넘는다. 목표 2.1년도 같은 이유로 2년보다 길게 잡았다.
- 품종명은 모두 가칭(가상)이다. 실존 품종과 관계없다는 문구를 화면 하단에 넣는다.
- ΔG 식의 선발 강도 i는 **부모 선발(재순환 선발) 단계**의 선발 비율 p로 정한다. 파이프라인 깔때기(품종 개발 단계)의 통과율과는 다른 값이다. 이 점을 구성 요소 패널 툴팁에 밝힌다.

## 화면 목적과 핵심 질문

1. 올해(종료 연도) 연간 유전적 개량량(ΔG)이 목표에 도달했는가? 미달이라면 어느 구성 요소(i, r, σA, L) 때문인가?
2. GS 도입 이후 예측 정확도와 세대 간격이 어떻게 바뀌었고, ΔG가 얼마나 늘었는가?
3. 품종 개발 파이프라인과 신품종 출원에서 기준에 못 미치는 단계는 어디인가?

### 연도별 확정 데이터(빌더는 이 표를 상수로 옮긴다)

ΔG 칸은 표시 값이 아니라 **코드에서 식으로 계산**하고, 아래 값은 검산용이다(반올림 전 값으로 계산한 뒤 표시할 때만 반올림).

| 연도 | p | i | r | σA (kg/10a) | L (년) | ΔG (kg/10a/년) | ΔG (%/년) | 훈련 집단 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 2019 | 20% | 1.400 | 0.45 | 30.0 | 4.5 | 4.20 | 0.75 | — |
| 2020 | 20% | 1.400 | 0.45 | 29.7 | 4.5 | 4.16 | 0.74 | — |
| 2021 | 20% | 1.400 | 0.45 | 29.6 | 4.4 | 4.24 | 0.76 | — |
| 2022 | 10% | 1.755 | 0.46 | 29.3 | 3.2 | 7.39 | 1.32 | 620 |
| 2023 | 10% | 1.755 | 0.50 | 29.0 | 2.8 | 9.09 | 1.62 | 950 |
| 2024 | 10% | 1.755 | 0.53 | 28.8 | 2.5 | 10.72 | 1.91 | 1,280 |
| 2025 | 10% | 1.755 | 0.55 | 28.5 | 2.3 | 11.96 | 2.14 | 1,560 |
| 2026 | 10% | 1.755 | 0.57 | 28.2 | 2.2 | 12.82 | 2.29 | 1,850 |

검산: 2026 = 1.755 × 0.57 × 28.2 / 2.2 = 12.823 kg/10a/년, 12.823 / 560 = 2.290%.
σA는 반올림 경계(소수 셋째 자리 5)에 걸리지 않도록 골랐다(2020: 4.158/560 = 0.7425%, 2021: 4.2382/560 = 0.7568%). 화면 숫자는 반드시 반올림 전 계산값을 같은 포맷 함수로 표시한다.

## 목업 데이터 생성 규칙

- 시드: **20261023** (`createRng(20261023)` from `@/lib/rng`)
- 연도별 표·목표·파이프라인·출원 데이터는 위 표의 **상수**를 그대로 쓴다(난수로 만들지 않는다). 연결된 수치를 정확히 맞추기 위해서다.
- ΔG, ΔG목표, 달성률, 통과율, 범위 평균은 상수에서 **계산**한다. 하드코딩하지 않는다.
- 난수는 형질별 교차 검증 반복값(툴팁의 분포·sr-only 표)에만 쓴다.

```ts
const MU = 560
const years = [2019, ..., 2026]
// 상수: P, I, R, SIGMA_A, L, TRAIN_N, I_T, R_T, L_T, PIPELINE, PIPELINE_TARGET_2026, MET_TARGET, APPS, APP_TARGET, REGS, APPLICATIONS

const dG = (y) => I[y] * R[y] * SIGMA_A[y] / L[y]               // kg/10a/년
const dGpct = (y) => dG(y) / MU * 100                            // %/년
const dGTarget = (y) => I_T[y] * R_T[y] * SIGMA_A[y] / L_T[y]    // σA는 실적 사용
const achHigher = (actual, target) => actual / target * 100      // ΔG, r, 출원, MET
const achLower  = (actual, target) => target / actual * 100      // L
const severity = (a) => a < 90 ? 'critical' : a < 100 ? 'warning' : 'ok'

// 범위 평균 ΔG = mean(dGpct(y) for y in [start..end])   (2022~2026 → 1.86)

// 교차 검증 반복값: 형질마다 50개(5-fold × 10회)
const rng = createRng(20261023)
for (const t of traits) {
  const raw = Array.from({ length: 50 }, () => rng.normal(0, 1))
  const m = mean(raw), s = sd(raw)
  t.folds = raw.map(z => clamp(t.mean + t.sd * (z - m) / s, 0, 1))  // 평균·SD가 표와 정확히 일치
}
```

- 연도별 출원 건수 APPS는 상수로 두지 않고 출원 목록(APPLICATIONS)의 출원일 연도로 센다(2019~2026: 2,1,2,1,3,2,3,1). 차트와 목록이 늘 일치한다.
- 파이프라인 목표 마커: 종료 연도 2026이면 6단계 모두(PIPELINE_TARGET_2026), 다른 연도는 MET 목표만 표시한다.
- 경보 목록 생성: 종료 연도 Y에 대해 ΔG, r(Y ≥ 2022일 때 "예측 정확도", 이전은 "선발 정확도"), L, 신품종 출원, MET 완료 5개 지표의 달성률을 계산하고 `severity !== 'ok'`만 남겨 달성률 오름차순 정렬(정렬·표시 달성률은 실적 기준).
- **연중 KPI 판정(2026-10-29 정리 회차 4, program-baseline 「연중 연도 KPI 판정」)**: Y = `PROVISIONAL_YEAR`의 신품종 출원은 등급만 연말 전망 달성률 `(APPS[Y] + (PLANNED_APPLICATION.year === Y ? 1 : 0)) / APP_TARGET[Y] × 100`(2026: 66.667% → 경보)으로 정한다. - MET 완료 경보 원인 문구: Y ≥ 2025이면 `${met}/${MET_TARGET[Y]}계통(그해 완료 세트). ${Y−2} 생산력 검정(AYT) ${PIPELINE[Y−2][3]}계통 중 ${진급률}%(목표 ${목표 진급률}%)`(2025: "21/25계통(그해 완료 세트). 2023 생산력 검정(AYT) 36계통 중 58.3%(목표 69.4%)"), Y ≤ 2024이면 `${met}/${MET_TARGET[Y]}계통(그해 완료 세트)`(전통 공정 MET 3년 세트라 코호트 진급률을 계산하지 않는다).

## 상호작용

- 연도 범위: 시작 ≤ 종료를 강제(시작을 종료보다 뒤로 고르면 종료를 시작으로 맞춤). 기본값 **2022~2026**(GS 도입 이후). KPI·경보·F·G는 종료 연도, D·E·H·I는 범위 전체를 쓴다.
- 툴팁: D는 연도·ΔG(%/년, kg/10a/년)·목표·달성률(연도는 axisValue가 아니라 dataIndex로 찾는다 — 잠정 연도 NaN 방지). E는 해당 연도 구성 요소 값과 그 해의 ΔG. F는 평균 r ± SD, 반복 50회, 그리고 **쌀 수량 행에만** 예측 능력(r×0.60)(√h² = 0.60은 수량 계통평균 h² = 0.36에서 나온 값이라 다른 형질에는 적용하지 않는다). G는 계통 수·통과율·목표.
- 드릴다운: 경보 항목 클릭 시 해당 차트 영역으로 스크롤하고 포커스 이동(키보드 Enter 동일).
- 상태: 초기 600ms `Skeleton`(시뮬레이션) → 데이터. 종료 연도 ≤ 2021이면 F는 `EmptyState`("GS 도입(2022) 이전 연도입니다"). 범위에 출원이 없으면 I는 `emptyText` "선택한 기간에 출원 건이 없습니다". 오류 상태는 `ErrorState`(재시도 버튼) 미리보기용 토글을 두지 않아도 된다.
- 숫자 표기: 정확도 소수 2자리, 백분율 소수 1자리, ΔG %/년 소수 2자리, kg/10a/년 소수 1자리(식 표기) 또는 2자리(툴팁), 계통 수 천 단위 쉼표.

## ΔG 배율 표기(2026-10-26 정리 회차 2, 사용자 결정)

- **표기 규칙(사용자 결정 2026-10-26)**: 헤드라인 ΔG 배율은 구성 요소(i · r · σA / L)로 계산한 **예측** 배율이므로 실현 배율과 병기한다.
  - 표준 문구: **"3.1배(예측) · 실현 2.6배"** — 문장·해설·각주·`ariaLabel`처럼 공간이 있는 곳.
  - 좁은 곳(배지, KPI 보조 줄, 큰 숫자, 모바일 요약 카드): **"3.1배(예측)"**만. 이때 같은 화면의 다른 위치(문장·각주)에 표준 문구나 실현 배율 설명이 있어야 한다.
  - 두 숫자는 상수에서 만든다: `${f1(GAIN_RATIO)}배(예측)`, `실현 ${f1(REALIZED_RATIO)}배`. 하드코딩 금지.
  - 실현 배율의 기준: genetic-gain-tracker 실현 추세 기울기 비(전통 2019~2021 코호트 3.439753, GS 2021~2026 코호트 9.097399 kg/10a/년 → 2.644783). 예측 배율 3.053(ΔG 2026 / 2019)과 기준 기간이 달라 나란히 쓸 때 "예측"·"실현"을 반드시 붙인다.

## 수용 기준

- [ ] ΔG KPI 값(2026: 2.29%/년, 12.8 kg/10a/년)이 구성 요소 패널의 식 "1.755 × 0.57 × 28.2 / 2.2"로 계산한 값과 일치하고, 연도 범위를 바꾸면 식과 KPI가 함께 종료 연도 값으로 갱신된다.
- [ ] ΔG 목표가 i목표·r목표·σA실적/L목표로 계산되어 2026 목표 2.44%/년, 달성률 93.8%로 표시된다.
- [ ] 세대 간격(L) KPI는 감소(▼0.1년)를 positive 색으로, 달성률을 목표/실적(95.5%)으로 표시한다.
- [ ] 형질별 예측 정확도 차트의 수량 막대 값이 ΔG 식의 r(종료 연도)과 같고, y축이 0~1이며 모든 막대에 교차 검증 SD 오차 막대가 있다.
- [ ] 파이프라인은 로그 축 가로 막대로 6단계를 보여 주고, 각 단계에 계통 수와 같은 해 단계 수 비(2026: 30.0%, 20.0%, 33.3%, 45.0%, 16.7%)가 표시되고, 화면 어디에도 "MET 진입"·"AYT → MET 통과율 45.0%" 표기가 없다.
- [ ] 경보 영역은 기본 범위(종료 2026)에서 경보 2건(신품종 출원 33.3% — 원인에 "연말 전망 2/3건(66.7%)", 지역 적응 시험 완료 72.0% — 원인에 "2024 생산력 검정(AYT) 38계통 중 47.4%(목표 65.8%)")과 주의 3건(ΔG 93.8%, 세대 간격 95.5%, 예측 정확도 98.3%)을 달성률 오름차순으로 보여 주고, 각 배지는 색과 문자(경보/주의)를 함께 쓴다.
- [ ] 연도별 ΔG 차트에 목표 점선과 2022년 "GS 도입" 표식, 범위 평균 라벨(2022~2026: 1.86%/년)이 있다.
- [ ] 출원·등록 차트의 연도별 출원 수가 출원 목록의 해당 연도 행 수와 일치하고(예: 2023년 3건), 2026년은 "연중"으로 표시된다.
- [ ] 화면에 나오는 모든 정확도·유전력·달성률 값이 통계적으로 가능한 범위(r, h² ∈ [0,1])에 있고, 모든 값에 단위와 기준 연도가 붙는다(ΔG는 "수량 기준" 명시).
- [ ] 용어가 첫 등장 시 한국어+약어로 표기된다: 연간 유전적 개량량(ΔG), 예측 정확도(r), 세대 간격(L), 선발 강도(i), 상가적 유전 표준편차(σA), 유전체 선발(GS), 지역 적응 시험(MET). 품종명 가칭 고지 문구가 있다.
