## 가정

- **program-baseline 준수.** 벼(*Oryza sativa*, 12개 염색체, 약 430 Mb, 자식성), 중부 평야지 벼 육종 프로그램. 세대 간격 L 2026 = 2.2년(디지털 공정 설계값 = 교배 0.5 + 세대 진전 1.3 + 유전형 분석 0.1 + GEBV 예측 0.1 + 선발 0.2), 세대 진전 속도 연 3.8세대(F2~F6 종자 5세대 ÷ 1.3년, digital-breeding-process `GEN_RATE.digital` = 5/1.3 = 3.846), 6K SNP 칩 연 2,000샘플(= 조합 400 × 조합당 5계통).
- 사용자: 세대 진전 담당 연구원(온실 운영). 매주 이 화면을 열어 베드별로 무엇이 언제 파종·출수·수확되는지, 빈 베드가 언제 생기는지, 다음 세대를 어느 베드에 넣을지 정하고 일정을 고친다.
- 사용 시나리오: 2026-10-23(금). 오늘 R25-1(CR25-001~100) F5를 수확했고, 다음 주 월요일(10-26) CR26 2차 교배 2묶음 F1 잎을 따서 KASP 진위 분석(KSP-2611-01, 결과 11-03 예정)에 보낸다.
- **시설(추정·가상)**: 속성세대진전(RGA, rapid generation advance) 온실 2동 × 5베드 = **10베드**(A01~A05, B01~B05). 베드 1개 = 50공 트레이 10개 = **500셀**. SSD 계통 1개 = 1셀(1주), F1 1주 = 1셀. 베드마다 차광 커튼·보광 LED가 따로 있어 베드 단위로 일장을 바꿀 수 있다.
- **세대 단축 조건과 세대당 일수(추정)**: 단일(短日) 처리 10시간 일장(인공광 LED + 차광), 주간 30 °C / 야간 25 °C, 질소 시비 절감.
