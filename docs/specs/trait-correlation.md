# 형질 상관 행렬 — 명세

slug `trait-correlation` · category `viz` · 기준일 2026-10-23 · 시드 20261023

## 가정
- 작물: 벼(*Oryza sativa*, 12개 염색체, 약 430 Mb), 중부 평야지 프로그램. **program-baseline 준수**.
- 사용자: 육종가(선발 지수 가중치를 정하는 사람), 유전체 분석가(다형질 모형 결과를 해석·보고하는 사람).
- 사용 시나리오: 2026 하반기 부모 선발(gebv-selection) 전에, 지수 가중치가 형질 간 상관 때문에 어떤 부수 효과를 내는지 확인한다. 2026-10 GS 재학습 준비 분석(분석일 2026-10-23)의 결과 화면.
- 대상 집단: **훈련 집단 1,850계통**(baseline `TRAIN_N[2026]`), 6K SNP 칩 마커 QC 후 4,820 SNP로 만든 유전체 관계 행렬(GRM). 표현형은 계통 평균(연차·지역 보정, 이하 "계통 평균").
- 형질 8개 = gs-model-performance 6형질(같은 이름·같은 h²·같은 GBLUP 정확도) + 수량 구성 요소 2개(수장, 주당 이삭수).

- 이미 알려진 관계를 따른다: 출수기–간장 양(+0.47, 늦게 피면 키가 큼), 수량–밥맛 약한 음(−0.20, 카탈로그 −0.3~−0.1), 수량–간장 +0.30·수량–도열병 +0.10·수량–밥맛 −0.20은 gebv-selection 생성 목표(`RHO_WITH_YIELD`)와 같다. 이삭수–천립중 음(−0.37)·수장–이삭수 음(−0.32)은 수량 구성 요소 보상 관계. 도열병 지수–밥맛 +0.15는 인디카 유래 저항성 유전자 주변의 연관 부담(저항성을 올리면 밥맛이 약간 떨어짐) 설정(**추정**). 웹 검색으로 확인한 수치는 없다.
- 상관 반응은 이론 기대값(무한 집단, 정규 가정, 1회 선발)이다. gebv-selection은 후보 600계통의 실제 선발 결과(절단된 분포, 앵커 포함)라 숫자가 조금 다르다: 수량 단일 p = 10% 수량 28.2 vs 실현 27.1, 간장 +1.44 vs +1.50 cm, 밥맛 −0.52 vs −0.43점, "수량 중시" 지수 수량 +24.3 vs +20.9. 화면 각주로 기준 차이를 밝힌다(검산 기록 참고).
- p = 10%의 수량 단일 선발 기대 반응 = 1.755 × 0.57 × 28.2 = 28.21 kg/10a/세대, ÷ L 2.2 = 12.8 kg/10a/년(2.29%/년) = baseline ΔG 2026과 같다.

## 화면 목적과 핵심 질문
1. 어떤 형질들이 유전적으로 함께 움직이나? — 군집 정렬로 "수량·구성 요소(수량·이삭수·천립중)"와 "생육·초형(출수기·간장·수장)" 두 묶음, 도열병·밥맛은 따로. 가장 강한 유전 상관은 출수기–간장 rG 0.47.
2. 표현형 상관만 보면 무엇을 잘못 읽나? — 쌀 수량–도열병은 rG +0.10인데 rP −0.16(환경 상관 −0.28: 병이 심한 환경에서 수량이 떨어짐). 부호가 다르다.
3. 지수 가중치가 상관 구조와 만나 어떤 부수 효과를 내나? — 수량 단일 선발은 간장 +1.4 cm, 밥맛 −0.52점, 출수 +1.2일 지연을 함께 낳고, "수량 중시" 지수는 수량 반응 86%를 지키며 그 손해를 없앤다.

해석 문장 규칙(D, 쌍 (x, y), 표시값은 원 실행값에서 한 번 반올림):
- 크기 등급 |rG|: < 0.10 "거의 없음", < 0.30 "약한", < 0.50 "중간", ≥ 0.50 "강한". 부호 "양의/음의".
- 조사 원칙: **숫자 바로 뒤에 조사를 붙이지 않는다**(숫자 읽기의 받침을 판정할 수 없어 "−0.10는", "0.27가" 같은 오류가 생김). 숫자는 괄호 안에 두고 조사는 괄호 앞 한글 낱말에 맞춘다. 형질 이름 뒤 조사는 받침 판정 함수(`josa`)로 자동 선택한다.
- 첫 문장: "{x}와(과) {y}의 유전 상관은 rG = {rG} ± {SE}로 {등급} {부호} 상관입니다"(등급 "거의 없음"이면 "상관이 거의 없습니다") + p ≥ 0.05면 "(유의하지 않음, p = 0.08, 95% 신뢰구간(−0.42~0.02)이 0을 포함)"(구간이 0을 포함하지 않으면 "95% 신뢰구간 −0.42~−0.02"), p < 0.05면 "(p < 0.001)" 형식.
- 둘째 문장(|rG| ≥ 0.10일 때): 둘 다 d ≠ 0이면 sign(rG)·d_x·d_y > 0 → "한쪽을 개량하면 다른 쪽도 함께 좋아집니다(동반 개량)", < 0 → "한쪽을 개량하면 다른 쪽은 나빠지는 쪽으로 작용합니다(상충)". 그 밖(한쪽 또는 둘 다 d = 0)은 **실제 선발 방향 s 기준**으로 방향만 서술한다. 주어 형질 = d ≠ 0인 쪽(둘 다 0이면 x), 주어 구 = 쌀 수량 "쌀 수량을 높이는", 밥맛 "밥맛을 높이는", 간장 "간장을 줄이는(단간화)", 도열병 "도열병 저항성을 높이는(발병 지수를 낮추는)", 출수기 "출수기를 앞당기는(조생화)", 천립중·수장·이삭수 "{이름}을(를) 늘리는". 상대 형질의 변화 부호 = sign(rG) · s_주어 → 양이면 "늘리는", 음이면 "줄이는"(출수기는 "늦추는"/"앞당기는", 도열병은 "발병 지수를 높이는"/"발병 지수를 낮추는"). 문형: "{주어 구} 선발은 {상대}을(를) {동사} 경향이 있습니다." 예: 간장–수장(rG +0.43) "간장을 줄이는(단간화) 선발은 수장을 줄이는 경향이 있습니다.", 도열병–이삭수(+0.14) "도열병 저항성을 높이는(발병 지수를 낮추는) 선발은 주당 이삭수를 줄이는 경향이 있습니다.", 출수기–간장(+0.47) "간장을 줄이는(단간화) 선발은 출수기를 앞당기는 경향이 있습니다.", 수량–출수기(+0.31) "쌀 수량을 높이는 선발은 출수기를 늦추는 경향이 있습니다."
- 셋째 문장: "표현형 상관(rP = {rP})은 유전 기여({g})와 환경 기여({e})의 합입니다." 예: "표현형 상관(rP = −0.10)은 유전 기여(−0.051)와 환경 기여(−0.053)의 합입니다."
- 부호가 다르고 |rG|, |rP| 모두 ≥ 0.05이면 넷째 문장: "유전 상관과 표현형 상관의 부호가 다릅니다. 환경 상관(rE = {rE})이 표현형 상관을 반대 방향으로 끌었습니다 — 표현형만 보고 선발 방향을 정하면 오해할 수 있습니다."

설계 rE는 생성에만 쓰고 화면에는 rP에서 역산한 rE를 보인다.

```
RG, RE = 대칭 8×8(대각 1), LG = cholesky(RG), LE = cholesky(RE)   // 표준 하삼각 콜레스키
mv(L) = { z = [rng.normal() for k in 0..7]; return L · z }          // 정규 8개를 먼저 다 뽑고 곱한다
rng = createRng(20261023)
for n in 0..1849:                       // 계통 순서대로, 계통마다 정규 24개
  u = mv(LG)   // 참 육종가(표준화)
  v = mv(LE)   // 환경(잔차, 표준화)
  w = mv(LG)   // GEBV 예측 오차 성분
  for t in 0..7:
    sE = σA_t · √((1 − h²_t)/h²_t)
    p  = μ_t + σA_t·u[t] + sE·v[t]
    if t == blast: p = clamp(p, 0, 9)                       // 발병 지수 척도
    pheno[n][t] = round(p, dp_t)
    gebv[n][t]  = round(r_t·σA_t·(r_t·u[t] + √(1 − r_t²)·w[t]), dg_t)   // 교차 검증 GEBV: corr(GEBV, BV) = r_t, SD = r_t·σA_t
// 계통명: 모든 계통의 형질을 만든 뒤 계통 순서대로
RESERVED = baseline·다른 템플릿 계통명 37개(검산 스크립트 RESERVED 배열 그대로)
used = Set(RESERVED)
for n: do { y = rng.int(2014, 2025); name = lineName 형식 "YR{yy}-{rng.int(1, 9999) 4자리}" } while used.has(name); used.add(name)
```
- `lineName(rng, 'YR', y)`를 쓰면 같은 소비 순서다(연도 `rng.int` 다음 번호 `rng.int`). 재생성 16회, 첫 계통 YR25-4559, 마지막 YR23-0519.
- rP·GEBV 간 상관·OLS는 **반올림된** pheno·gebv로 계산한다(화면 데이터와 같은 값).
- rG·SE·p·CI·군집·상관 반응은 상수에서 계산한다(생성 데이터를 쓰지 않음).
- UPGMA: 보이는 형질 집합에서 평균 거리 최소 쌍을 병합(동률이면 먼저 찾은 쌍, 탐색은 현재 군집 배열 순서의 이중 루프). 새 군집의 잎 순서 = (원래 인덱스 최솟값이 작은 군집) 뒤에 (다른 군집). 병합한 두 군집을 배열에서 빼고 새 군집을 끝에 붙인다.
