# 시험지 기상·환경 — 명세

slug `trial-site-environment` · category `kpi` · 기준일 2026-10-23 · 시드 20261023(기상 생성 `WX_SEED` = 20261023 + 7 = 20261030)

## 가정
- 작물: 벼(*Oryza sativa*, 12개 염색체, 약 430 Mb), 중부 평야지 프로그램. **program-baseline 준수**(2026 MET 결과 행, 연간 일정 "MET 이앙 5월").
- 사용자: 육종 연구원, 시험 관리자(지역 적응 시험 운영 담당).
- 사용 시나리오: 2026 지역 적응 시험(MET) 2년차 수확·분석이 끝난 2026-10-23에, 지역·연도별 수량 차이(환경 지수)가 어떤 기상 때문이었는지 정리하고, 이상 기상으로 해석에 주의해야 할 환경을 표시한다. met-gxe-stability(GxE·안정성 분석)의 "환경" 쪽 해설 화면이다.
- 지역·권역·환경 지수는 **met-gxe-stability를 그대로 따른다**: 경기 화성·경기 이천·충남 당진·충남 예산·충북 청주(중부 평야지), 전북 김제·경남 밀양(남부 평야지), 강원 철원(중북부지) 8곳 × 2025·2026 = 환경 16개. 환경 지수 I = 환경 평균 − 전체 평균 566.4 kg/10a(쌀 수량, 백미 기준), met-gxe-stability `ENVS[e].index` 원 실행값을 상수로 복제한다(아래 표). 범위 −65.9(철원 2026)~+60.0(당진 2025), 연도 평균 2025 +9.3 · 2026 −9.3(= met-gxe `YEAR_MEANS` 575.7 · 557.1 − 566.4).
- **기상 값은 모두 목업(가상)이다.** 실제 2025·2026년 관측값이 아니며 화면 머리말과 각주에 "기상 값은 목업(가상 관측)"을 표기한다. 값 범위는 중부·남부 평야지와 철원의 1991~2020 평년 근처에서 현실적으로 정했다.
- 평년: **1991~2020년 30년 평년**(기상청 현행 평년). 지역별 평년값은 인근 ASOS 지점(수원·이천·서산·홍성·청주·부안·밀양·철원)의 평년값을 근사한 **추정**이다(웹 확인 안 함). 화면에는 "평년 = 1991~2020 (인근 ASOS 지점 근사, 추정)"으로 쓴다.
- 재배기: 지역별 **이앙일~수확일**(연도마다 출수·수확일이 기상에 따라 달라짐). 이앙은 모두 5월(baseline "MET 이앙 5월"): 철원 05-14 ~ 밀양 05-30.
- 출수기: 대비 품종 가람솔(중만생) 기준. 기준 출수일(평년)에서 6~7월 기온 편차로 앞당기거나 늦춘다(규칙은 아래).
- 유효적산온도(GDD): **기준 온도 10 °C**, 일평균기온 방식 Σ max(0, Tmean − 10), 상한 미적용, 재배기(이앙~수확) 합.
- 고온 일수: 출수 전 15일~출수 후 15일(31일) 중 일 최고기온 ≥ 33 °C인 날(폭염 기준). 이 중 ≥ 35 °C(개화기 고온 불임 위험 임계)는 따로 센다.
- 저온 일수: 같은 31일 창에서 일 최저기온 ≤ 17 °C인 날. 경보는 감수분열기~출수기(출수 전 15일~출수일, 16일)만 본다(장해형 냉해 위험).
- 등숙기: 출수 다음 날부터 40일. 등숙 적온은 일평균 21~23 °C로 보고 "적온 이탈" = |등숙기 평균기온 − 22|.
- 수확일: 출수 다음 날부터 일평균기온을 누적해 **1,100 °C·일**에 처음 도달한 날(메벼 수확 적기 관행 1,100~1,200 °C 중 하한, 추정 인용).
- 상관 분석은 n = 16(지역 8 × 연도 2) Pearson. 지역 주효과(토양·관리)가 섞여 있으므로 "상관 ≠ 인과" 각주를 단다.

## 화면 목적과 핵심 질문
1. 2026년 시험지 기상은 평년과 어떻게 달랐나? — 8개 지역 평균 유효적산온도는 평년보다 +31 °C·일 높았지만 강수량 111%, 등숙기 일조 95%로 일조가 부족했다(2025년은 등숙기 일조 107%).
2. 환경 지수(지역·연도 평균 수량 − 전체 평균)를 가장 잘 설명하는 기상 요인은? — 등숙기 일조시간(r = 0.73, p = 0.001). 일조로 설명되지 않는 큰 하락 4개 환경은 모두 밀양(출수기 고온)·철원(감수분열기 저온)이다.
3. 어느 시험지에 해석 주의가 필요한가? — 2026년 경보 4건: 밀양 고온 불임 위험(≥ 35 °C 12일), 철원 장해형 냉해 위험(≤ 17 °C 4일), 당진 호우(229 mm, 09-03), 청주 등숙기 일조 부족(평년의 78%).

### 2) 일 값 생성(환경 e = 0..15 순서, 환경마다 ar = 0으로 시작)

```
for k in 0..183:
  m = monthOf(k); clim = interp(mids, k); anom = interp(dT8, k)     # mids = climMids(tmp), 지역마다 1회
  ar = 0.7·ar + rng.normal(0, 0.9)                       # ① AR(1) 기온 잡음
  bump = Σ 이벤트 dT (k가 heat/cold 구간 안), heatEv = heat 구간 안
  Tmean = clim + anom + ar + bump
  pp = RAIN_DAYS[m] / MONTH_DAYS[m]
  rainEv = (k가 rain 이벤트 날짜)
  wet = rng.next() < pp·(heatEv ? 0.3 : 1)  ||  rainEv  # ② (rng는 항상 소비)
  u = rng.next()                                          # ③ (항상 소비)
  prRaw = wet ? −ln(1 − u) : 0
  kDry = (1 − 0.25·pp) / (1 − pp)
  sunRaw = max(0, (wet ? 0.25 : kDry) + rng.normal(0, 0.2))   # ④
  Tmax = Tmean + (wet ? 2.8 : dtr[0]) + rng.normal(0, 0.8)    # ⑤
  Tmin = Tmean − (wet ? 2.0 : dtr[1]) + rng.normal(0, 0.8)    # ⑥
for m in 0..5:                                            # 월 합 척도화
  prTarget  = pr[m]·rain[m]·exp(rng.normal(0, 0.15))      # ⑦
  sunTarget = sun[m]·sun배율[m]·(1 + rng.normal(0, 0.04))  # ⑧
  그 달 각 날: pr = prRaw·prTarget/Σ prRaw, sun = min(13.5, sunRaw·sunTarget/Σ sunRaw)
rain 이벤트 날: pr += mm (척도화 뒤에 더함)
```
`normal`은 Box–Muller 여분 값을 쓰므로 호출 순서를 바꾸면 모든 값이 달라진다(①④⑤⑥⑦⑧ 순서 고정).
