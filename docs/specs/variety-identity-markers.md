# 품종 식별 마커 프로필 — 명세

- slug: `variety-identity-markers` · 카테고리: `viz` · 기준일 2026-10-23 · 시드 20261023(난수 미사용, 모든 값은 확정 상수와 그 계산값)

## 가정

- 작물: 벼(*Oryza sativa*, 12개 염색체, 약 430 Mb, 자식성 고정 계통). 중부 평야지 가상 육종 프로그램. **program-baseline 준수**(「KASP 대립유전자 방향」, 「품종·계통 하플로타입 보유」, 「YR19-0118」, 「종자 재고」, 계보·품종 행).
- 사용자: 종자 관리·품종보호 담당자(품종 식별 DB 관리, 출원 서류용 DNA 프로필, 채종 로트 순도 관리).
- 사용 시나리오: (1) 출원 예정·검토 계통이 기존 프로그램 품종과 DNA 프로필로 식별되는지 확인, (2) 16마커로 식별이 어려운 쌍을 찾아 보강 분석 계획, (3) 채종포 수확분(입고 전) DNA 순도 검정 결과로 입고 여부 판정.
- 대상 10품종·계통(행 순서 고정): 출원 후보 3(YR19-0118 가칭 '들솔미' 출원 예정 2026-12, YR20-0342·YR20-0527 2027 출원 검토) → 출원·심사 중 2(별하랑 2026-06-09 출원, 해솔가온 2025 출원·재배심사 중) → 등록 3(늘솔찬 2026, 솔빛나래 2024, 청여울 2022) → 대비 품종 2(온새미로 2025 등록 — MET 대비·YR19-0118의 DUS 대조, 가람솔 2020 등록 — 표준 대비). 다른 프로그램 품종(다올미 등 8개)은 이 화면 범위 밖으로 두고 각주에 밝힌다.
- KASP 16마커(crossing-record `MARKERS` 순서): 기능 11(Pi9·Pi-ta·Pib·Pigm·Xa21·xa5·Bph18·Wx·Hd1·sd1·GS3) + ID 5(ID02·ID04·ID07·ID09·ID11). 0 = AA, 2 = BB(고정 계통이라 기준 프로필에는 이형 없음). **기능 마커 BB = 효과(표적) 대립유전자, ID 마커 BB = 대체 대립유전자(IRGSP-1.0 기준).**
- 일관성 고정점(실행으로 확인, 「검산 기록」):
  - variety-application-brief `KASP` 4품종(YR19-0118·온새미로·늘솔찬·가람솔) 행 그대로 복사.
  - haplotype-viewer 7품종·계통 × 5좌위(sd1·Hd1·GS3·Pi-ta·Pi9) 표적 보유(`carry`)와 KASP BB가 35칸 모두 일치.
  - 계보(pedigree-explorer `PEDIGREE`)의 부모가 프로필에 있는 4조합(별하랑 = 가람솔/늘솔찬, 늘솔찬 = 청여울/솔빛나래, YR19-0118 = 온새미로/늘솔찬, 해솔가온 = 온새미로/미프로필 YR10-0866)과 crossing-record `PARENT_GENO` YR22-0412·0415(= 별하랑/해솔가온)에서 자식의 모든 마커가 부모 한쪽과 같다(불일치 0).
  - pedigree-explorer 보유 유전자 목록(청여울 Pi-ta·Pib·sd1, 솔빛나래 Xa21·sd1, 늘솔찬 Pi-ta·Pib·Xa21·sd1, 해솔가온 sd1, 별하랑 Pi-ta·Pib·sd1, 가람솔 sd1)과 BB가 일치. **예외(이 템플릿 밖 기존 불일치):** pedigree-explorer는 온새미로에 sd1을 표시하지만 haplotype-viewer(유리 0)·variety-application-brief(sd1 AA)는 비보유다. 이 템플릿은 program-baseline「KASP 대립유전자 방향」 규칙(sd1 = haplotype-viewer 판정)대로 **AA**로 둔다. `docs/backlog/baseline.md`에 등록됨(2026-10-30, pedigree-explorer 쪽 수정 후보).
  - 순도 검정 로트 = seed-inventory 로트 ID·입고량·입고일(L25-001~005, L26-001~005).
  - 재확인 상태 = variety-application-brief `KASP_STATUS`·seed-inventory RQ26-041(5품종·계통 × 20립, 출고 2026-10-14, 결과 대기).
- 순도 검정 방식(추정, 이 템플릿이 새로 정하는 사실): 채종포(본장 채종포 C-1) 구획별로 **수확 전 이삭 시료**를 188이삭에서 1립씩 채취(이삭 1개 = 1주 → 혼입형 이형립은 이형주와 같다), 1립 DNA로 KASP 16마커 분석(96웰 2판 × 94시료, 판마다 기준 품종 DNA 1웰 + NTC 1웰). 시료는 입고량 밖이라 seed-inventory 원장에 차감이 없다. 합격 구획 수확분만 입고한다. 2026: 채취 09-14 → 판정 09-22 → 입고 10-02(seed-inventory L26 입고일), 2025: 채취 09-15 → 판정 09-23 → 입고 10-01(L25 입고일). 시료는 2026 KASP 누계 8,366샘플에 포함된 것으로 보고 genotyping-lab-ops 월별 값은 바꾸지 않는다.
- 합격 기준(육종 기관 내부 기준, 추정): variety-application-brief 균일성과 같은 이항 수용 방식 — **집단 기준 이형률 0.1%, 수용 확률 95% 이상**인 최소 허용 수 k. 판독 52~355립이면 k = 1. 국가 종자검사(포장·종자 검사) 기준과는 별개라고 각주에 밝힌다.
- 품종명은 모두 가상, 유전자 이름은 실제이나 보유 여부는 가상이다.

## 화면 목적과 핵심 질문

1. 이 10개 품종·계통은 KASP 16마커로 서로 식별되는가? → 45쌍 중 **44쌍 식별 가능(97.8%)**, **식별 곤란 1쌍(YR20-0342 ↔ 온새미로, ID09 1개)**.
2. 출원 예정 YR19-0118과 가장 가까운 품종은? → **청여울 3개(Pi-ta·Hd1·sd1)**. DUS 대조 온새미로와는 5개. (마커 차이는 식별 참고 자료이며 구별성은 형질로 판정)
3. 올해 채종 로트 순도는 합격인가? → 2026 검정 **6건 중 5건 합격**, YR20-0527 북측 구획 **이형립 4/185(97.84%) 불합격 → 입고 제외**. 입고 로트 5개 합계 이형립 1/934.
