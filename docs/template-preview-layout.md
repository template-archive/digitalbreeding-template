# 템플릿 상세 화면의 영역 구분

상세 화면은 라이브러리 도구, 템플릿 미리보기, 다른 템플릿 탐색의 세 영역으로 구성합니다.

- 상단: 라이브러리로 돌아가기, 카테고리·상태·태그, 템플릿 설명과 프로젝트에 가져오기.
- 가져오기: 큰 상시 카드 대신 버튼으로 열리는 모달. 코드 ZIP, 샘플/목업 데이터, 명세와 적용 가이드를 제공합니다. 키보드 포커스와 Esc는 모달이 처리하고 닫으면 트리거로 돌아갑니다.
- 미리보기: 별도 테두리와 안쪽 여백. 상단 프레임 바에 미리보기 모드·화면 폭·테마·임베드 열기를 모으고, 하단에는 미리보기 끝을 표시합니다. 프레임 안에는 템플릿 또는 사용자 데이터 결과만 렌더합니다.
- 탐색: 미리보기 프레임 밖의 다른 템플릿 영역. 큰 이미지 카드를 제거하고 이전/다음 제목과 전체 목록 링크를 제공합니다.

폭 선택은 프레임 안에서 실제 사용할 수 있는 폭을 기준으로 합니다. 프레임에는 overflow 숨김이나 별도 세로 스크롤을 추가하지 않으므로 기존 sticky iframe과 템플릿의 스크롤을 유지합니다. 인쇄에서는 프레임 장식과 도구를 숨기고 인쇄 캔버스를 평탄화합니다.

다운로드 모달은 native dialog로 포커스를 격리합니다. 열려 있는 모달의 C/Esc 키를 피드백 도구가 가로채지 않으며, 모달로 포커스가 이동해도 뒤의 코멘트 초안을 지우지 않습니다. 업로드 데이터 미리보기와 기존 피드백 저장 범위는 동일합니다.
