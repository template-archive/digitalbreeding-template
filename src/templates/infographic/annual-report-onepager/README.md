# 연간 성과 원페이저

- 카테고리: infographic · 캔버스 A4 세로(`ScaledCanvas` 1240×1754, `print="a4-portrait"`)
- 명세: `docs/specs/annual-report-onepager.md`

## 목적
기관장·외부 보고(정책 담당자·평가위원·협력 기관)용 한 장 요약. 2026년 벼 디지털육종 프로그램이
1) 얼마나 성과를 냈는지(연간 유전적 개량량 2.29%/년, 2019년의 3.1배(예측) · 실현 2.6배, 목표 대비 93.8%),
2) 무엇을 내놓았는지(별하랑 출원, 늘솔찬 등록, 유전형 분석 10,742샘플),
3) 무엇이 모자란지(출원 1/3건, MET 완료 18/25계통, ΔG 목표 미달)를 숨기지 않고 보여 준다.
2026-10-23 기준 잠정치이며 화면 그대로 인쇄(PDF 저장)한다.

## 화면 구성(위 → 아래)
A 머리(표제 라벨 → 큰 표제 → 부제, 오른쪽 기준일·ΔG 추이: 0 기준 선, GS 도입·목표·잠정 표식) → B 핵심 수치 4개 → C 요인 변화 띠
→ E 2026 마일스톤(①~⑧, 기준일 세로선, ⑧ 예정 점선) → F 파이프라인 숫자 블록(같은 해 단계 수 비 화살표, MET = 그해 완료 세트, 목표 미달)
→ G 대표 성과 3개 → H 남은 과제 → I 각주. 640px 미만에서는 캔버스 위에 "핵심 요약"(인쇄 제외)을 보인다.

## 사용 지표
연간 유전적 개량량(ΔG = i · r · σA / L, %/년 = ΔG / 560 × 100), 예측 정확도 r, 세대 간격 L, 달성률(높을수록 좋음 = 실적/목표, L = 목표/실적),
신품종 출원·등록, 유전형 분석 처리량, 훈련 집단 크기, 파이프라인 단계별 계통 수·같은 해 단계 수 비, AYT → MET 코호트 진급률, 6K SNP 칩 콜레이트·QC·TAT.

## 실제 데이터로 교체하기
`data.ts`의 상수(I·R·SIGMA_A·L·TARGET_2026·PIPELINE·APPS·LAB·BYEOL·MILESTONES 등)를 성과 집계 API 응답으로 바꾼다.
파생 값(ΔG·달성률·배율·단계 수 비·진급률·마일스톤 x 위치)은 모두 계산식이라 그대로 둔다. 현재 상수는 program-overview·digital-breeding-process·
variety-profile·genotyping-lab-ops 템플릿 값을 복제한 것이다(템플릿 간 import 금지). 마일스톤 ①②④의 월은 이 템플릿의 추정값이다.
