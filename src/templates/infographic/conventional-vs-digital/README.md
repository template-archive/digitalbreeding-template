# 전통 육종 vs 디지털육종

- 카테고리: infographic · 캔버스 1920 × 1080(16:9) · A4 가로 인쇄
- 명세: `docs/specs/conventional-vs-digital.md`

## 목적
정책 결정자·예산 심의 담당자·외부 방문객에게 "디지털육종으로 바꾸면 무엇이 얼마나 달라지고, 왜 빨라지며, 돈은 얼마나 더 드는가"를 한 장으로 답한다.
단계 흐름(7단계 카드·기간 타임라인)은 `infographic/digital-breeding-process`가 맡고, 이 화면은 지표별 좌우 대비와 ΔG 구성 요소 기여를 맡는다.

## 화면 구성
1. **제목 띠** — 핵심 문장(ΔG 3.1배(예측) · 실현 2.6배 표기 규칙, 개발 기간 4.3년 단축·설계값), 기준일, 전통/디지털 범례(빗금 회색 / 강조 단색 + 문자 라벨)
2. **지표별 대비(나비형 표)** — 9행, 4묶음(시간·선발·규모·비용·성과). 막대는 가운데 0 기준선에서 시작하고 같은 행 안에서만 같은 축. 변화 배지는 "단축·향상·증가·감소" 글자로 방향을 밝힘
3. **왜 빨라지는가(폭포 차트, 정적 SVG)** — 전통 ΔG → i·r·σA·L 기여(연도별 LMDI 합산) → 디지털 ΔG. 원값으로 쌓고 라벨만 반올림. 아래에 ΔG = i · r · σA / L 식 두 줄
4. **비용 대비 성과** — 연간 직접비와 개량 1 kg/10a당 연간 직접비(추정)
5. **각주** — 목업 고지, 비교 기준 시점, 예측값·실현 추세, 비용 가정. 모든 숫자는 `data.ts` 상수에서 끼워 넣음

390px에서는 캔버스 위에 모바일 요약 카드 4개(`data-print-hide`)를 두고, 캔버스는 최소 배율 0.6 + 가로 스크롤로 보여 준다.

## 사용 지표
품종 개발 기간, 세대 간격(L), 선발 정확도(r), 선발 강도(i), 상가적 유전 표준편차(σA), 연간 유전적 개량량(ΔG, kg/10a/년·%/년), ΔG 구성 요소 기여(LMDI), 사이클당 평가 계통 수, 시험 규모(시험구), 연간 직접비, 개량 1 kg/10a당 직접비. 정의는 `breeding-metrics` 카탈로그와 `program-baseline.md`를 따른다.

## 실제 데이터로 교체하기
`data.ts`의 상수(`I`, `R`, `SIGMA_A`, `L`, `PIPELINE`, `DEV_YEARS`, `TRIAL_YEARS`, `REALIZED`, `COST`)만 바꾸면 파생값(`DG`, `CONTRIB`, `SHARE`, `N_PLOTS`, `ANNUAL_COST`, `COST_PER_GAIN`, `COST_PER_GAIN_REALIZED`, `WATERFALL`)과 화면 문구가 따라 바뀐다.
- 비교 시점은 `BASIS`로 바꾼다. LMDI는 연도별 분해를 합산하므로 `YEARS` 사이 모든 연도의 i·r·σA·L이 필요하다.
- 상수는 `kpi/program-overview`, `infographic/digital-breeding-process`, `kpi/genetic-gain-tracker`에서 복제했다(템플릿 간 import 금지). 기준값이 바뀌면 세 곳과 함께 맞춘다.
- DEV 모드에서 `[검산] [conventional-vs-digital]` 검산이 수용 기준 숫자를 확인한다. 상수를 바꾸면 기대값도 바꾼다.
