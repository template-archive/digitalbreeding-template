# 디지털육종 프로세스

- 카테고리: infographic

## 목적
기관 소개 자료·발표 슬라이드·인쇄 브로슈어에 넣는 16:9 한 장 인포그래픽이다. 세 가지 질문에 답한다.

1. 벼 품종 하나를 만드는 기간이 얼마나 줄었나: 11.0년 → 6.7년(4.3년, −39.1%)
2. 어느 단계에서 줄었고, 어떤 단계가 새로 생겼나: 세대 진전·선발·시험 단축, 유전형 분석·GEBV 예측 신규(+0.2년)
3. 단계마다 어떤 데이터가 쓰이고 얼마나 정확한가: 2,000계통 유전형 분석, r = 0.57, L = 2.2년, ΔG 3.1배(예측) · 실현 2.6배

## 구성
| 영역 | 내용 |
| --- | --- |
| A. 머리 | 표제 라벨(프로세스 이름·기관명), 큰 표제(결론), 부제(작물·형질·연도), 오른쪽 기준일 배지·개발 기간 비교 도식 |
| B. 핵심 숫자 | 개발 기간(가장 크게), 세대 간격(L), 예측 정확도(r), 연간 유전적 개량량(ΔG) |
| C. 흐름도 | 7단계 카드(디지털 기간 크게, 전통 기간·단축 배지, 핵심 데이터) + ⑤→① 재순환 화살표와 ΔG 식 |
| D. 타임라인 | 공통 0~12년 축 가로 누적 막대 2줄(전통 = 빗금·옅은 색), L 눈금, 단축 괄호 |
| E. 각주 | 목업 고지, 설계값(예상) 설명, 정확도 산출 조건, 근거, 가상 고지 |

## 사용 지표
품종 개발 기간, 단계별 소요 기간, 세대 간격 L = ①~⑤ 합, 세대 진전 속도(F2~F6 5세대 ÷ 기간),
예측 정확도 r(GBLUP, 5-fold × 10회), 선발 강도 i, σA, ΔG = i·r·σA/L(%/년 = ΔG/560×100),
계통 선발 30%(i = 1.159)·평균 GEBV = i × r × σA, 시험 단계 계통 수(PYT → AYT → MET).
합계·단축·단축률·L·ΔG·배율·평균 GEBV는 모두 `data.ts`에서 계산한다(하드코딩 없음).

## 캔버스와 인쇄
- 공통 `ScaledCanvas`(`@/design-system`, 기준 1920×1080): `--u = 100cqw / 1920`을 1 논리 픽셀로 쓰고 모든 크기를 `u(n)`으로 지정해
  부모 너비가 바뀌어도 줄바꿈 변화 없이 비례 축소된다. 기본 `minScale` 0.6 — 1152px보다 좁으면 그 폭에 고정하고 가로 스크롤한다(안내 문구 표시).
- 인쇄: `print="a4-landscape"` → `@page A4 landscape, margin 10mm`, 캔버스 너비 277mm(높이 약 156mm), `print-color-adjust: exact`.
  갤러리 헤더·사이드바는 공통 인쇄 계약(`data-print-hide`·`data-print-flat`, `src/index.css`)으로 숨는다.
- 흑백 대비: 단계 번호 칩, "전통/디지털" 문자 라벨, 전통 막대 빗금.

## 실제 데이터로 교체하기
`data.ts`의 `STAGES`(단계별 전통·디지털 기간과 카드 문구), `PARAMS`(i·r·σA), `GENOTYPING`, `TRIALS`, `TRAIN_N` 등을
기관 값으로 바꾸면 합계·L·ΔG·배지·타임라인이 자동으로 다시 계산된다. 단계 수를 바꾸면 `index.tsx`의 `CARD_W` 계산(7열)과
`stageColor`(범주형 8색)를 함께 조정한다.
