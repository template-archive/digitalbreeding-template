# MAS 여교배 사례

- 카테고리: infographic · 캔버스 1920 × 1080(16:9), A4 가로 인쇄, 390px 모바일 요약
- 명세: `docs/specs/mas-backcross-story.md`

## 목적
외부 청중(방문객, 정책·예산 담당자, 언론)과 연구 관리자에게 "익숙한 품종에 저항성 유전자 하나만 더한다"를 한 장으로 보여 준다.
대비 품종 가람솔(반복친)에 도열병 저항성 유전자 Pi9를 YR20-1108(공여친)에서 마커 보조 여교배(MABC)로 옮긴 사례.

읽는 순서: A 제목 → B 큰 숫자 4개 → C 세대 흐름 ①~⑦(개체 깔때기, 선발 개체 회복률, 미니 게놈 띠) → D 회복률 점 그래프 · 최종 계통 염색체 · 기존 여교배 대비 기간 → E 각주.

## 사용 지표
- 반복친 게놈 회복률(RPG): 다형성 SNP 1,523개에서 (2·반복친형 동형 + 이형) / (2 × 1,523), 운반 염색체 포함
- 이론 회복률 BCt = 1 − (1/2)^(t+1)
- 전경·재조합·배경 선발 통과 개체 수, KASP·6K 분석 규모
- 표적 주변 공여친 단편(연관 끌림), 기대 연관 끌림(모의 상수)
- 세대 수·소요 기간(기존 여교배 가정 대비 단축)
- 2026 관찰 포장 검증 형질(잎도열병 발병 지수, 출수, 간장)

## 실제 데이터로 교체하기
- `generate()`를 세대별 KASP(전경·측면 마커) 판정과 6K 칩 유전형 로더로 바꾸고 `{ markers, gens, dose }` 형태를 유지하면 화면은 그대로 동작한다.
  `gens[]`는 `{ gen, n, carriers, recL, recR, chip: {id, rpg}[], selected: {id, rpg, ind}[] }`. 실제 데이터에서는 `ind`(반수체 구간) 대신 마커별 dose 배열을 받아 `dose` 함수를 그에 맞게 만든다.
- `SCHEDULE`, `VERIFY_2026`, `CONVENTIONAL`, `DRAG_EXPECTED`는 과제 기록·가정 상수다.
- 가람솔·YR20-1108 형질, 6K 칩 마커 수, KASP 패널·TAT는 다른 템플릿(variety-profile, crossing-record, genotyping-lab-ops)과 같은 값을 복제해 두었다(템플릿 간 import 금지). 6K는 외부 위탁(분석실 누계 밖), KASP 2026년분 188은 분석실 KASP 누계에 포함.
- 차트는 ECharts 대신 정적 SVG다(인쇄 선명도, 툴팁 없음). 스크린리더용 sr-only 표가 같은 값을 담는다.
