# 신품종 출원 요약서

- 카테고리: infographic · 캔버스 A4 세로 1240 × 1754(`ScaledCanvas print="a4-portrait"`)
- 명세: `docs/specs/variety-application-brief.md` · 기준일 2026-10-23 · 시드 20261023(난수 미사용)

## 목적

출원 예정 계통 YR19-0118(가칭 '들솔미')의 품종보호 출원 근거를 내부 검토 회의·심사 대응용 A4 한 장으로 모은다.
"출원 근거가 충분한가(신규성·구별성·균일성·안정성·명칭)"에 답한다. 출원 완료 품종의 보급용 소개 카드(`variety-profile`)와 역할이 다르다.

읽는 순서: 머리(표제 라벨 → 큰 표제 → 결론 부제, 오른쪽 연도별 쌀 수량) → 근거 숫자 4개 → ① 요건 점검 → ② 육성 경위 → ③ MET 성적·재배 적지 → ④ 주요 특성 → ⑤ 구별성·균일성 → ⑥ KASP 식별 마커 → ⑦ 출원 일정 → 각주.

## 사용 지표

| 영역 | 지표 | 출처 |
| --- | --- | --- |
| 근거 숫자 | 쌀 수량 MET 2년 평균·지수·LSD(5%), ASV·W·b, 명확한 차이 형질 수, 이형주 | met-gxe-stability 원 실행값, 이 템플릿 DUS 상수 |
| ③ MET | 지역 8곳 증감 %(0 = 대비 가람솔), 권역 지수(권역 평균끼리 나눔), 메가 환경 승자 | met-gxe-stability, `@/charts` MET_ZONES·metZoneColor |
| ④ 주요 특성 | 6형질 비교, 판정 = \|차\| > LSD(5%) | 명세 「주요 특성」 |
| ⑤ 구별성 | 대조 품종 온새미로와 2년 비교, 명확한 차이 = 2년 모두 \|차\| > LSD(1%)·같은 방향 | UPOV TG/16/9 |
| ⑤ 균일성 | 허용 이형주 = P(X ≤ k \| 400, 0.001) ≥ 0.95인 최소 k(이항 분포 계산 → 2) | UPOV TG/16/9 4.2.6 |
| ⑥ KASP | 16마커 × 4품종, 차이 마커 수, 친자 일치(모본형·부본형) | crossing-record 마커 순서, haplotype-viewer 5좌위 |
| ② 육성 경위 | GS 1차 GEBV 순위(정규 근사), 2023 코호트 계통 수, 개발 기간 | program-overview, breeding-pipeline-flow |
| ⑦ 일정·종자 | 출원 일정 8항목, 로트 잔량·발아율 | seed-inventory |

판정·차·지수·허용 이형주·마커 차이·순위·요건 상태·개발 기간·종자 합계와 화면 문장·ariaLabel의 숫자는 모두 `data.ts` 상수에서 계산한다. 명세의 수용 기준 숫자는 `data.ts` 끝의 DEV 검산(`console.assert` + `[검산]`)으로 확인한다.

## 구성 파일

- `components/YearBars.tsx` — 머리 오른쪽 연도별 쌀 수량 막대(0부터)·지수
- `index.tsx` — 캔버스 조립, 머리·근거 숫자(공통 `CanvasBigNumber` compact·라벨 위)·요건 띠·계보·권역 블록·각주, 390px `MobileSummary` 2개
- `components/LineageTimeline.tsx` — 2019~2029 가로 타임라인(SVG)
- `components/SiteBars.tsx` — 지역 발산 막대(SVG)
- `components/TraitTable.tsx`, `DusPanel.tsx`, `KaspGrid.tsx`, `Schedule.tsx` — 표·격자·일정
- `components/style.ts` — 강조색, 판정 기호, KASP 차이 셀 사선

## 실제 데이터로 교체하기

`data.ts`의 export 형태(`MET`, `SITES`, `TRAITS`, `DUS`, `UNIFORMITY`, `KASP`, `TIMELINE`, `SCHEDULE`, `SEED_LOTS`)를 유지한 채 MET 분석 결과·DUS 조사 원장·KASP 분석 결과·종자 원장 API 응답으로 바꾼다. 판정과 요건 상태는 계산 함수가 다시 만든다. DEV 검산은 목업 숫자를 고정하므로 실데이터로 바꾸면 지운다.

## 인쇄·접근성

- 흑백 인쇄 대비: 판정은 기호 + 문자(✓·•·=, ● 명확한 차이, ✓/△ 요건), KASP 차이 셀은 사선 + "≠", 권역은 묶음 머리글 문자.
- 차트는 정적 SVG(툴팁 없음, 인쇄와 화면이 같다). SVG마다 결론형 `aria-label`, KASP는 실제 `<table>`.
