# 신품종 소개 카드

- 카테고리: infographic
- 명세: `docs/specs/variety-profile.md`
- 연결 템플릿: `kpi/program-overview`(출원 목록 R15·R1·R10, μ = 560, 2022 r·σA·파이프라인), `infographic/digital-breeding-process`(전통 11.0년, 디지털 설계값 6.7년). 공유 수치는 `data.ts`에 복제하고 출처 주석을 남겼다.

## 목적
보급 설명회 배포물·품종 소개 책자·전시 패널용 A4 세로 한 장 인포그래픽이다. 가상 신품종 '별하랑'(YR19-0083)에 대해 세 가지 질문에 답한다.

1. 지금 쓰는 품종(가람솔)보다 무엇이 나은가: 쌀 수량 605 kg/10a(대비 108.0%, +45), 잎도열병 2점(저항성), 간장 −4 cm
2. 어디에 심으면 좋은가: 중부 평야지(111.5%), 중북부지 부적지(98.5%)
3. 어떻게, 얼마나 빨리 만들었나: 2019 교배 → 2022 GS 선발 → 2026-06-09 출원, 7년(전통 11.0년보다 4.0년 짧음)

## 구성
| 영역 | 내용 |
| --- | --- |
| A. 머리 | 표제 라벨(기관명), 품종명(가장 큰 글씨)·계통명, 한 줄 소개, 부제(작물·유형·숙기·상태·출원일), 오른쪽 기준일·교배 조합 도식 |
| B. 핵심 숫자 | 쌀 수량(가장 크게), 잎도열병 발병 지수, 출수기, 개발 기간 + 대비 품종·성적 기준 한 줄 |
| C. 무엇이 나은가 | 수량 원값 막대(축 0~700) + 형질 6행 비교 표(증감 % 발산 막대는 수량·간장·천립중만, 도열병 0~9 눈금 띠, 판정 = \|차\| > LSD) |
| D. 어디에 심으면 좋은가 | 권역 요약 3블록 + 재배 적지/부적지/재배 요령, 지역 8곳 가로 발산 막대(0 = 대비 품종, 권역별 묶음) |
| E. 무엇이 들어 있나 | 염색체 12개 트랙(길이 비례) 위 유전자 6개 위치 + 보유 유전자 표, 도열병 지수와 Pi-ta·Pib 연결 설명 |
| F. 어떻게 만들었나 | 2019~2028 타임라인: 단계 막대, GS 선발 강조 콜아웃, 출원 굵은 표식, 기준일 점선, 재배심사 점선(예정), 교배~출원 7년 괄호 |
| G. 각주 | 목업·가상 고지, 성적 출처, 과도기 계통 설명 |

레이더 차트는 쓰지 않는다(형질마다 척도·좋은 방향이 다름). 출수기·도열병·식미치에는 % 지수를 만들지 않는다.

## 사용 지표
쌀 수량, 수량 지수·차, 연차별 지수, 출수기(파종 후 일수), 간장, 천립중, 잎도열병 발병 지수(0~9, 등급 0~3/4~6/7~9), 식미치, LSD(5%) 판정,
지역별·권역 평균 수량 지수(권역 평균 수량끼리 나눔), 보유 유전자 수(5종 중), GS 선발 당시 GEBV·순위, 품종 개발 기간(출원 연도 − 교배 연도).
지수·차·판정·평균·권역 지수·재배 적지·보유 수·개발 기간·단축 연수·순위 비율은 모두 `data.ts`에서 계산한다. 개발 모드에서 검산(지역·연도 평균 = 형질 표, 대비 = μ, 7년, 유전자 위치 < 염색체 길이)이 실패하면 콘솔 경고를 낸다.

## 캔버스와 인쇄
- 공통 `ScaledCanvas`(`width=1240 height=1754 print="a4-portrait"`). 모든 크기는 `u(n)`, 차트는 정적 SVG(인쇄 선명도, 툴팁 없음).
- 인쇄: A4 세로 한 쪽, 여백 10mm, 갤러리 내비게이션은 공통 인쇄 계약으로 숨는다.
- 흑백 대비: 대비 품종 막대 빗금 + 이름 라벨, 보유/미보유 ●/○ + 문자, 판정 ▲/▼/= + 문자, 권역 묶음 머리글 문자.
- 최소 글자 13 논리 px(각주·염색체 라벨), 본문 14~17 px.

## 실제 데이터로 교체하기
`data.ts`의 `VARIETY`, `CHECK`, `TRAITS`(v·c·lsd·dir·ratio·words), `YIELD_BY_YEAR`, `SITES`, `GENES`, `GS2022`, `TIMELINE`을 품종 값으로 바꾸면
문구·막대·판정·권역 요약이 다시 계산된다. 지역 수가 바뀌면 `SiteBars`의 높이가 자동으로 늘어나므로 `index.tsx`의 D 영역 높이(`u(296)`)를 함께 조정한다.
지역 증감 축 범위(−4~+14%)는 `components/SiteBars.tsx`의 `X_MIN`/`X_MAX`, 형질 증감 막대 배율은 `components/TraitTable.tsx`의 `DV_PX`에서 바꾼다.
