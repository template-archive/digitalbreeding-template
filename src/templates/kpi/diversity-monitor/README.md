# 유전 다양성 모니터 (`kpi/diversity-monitor`)

부모 재순환 집단(부모 선발 후보)의 유전 다양성이 경보 기준 안에 있는지, GS 도입 뒤 다양성 손실이 왜 빨라졌는지(세대당 증가 vs 세대 간격 단축), 최적 기여 선발(OCS)로 근교 증가를 묶으면 ΔG를 얼마나 잃는지 보여 주는 KPI 대시보드. 작물은 자식성 벼(가상 "중부 평야지 벼 육종 프로그램"), 값은 모두 가상 목업이다.

명세: `docs/specs/diversity-monitor.md`

## 화면 구성

| 영역 | 내용 |
| --- | --- |
| 결론 패널 | 대표 값 연간 ΔF + 판정 한 문장(OCS 기본값 0.75% 기준 고정) + 연도별 추세·상한(`PanelTrend`). 세대당 ΔF는 값 이름 줄 |
| 받치는 KPI 4개 | Ne, 평균 공조계수 f̄, He, 고정 마커 — 증감 색은 지표 방향 |
| 경보 목록 | 경보 1 + 주의 3, 클릭하면 해당 차트로 스크롤·포커스 |
| 차트 | Ne 추이(95% 구간 띠, 50·60 기준선), 근교 증가율 세대당/연간(상한선·분해 문구), f̄·He 추이, 그룹별 He, 마커 고정·희소 |
| 근연 요약 | 강한 근연 49쌍·근연 주의 29쌍·근연 군집 13개·F 평균 0.970(`KinBadge`) |
| 시나리오 | OCS 슬라이더(0.40~1.00%) + 이득-다양성 경계, 아래 12열 3행 비교 표 |
| 연도별 표 | 8행, 최신 연도 먼저, 첫 열 고정 |

## 지표 정의(요약)

- Ne = 1/(2ΔF세대) (연도별 상수, 추정), ΔF연 = 1 − (1 − ΔF세대)^(1/L)
- f̄: 2026 = 0.0839(kinship-heatmap 평균 G / 2)에서 거꾸로 1 − f̄t = (1 − f̄t−1)(1 − ΔF연,t)
- He = 0.40 × (1 − f̄), 그룹 He = 0.40 × (1 − 그룹 내 평균 f)
- 마커 고정(MAF = 0)·희소(0 < MAF < 0.05): 시드 20261023 드리프트 모의
- OCS 경계: ΔG = 1.04 × ΔG0 × (ΔF/ΔF0)^0.2 (단순 모형, 추정)

## 데이터 교체

`data.ts`의 `L`, `NE`, `F_BAR_2026`, `GROUPS`, `KIN_2026`, `MARKERS`를 실제 값(GRM 계산 결과·마커 집계)으로 바꾸면 나머지는 계산된다. 경보 기준은 `TH`. 개발 모드에서 `[검산]` `console.assert`가 명세의 실행값과 대조한다.
