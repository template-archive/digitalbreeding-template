# 유전적 개량량 추적 (`kpi/genetic-gain-tracker`)

코호트 유전적 추세(평균 GEBV)가 유전체 선발(GS) 도입 뒤 얼마나 가팔라졌는지, 육종가 방정식 예측 ΔG와 맞는지(실현율), ΔG 증가가 i·r·σA·L 중 무엇에서 왔는지(LMDI 분해), 수량 위주 선발이 다른 형질을 어느 방향으로 끄는지(상관 반응)를 한 화면에서 점검한다.

- 명세: `docs/specs/genetic-gain-tracker.md`
- 작물·프로그램: 벼, 가상 "중부 평야지 벼 육종 프로그램"(program-baseline 준수). 구성 요소 i, r, σA, L은 `kpi/program-overview`와 같은 값.

## 화면 구성

| 영역 | 내용 |
| --- | --- |
| A 헤더 | 공통 PageHeader. 형질(쌀 수량·간장·잎도열병 발병 지수·식미치), 시작·종료 연도(종료 − 시작 ≥ 2 강제), 표현형 추세 Switch |
| B 결론 묶음 | `ConclusionPanel`: ΔG(예측) 또는 상관 반응 + 판단 문장 + 연도별 추세. 받치는 KPI: 실현 추세(GS)·실현 추세(전통)·누적 개량. 수량 외 형질은 바람직/비바람직 배지(색+문자) |
| 결론 문장 | 패널 안: 실현 기울기 GS/전통 배율, 최대 기여 요소(수량) 또는 상관 반응 방향(다른 형질, 비바람직이면 패널에 비바람직 태그) |
| 경보·주의 | 결론 묶음 아래. 비바람직 상관 반응 형질(형질 표 방향 배지와 같은 판정, 등급 주의), 누르면 그 형질의 추세로 이동 |
| C 유전적 추세 | 코호트 평균 GEBV 점 + 전통·GS 회귀선(끝 라벨) + 표현형 점선(속 빈 마커), GS 도입선, 2019 코호트 기준선 |
| D 예측 대비 실현 | 묶음 막대 + 구성 요소 비교 표(전통·GS·배율) |
| E 식 띠 | ΔG = i·r·σA/L 또는 CR = i·r·rg·σA/L 숫자 대입 |
| F·G·H | 구성 요소 지수(시작=100, 1/L), 기간 LMDI 폭포, 전년 대비 기여 누적 막대 — 항상 쌀 수량 기준 |
| I 형질 요약 | 4개 형질 실현 기울기·예측·실현율·표현형 기울기·방향 배지 |

상태 미리보기: `?state=loading|empty|error`.

## 데이터 교체

`data.ts`만 바꾼다.

- `I`, `R`, `SIGMA_A`, `L`, `N_COHORT`: 연도별 프로그램 실적
- `TREND[trait].G`(코호트 평균 GEBV, 기준 코호트 = 0), `TREND[trait].P`(생산력 검정 평균의 기준 코호트 대비 편차): 실제로는 GBLUP 재추정 결과와 시험 DB에서 받는다. 지금은 시드 20261023 RNG로 만든다(소비 순서 yield→culm→blast→taste, 형질마다 증분 잡음 7회 → 환경 효과 8회).
- `TRAITS[].rg`, `sigmaA`: 수량 외 형질의 유전 상관·σA(추정값)
- 기울기·실현율·LMDI·지수는 `periodStats`, `lmdi`, `lmdiRange`, `componentIndex`가 계산한다. DEV 모드에서 명세 수용 기준 숫자를 `console.assert('[검산] …')`로 확인한다.
