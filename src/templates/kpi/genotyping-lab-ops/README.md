# 유전체 분석실 운영 현황

- 카테고리: kpi · slug: `genotyping-lab-ops`
- 명세: `docs/specs/genotyping-lab-ops.md`
- 연결 템플릿: `infographic/digital-breeding-process`(③ 유전형 분석), `kpi/program-overview`. 6K 공유 수치(2,000샘플 · 콜레이트 98.9% · QC 1,930/2,000 · TAT 14일 · 4,820마커)가 같다.

## 목적
육종 프로그램 전용 분석실 책임자가 주간 회의에서 다음을 점검한다.
1. 올해 처리량이 목표를 따라가는가(누계 대비 진도 목표, 10월 진도).
2. 데이터 품질이 기준을 넘는가(6K 콜레이트 분포·QC 통과율).
3. 지금 손대야 할 실패·지연은 무엇인가(플레이트 경보, 미해결 재분석, TAT 초과).

## 구성
| 영역 | 파일 |
| --- | --- |
| A. KPI 5개(누계 처리량 hero, 6K 콜레이트, 6K 1차 QC, 6K TAT, 미해결 재분석) | `index.tsx` |
| B. 월별 처리량(플랫폼 누적 막대 + 월 목표선, 10월 빗금·진도 표식) | `components/MonthlyThroughputChart.tsx` |
| C. 6K 콜레이트 히스토그램(QC 기준선 95%, 평균선, 선형/로그) | `components/CallRateHistogram.tsx` |

개발용 상태 확인: `?state=loading|empty|error`.

## 사용 지표
샘플 처리량(결과 제공일 기준 신규 샘플), 진도 달성률, 샘플 콜레이트(call rate), 1차 QC 통과율, 처리 소요 시간(TAT, 샘플 가중), 플레이트 실패율(경보 > 10%), 미해결 재분석 샘플. 정의는 명세 「지표 정의」와 `breeding-metrics` 카탈로그 4장.

## 실제 데이터로 교체하기
`data.ts`에서 다음 세 가지만 LIMS 응답으로 바꾸면 KPI·차트·표가 모두 다시 계산된다.
- `PLATES`: 플레이트 ID, 플랫폼, 접수일, 결과일, 시료 수, TAT
- `FAILS`: 1차 QC 실패 샘플(웰, 콜레이트, 이형접합도, 원인, 조치, 재분석 상태, 완료·예정일)
- `CALL_RATES_6K`: 6K 1차 분석 샘플별 콜레이트

목표값(`ANNUAL_TARGET`, `TAT_TARGET`, `PLATE_ALERT_PCT` 등)과 전년 동기(`PREV_YEAR`)는 상수다. 파일 끝의 개발 중 단언은 목업 전용이므로 실제 데이터에서는 지운다.
