# 유전체 선발 모델 성능

- 카테고리: kpi
- 명세: `docs/specs/gs-model-performance.md`

## 목적
운영 GS 모델(GBLUP)과 대안 모델 3종(BayesB, BayesCπ, RKHS)을 같은 교차 검증 분할(5-fold × 10회)로 비교해 다음 세 가지를 판단한다.
1. 쌀 수량 예측 정확도가 목표(0.58)에 닿았는가, 형질별로 어느 모델이 가장 높은가
2. 훈련 집단을 몇 계통까지 늘려야 목표에 닿는가(학습 곡선)
3. 다음 재학습(2027-02)에서 형질별로 어떤 모델을 쓸 것인가(쌍체 차이 Δr, 95% CI, 실용 기준 0.02)

## 화면 구성
- KPI 5개: 쌀 수량 r(달성률·주의 상태), 훈련 집단, 6개 형질 평균 r, 모델 교체 권장 수, 전진 검증 정확도
- 주 차트 GBLUP 대비 Δr 점 + 95% CI(0 기준선·실용 기준선, 채운 점 = 교체 기준 충족)
- A 형질 × 모델 묶음 막대 + ±SD 오차 막대 + '권장' 표식 (지표 토글: 예측 정확도 / 예측 능력, 좁은 화면에서는 가로 막대)
- B 형질별 모델 판정 카드(판정 배지, Δr, 95% CI, 근거 문장)
- C 학습 곡선(선택 형질, GBLUP ±SD 띠, 1,850 초과는 점선 외삽, 쌀 수량은 목표선·연도별 운영 모델 점·N*)
- D 쌀 수량 연도별 CV 정확도·목표·전진 검증
- E h²–r 산점도 + OLS 회귀선(R²)
- 형질 × 모델 상세 표와 모델별 평균·교차 검증 계산 시간

형질 선택은 A 배경, B 카드, C 곡선, E 점, 상세 표 행을 함께 바꾼다. 모델 토글은 A와 C가 따로 가지며(C 기본은 운영 모델만) 마지막 모델 하나는 숨길 수 없다.

## 사용 지표
예측 정확도 r = corr(GEBV, y)/√h², 예측 능력 = r·√h², 신뢰도 r², 협의 유전력 h²(훈련 집단 계통평균), 쌍체 차이 Δr와 95% CI(t(0.975, 49) = 2.0096), 학습 곡선 r(N) = a·√(N·h²/(N·h² + Me)), 전진 검증 정확도.

## 실제 데이터로 교체하기
`data.ts`에서 `CELLS`(형질 × 모델별 반복 50회 정확도)를 교차 검증 결과로, `R`·`R_T`·`TRAIN_N`·`FORWARD`를 연도별 실적으로 바꾼다. 요약값, 쌍체 차이, 권장, 학습 곡선, 회귀는 모두 여기서 다시 계산된다. 학습 곡선의 `ME`와 `upperA`는 실제 부분 표본 교차 검증 결과에 맞춰 다시 적합한다.

## 상태 확인
갤러리 URL에 `?state=loading|empty|error`를 붙인다. error 상태에서는 영역마다 오류 카드와 「다시 시도」가 나온다.
