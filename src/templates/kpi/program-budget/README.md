# 육종 프로그램 예산·효율

- 카테고리: kpi · 작물: 벼(중부 평야지 가상 프로그램)
- 명세: `docs/specs/program-budget.md`

## 목적
연구 관리자·기획 담당자가 10월 말 집행 점검과 2027 예산안 설명 자료 준비에 쓴다.
1. 올해 예산은 계획대로 쓰이는가(집행률 82.6%, 계획 대비 100.0%, 연말 전망 100.1%)
2. 어느 비목이 넘치거나 남는가(KASP 전망 105.0% 경보, 종자 관리·연구 활동비 83.8% 주의)
3. 디지털 전환이 돈값을 하는가(개량 1 kg/10a당 연간 직접비 3,096 → 1,466만 원, 예측 기준 −52.6% · 실현 기준 −45.3%)

## 화면 구성
- 머리 + 결론 묶음: 연말 전망 `ConclusionPanel`(판단 문장 + 예산 대비 누계 추세) + KPI 4개(390px 2열)
- B 월별 누계 집행(계획 점선·실적 실선·연말 전망 파선, 예산선·기준일선) + F 경보·주의 `AlertList`(경보 2 · 주의 1 · 정보 1, 누르면 해당 비목 행 강조·이동)
- C 비목별 구성(그룹 A·B·C·D 100% 막대) + 비목 12행 불릿(예산·실적·전망 눈금, 경보·주의는 왼쪽 칸 `SeverityTag`(아이콘 + "경보 · 전망 n%"), 시각 숨김 표)
- D 연도별 효율: 계통당 선발 평가비 구성 누적 막대(2027안 빗금), 개량 1 kg/10a당 연간 직접비(예측 선 + 2027안 점선 + 실현 기준 마름모), GS 도입선
- E 유전형 분석 플랫폼 표 + 6K 칩 단가 스파크라인
- G 2027 예산안 비교 표(그룹 소계·합계, `DivergingBar` 증감, 증감률 제어형 정렬 — 정렬 중에는 비목 행만)
- H 각주 4줄

## 직접비 정의(혼용 금지)
- 비교 기준 직접비 = conventional-vs-digital 정의(A 그룹, 2026 18,800만 원). 연도별 추이는 이 정의로만 계산한다.
- 직접비(소모성 경비) = A + B. 인건비·시설 감가상각(C)은 "직접비 정의 밖(별도 집계)", 간접비(D) = (직접비(소모성 경비) + 인건비) × 10%.

## 실제 데이터로 교체하기
`data.ts` 「확정 상수」 블록만 바꾼다: `PIPELINE`·`PER_LINE`(연도별 단가), `I`·`R`·`SIGMA_A`·`L`, 월별 가중 `W`, 플레이트·샘플 실적(`*_ACT_*`),
`PERSONNEL`·`DEPRECIATION`·`CROSS_BUDGET`·`SEED_OPS_BUDGET`, `BUDGET_2027`. 비목 예산·월별 누계·전망·경보·2027안·각주 숫자는 모두 계산값이다.
실제 전표를 연결하면 `buildItem`의 `monthlyAct`를 월별 집행액 배열로 바꾸면 된다. 개발 모드에서 `[검산] [program-budget]` assert가 명세 수용 기준 숫자를 확인한다.
