# 육종 프로그램 KPI 개요

- 카테고리: kpi
- 명세: `docs/specs/program-overview.md`
- 작물·형질: 벼, 쌀 수량(kg/10a). 가상의 "중부 평야지 벼 육종 프로그램"(2022년 GS·속성세대진전 도입)

## 목적
연구 관리자가 분기 보고·연간 목표 점검에 쓰는 화면이다. 세 가지 질문에 답한다.
1. 종료 연도의 연간 유전적 개량량(ΔG)이 목표에 도달했는가, 미달이면 어느 구성 요소(i, r, σA, L) 때문인가?
2. GS 도입 이후 예측 정확도·세대 간격이 어떻게 바뀌었고 ΔG가 얼마나 늘었는가?
3. 파이프라인과 신품종 출원에서 기준에 못 미치는 단계는 어디인가?

## 화면 구성
| 영역 | 내용 | 기준 |
| --- | --- | --- |
| A | 제목, 작물·형질 배지, 시작·종료 연도 선택(시작 ≤ 종료 강제) | — |
| 결론 줄 | ΔG·목표·달성률·GS 전 대비 배수를 한 문장으로 | 종료 연도 |
| B | KPI 5개(ΔG를 크게): ΔG, r, L(낮을수록 좋음), 신품종 출원(연중은 연말 전망으로 등급), MET 완료(그해 완료 세트) | 종료 연도 |
| C | 경보·주의 n건(경보 <90%, 주의 90~<100%), 클릭 시 관련 차트로 이동 | 종료 연도 |
| D | 연도별 ΔG 막대 + 목표 계단 점선 + GS 도입 표식 + 범위 평균선 | 선택 범위 |
| E | ΔG 식(종료 연도 값) + i·r·σA·L small multiples | 선택 범위 |
| F | 형질별 GS 예측 정확도(±SD, 교차 검증 반복 점) | 종료 연도 |
| G | 파이프라인 로그 축 가로 막대(계통 수·같은 해 단계 수 비·목표 마커) | 종료 연도 |
| H | 신품종 출원·등록 묶음 막대 + 출원 목표 | 선택 범위 |
| I | 출원 목록(최신순, 가칭 고지) | 선택 범위 |

## 사용 지표와 계산
- ΔG = i · r · σA / L (kg/10a/년), %/년 = ΔG / 560 × 100
- ΔG 목표 = i목표 · r목표 · σA실적 / L목표
- 달성률: 높을수록 좋은 지표 = 실적/목표, 세대 간격 = 목표/실적
- 같은 해 단계 수 비 = 해당 단계 / 이전 단계(코호트 진급률 아님). MET 경보의 코호트 진급률 = 완료 세트(Y) / AYT(Y−2), 2년제 세트(종료 2025~)만
- 연중 출원 등급 = 연말 전망 달성률 (실적 + 확정 예정) / 목표(`forecastAchievement`, breeding-pipeline-flow와 같은 식). 표시 달성률·정렬은 실적
- 모든 파생값은 `data.ts`에서 상수로부터 계산한다(하드코딩 없음). 난수(시드 20261023)는 형질별 교차 검증 반복값 50개에만 쓴다.

## 실제 데이터로 교체하기
배포 사이트에서는 코드 ZIP, 연간 지표 샘플 JSON·CSV, 데이터 명세와 적용 가이드를 받을 수 있습니다. 외부 입력은 `src/features/template-data/contract.ts`의 `validateProgramData`로 검증한 뒤 `<ProgramOverviewTemplate data={data} />`로 전달합니다. 이 연결 화면은 연간 개량량·목표 달성률·정확도·세대 간격과 추세/입력 표만 표시하며, 아래 목업의 파이프라인·출원 등은 섞지 않습니다. 파일 미리보기는 서버 전송이나 저장 없이 브라우저 메모리에서만 처리합니다.

전체 목업 화면을 실제 운영 데이터로 확장하려면 아래 데이터 소스와 계산의 의존 관계를 함께 수정해야 합니다.
`data.ts`의 연도별 상수(`I`, `R`, `SIGMA_A`, `L`, `I_T`, `R_T`, `L_T`, `PIPELINE`, `MET_TARGET`, `APP_TARGET`, `REGS`, `APPLICATIONS`, `TRAITS`)를 API 응답으로 바꾸면 된다. 계산 함수(`dG`, `dGTarget`, `achievements`, `buildAlerts`, `traitAccuracy`)와 화면은 그대로 쓴다. 출원 건수(`APPS`)는 출원 목록에서 세므로 차트와 표가 항상 일치한다.

## 상태 미리보기
갤러리 URL에 `?state=loading|empty|error`를 붙이면 상태 화면을 볼 수 있다. 기본은 600ms 스켈레톤 후 데이터. 종료 연도 ≤ 2021이면 F는 빈 상태, 범위에 출원이 없으면 I는 빈 표 문구.

## 로컬 컴포넌트
- `PanelTrend` — 결론 패널 안 작은 추세 도식(면 색 토큰만, 8개 KPI 템플릿에 같은 규격)과 패널 위 심각도 태그
- `AlertList` — 경보·주의 n건 카드(목록은 공통 `AlertList`, 클릭 시 이동)
- `GainChart`, `ComponentsPanel`, `TraitAccuracyChart`, `PipelineChart`, `ApplicationsChart`
