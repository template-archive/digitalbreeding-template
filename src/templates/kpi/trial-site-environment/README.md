# 시험지 기상·환경 (`kpi/trial-site-environment`)

지역 적응 시험(MET) 8개 지역 × 2025~2026의 재배기(이앙~수확) 기상을 평년(1991~2020)과 비교하고,
환경 지수(지역·연도 평균 수량 − 전체 평균)를 가장 잘 설명하는 기상 요인과 해석에 주의할 이상 기상을 정리한다.
`viz/met-gxe-stability`(GxE·안정성 분석)의 "환경" 쪽 해설 화면이다.

## 화면 구성
| 영역 | 내용 |
| --- | --- |
| A 머리말 | 조건(GDD 기준 10 °C, 평년 1991~2020, 재배기 = 이앙~수확, 목업 표기), 연도 Segmented, 지역 Select |
| 결론 | 선택 연도 평년 비교 + 최강 상관 요인 + 경보 요약(모두 계산값에서 생성) |
| B KPI | 유효적산온도·강수량·일조시간(등숙기 일조 평년 대비 변화)·이상 기상 건수 |
| C 지역 배치 | 위경도 산점(경계선 없음, 위도 1/cos 37° 보정) + 지역 카드 8개. md 미만은 카드만 |
| G 경보 | AlertList(경보·주의), 날짜 내림차순, 누르면 지역 선택 |
| D 월별 | 기온·강수량·일조시간 실측 vs 평년 |
| E 일별 | 최고~최저 띠·평균, 33·35·17 °C 기준선, 출수 ±15일 음영, 이앙·출수·수확 선 |
| F 요인 | 8개 요인 r 막대(유의 임계 ±0.497) + 선택 요인 산점도(회귀선, 잔차 하위 4개 라벨) |
| H 표 | 환경 요약 DataTable(환경 지수 내림차순, 2개 연도 토글) |

## 지표
- 유효적산온도(GDD) = Σ max(0, Tmean − 10), 이앙~수확. 평년 편차는 같은 날짜의 평년 일 값 합 대비.
- 고온 일수 = 출수 ±15일 최고 ≥ 33 °C(괄호 ≥ 35 °C), 저온 일수 = 같은 창 최저 ≤ 17 °C.
- 등숙기 = 출수 후 1~40일. 수확일 = 출수 후 일평균기온 누적 1,100 °C·일 도달일.
- 경보 규칙(추정): `data.ts`의 `ALERT_RULES`.
- 상관 = Pearson(n = 16), p = 양측 t(df 14).

## 데이터 교체
`data.ts`의 `generate()`가 환경별 일 기상(`Day[]`)과 파생 값을 만든다. 실제 자료로 바꿀 때는
`ENVS`를 관측 일 기상·이앙/출수/수확일로 채우고, `ENV_INDEX`를 MET 분석 결과(환경 평균 − 전체 평균)로 바꾼다.
연도 요약(`SUMMARY`)·경보(`ALERTS`)·상관(`CORRELATIONS`)은 그 값에서 다시 계산된다.

- 기상 값은 모두 목업(가상 관측, 시드 `WX_SEED` 20261030). 평년값은 인근 ASOS 지점 근사 추정.
- `ENV_INDEX`는 `viz/met-gxe-stability`의 `ENVS[e].index` 원 실행값 복제다. 그 템플릿 목업이 바뀌면 함께 갱신한다.
