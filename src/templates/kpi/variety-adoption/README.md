# 품종 보급 현황

- 카테고리: kpi · 작물: 벼(중부 평야지 프로그램)
- 명세: `docs/specs/variety-adoption.md`

## 목적
연구 관리자·보급 담당자가 2026 작기 뒤(10월 하순) 세 가지를 점검한다.
1. 우리 품종이 국내 벼 면적의 얼마를 차지하고 보급 목표를 채웠나(24,966 ha, 3.73%, 목표 대비 94.2%)
2. 2027 봄 보급종이 수요를 채우나(831 t / 865 t = 96.1%, 부족 3품종)
3. 신품종이 종자 증식을 거쳐 언제 농가에 닿나(등록 후 3년, 별하랑은 사전 증식으로 2030)

## 화면 구성
- A 결론 묶음: 재배 면적 판단 패널(`ConclusionPanel` + 면적 추세) + KPI 4개(`KpiRow`)
- B 재배 면적 추이(품종 누적 막대, 2027 전망 빗금, 합계·점유율 라벨, 가람솔 등록·첫 공급 세로선)
- J 경보·주의(`AlertList`, 수급률 오름차순 → 목표 미달) + 정보 2건
- G 보급 목표 불릿 막대 · E 도별 보급률(전체/품종별, 중부 평야지 띠)
- I 2027 보급종 공급 계획 표(`DivergingBar` 과부족, 390px 3열)
- C 증식 단계 타임라인(품종 11행 × 2019~2030, 연도 칸 다섯 칸 색 띠, 계획 빗금, 시범 점선, 문자는 2026 칸의 현재 단계와 ◆ 등록 ○ 출원, 390px는 품종별 현재 단계·농가 도달 연도 목록)
- D 선택 품종 원원종·원종·보급종 소형 다중 막대(보급종 패널에 공급량 S 점선) · F 가람솔 대체율(위 선, 아래 누적 막대)
- H 농가·RPC 평가 표(평균 ± 95% CI 점·막대, RPC 10곳 미만 '참고')

## 사용 지표
보급종 생산량 P3, 원종 P2 = P3(y+1)/30 + 시범(y+1)×0.04, 원원종 P1 = P2(y+1)/20, 기본식물 = P1(y+1)/20×1000 kg,
공급량 S = P3(y−1)×0.95, 공급 면적 = S/0.04, 재배 면적 = SA(y) + 0.6·SA(y−1) + 0.3·SA(y−2) + 시범,
국내 점유율, 도별 보급률, 가람솔 대체율(중부 3도), 목표 달성률, 수급률, 만족도(평균 ± 1.96·SD/√n), 재재배 의향(n 가중).

## 실제 데이터로 교체하기
`data.ts`의 상수만 바꾼다: `VARIETIES`(품종별 보급종 생산 P3·시범 면적·목표·도 배분), `NATIONAL`·`PROV_2025`(통계청 면적),
`OLD_MAIN_CENTRAL`, `DEMAND_2027`, `SURVEY`. 나머지(단계·면적·점유율·경보 문구)는 모두 계산값이다.
개발 모드에서 `[검산]` assert가 명세 수용 기준 숫자를 확인한다.
