# GEBV 기반 선발

- 카테고리: viz · 작물: 벼 · 명세: `docs/specs/gebv-selection.md`
- 연결 템플릿: `program-overview`(2026년 ΔG 구성 요소), `cross-planner`(앵커 8계통 수량 GEBV·신뢰도)

## 목적
2026년 하반기 부모 선발(재순환 선발) 단계에서 육종가가 다음 교배(2027년 1차)에 쓸 부모 후보를 고른다.
선발 비율(p)을 정하면 GEBV 분포 위에 선발 기준선이 그어지고, 선발 수·선발 강도(i)·기대 연간 유전적 개량량(ΔG)이 즉시 바뀐다.
다형질 선발 지수 모드에서는 경제적 가중치로 수량–식미 상충을 조정하고 형질별 선발 차로 손익을 확인한다.

## 사용 지표
- GEBV(GBLUP, 훈련 집단 1,850계통, 기준 = 훈련 집단 평균 0), 신뢰도(r²)
- 선발 강도 i = φ(x_p)/p(무한 집단 정규 절단, 소수 3자리 반올림값을 계산에도 사용)
- 육종가 방정식 ΔG = i·r·σA/L, r = 0.57, σA = 28.2 kg/10a, L = 2.2년, μ = 560 kg/10a → p = 10%에서 12.82 kg/10a/년(2.29%/년)
- 표준화 GEBV z_t = d_t·(GEBV − 평균)/SD(간장·도열병은 부호 반전), 다형질 선발 지수 I = Σ w_t·z_t(Σw = 1)
- 실현 선발 차 S = 선발 평균 − 후보 평균

## 실제 데이터로 교체하기
`data.ts`의 `LINES`(계통명, 형질별 GEBV·신뢰도)만 API 응답으로 바꾸면 된다. `STATS`·z·지수·순위·컷오프·S·ΔG·KDE·상관은 모두 계산된다.
육종 프로그램 매개변수(`R_ACC`, `SIGMA_A`, `L`, `MU`)와 형질 정의(`TRAITS`), 프리셋(`PRESETS`)은 상수로 분리돼 있다.

개발용 상태 확인: 갤러리 URL에 `?state=loading|empty|error`.
