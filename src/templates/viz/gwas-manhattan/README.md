# GWAS 결과 뷰어

- 카테고리: viz
- 명세: `docs/specs/gwas-manhattan.md`
- 작물: 벼(IRGSP-1.0 근사 염색체 길이, 12염색체)

## 목적
유전체 분석가가 형질을 바꿔 가며 (1) 전장 유전체 유의선을 넘는 좌위의 위치, (2) 집단 구조 보정의 적절성(λGC·QQ), (3) 리드 SNP의 p값·MAF·효과(β)·PVE·후보 유전자를 한 화면에서 확인한다.

## 화면 구성
- 상단: 분석 조건 메타 줄, 형질 `Select`, 유의 기준 `Segmented`(본페로니 0.05/M ↔ 5×10⁻⁸)
- KPI 4개: 분석 규모, 유의 SNP 수, 유의 좌위 수(제안 좌위 보조), λGC(상태 배지·정상 범위 눈금)
- 결론 줄: 유의 좌위 목록과 최강 신호 요약(맨해튼 `ariaLabel`과 같은 내용)
- 맨해튼 플롯: 염색체 교대 2색, 유의선(실선)·제안선(점선), 유의 리드 SNP 라벨. 점 클릭 또는 표 행 클릭 → 염색체 확대(QTL ±200 kb 음영, dataZoom). "전체 유전체로" 버튼·Esc로 복귀
- QQ 플롯: y = x, 95% 신뢰 띠, λGC 표기(KPI와 같은 숫자)
- 피크 SNP 표: ±500 kb clumping 리드 SNP, p값 오름차순

## 사용 지표
−log10(p), 본페로니 유의 수준(0.05/M = 5.86), 제안 수준(5.00), λGC(본페로니 유의 리드 SNP ±1 Mb 안 SNP를 뺀 p 중앙값 기반, QQ는 전체 SNP), MAF, β(소수 대립유전자 동형 − 주 대립유전자 동형), PVE = χ²/(N + χ²) (심은 피크는 명세 표 값), QTL 구간(리드 ± 200 kb).

## 실제 데이터로 교체하기
`data.ts`의 export 형태를 유지한 채 바꾼다.
- `PANEL.snps`: SNP 위치·MAF(모든 형질 공통), `PANEL.chrOffsets`: 누적 x축 구간
- `getTraitResult(key)`: 형질별 `logP`/`chi2`(PANEL 순서 배열), `leads`, `lambda`(피크 ±1 Mb 제외)·`lambdaAll`·`lambdaN`·`lambdaPeaks`, `sortedDesc`, `qq`, `band`
  - 실제 결과 파일(PLINK/GEMMA/GAPIT 등)을 읽어 `logP`를 채우면 clumping·λ·QQ 계산 코드는 그대로 쓸 수 있다.
  - β·PVE는 실제 분석 결과의 값을 `Lead`에 넣는다(목업은 χ²로 역산).
- 후보 유전자 위치는 RAP-DB/IRGSP-1.0 기준 추정 근사값이다. 실제 주석 DB로 바꾼다.

## 개발용 상태 확인
갤러리 URL에 `?state=loading|empty|error`를 붙인다. `empty`는 피크 없이 귀무 SNP만 생성하고 제안선 이상 값을 4.99로 눌러 빈 표 경로를 보여 준다.
