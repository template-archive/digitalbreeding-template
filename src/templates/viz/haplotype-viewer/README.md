# 마커·하플로타입 뷰어 (`viz/haplotype-viewer`)

GWAS 유의 좌위(sd1·Hd1·GS3·Pi-ta·Pi9)의 리드 LD 블록 하플로타입 구조와 하위 집단별 빈도를 보고, 교배 부모 후보 60계통·출원 후보·대비/참고 품종이 표적(유리·효과) 대립유전자를 갖는지 확인한다. 명세: `docs/specs/haplotype-viewer.md`.

## 화면 구성

- 컨트롤: 유전자 구간, 계통 집합(다양성 패널 412 / 육종 계통 67), 정렬(하플로타입·하위 집단·GEBV — 패널에서는 비활성), 열 범위(창 ±500 kb / 리드 블록), 색 기준(주·소수 / 표적 하플로타입 비교). 640px 미만은 정렬·열·색이 select로 바뀐다.
- KPI 4개(③ 표적 대립유전자 보유가 hero), 결론 2문장(계산값에서 생성)
- 유전형 격자(캔버스): 위 트랙(Mb 축, 연결선, 후보 유전자 눈금, 리드·C2 표식, ld-decay 블록 괄호), 왼쪽 하위 집단·하플로타입 띠, 결측 빗금. 그리기 후 `data-chart-ready="true"`
- 리드 SNP 효과 카드(GWAS β·PVE·−log10 p, 육종 계통 검산), 하플로타입 빈도 100% 누적 막대
- 하플로타입 표, 육종 계통 67 × 5좌위 보유 요약 표(역할 필터, 행 클릭 → 격자 강조)

## 사용 지표

리드 블록(r² ≥ 0.5 스파인), 이름 있는 하플로타입(블록 완전 호출 5계통 이상), 결측 보정 배정, 표적 대립유전자 보유, 유리 대립유전자 수(유리형 3좌위). 정의는 명세 「지표 정의」.

## 데이터 교체

`data.ts`의 `computeAll()`이 돌려주는 `HapData`만 같은 모양으로 채우면 된다.

- `loci[]`: 창 SNP(`snps`), 참값 유전형 `G`(SNP × 412 ld 인덱스), 결측 `miss`, 블록·리드 블록, 하플로타입(`named`), 계통별 배정(`panel`, `breed` — `slot`이 유전형 열 인덱스, `observed`면 결측 포함)
- `panel`(다양성 패널 계통·하위 집단), `breed`(육종 계통·역할·GEBV·저항성 기록)

목업은 ld-decay·population-structure·cross-planner `data.ts`의 생성 코드를 **복사**해(템플릿 간 import 없음) 같은 ID·창 유전형·블록을 재현한다. 참조 구현 `hapref.mjs`의 `expected.json`과 계통별 하플로타입·판정·공여 슬롯·빈도가 모두 일치함을 확인했다. DEV 검산(`[검산]`)이 명세 8)의 수치를 확인한다.
