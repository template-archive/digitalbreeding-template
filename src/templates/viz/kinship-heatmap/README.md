# 유전적 관계 히트맵

- 카테고리: viz
- 명세: `docs/specs/kinship-heatmap.md`

## 목적
2027년 1차 교배 계획 부모 후보 60계통의 유전체 관계 행렬(GRM)을 히트맵으로 보고 다음을 확인한다.
1. 서로 아주 가까운 계통 묶음(근연 군집)이 몇 개이고 어느 계통끼리인가(UPGMA 군집 순 + 덴드로그램, d = 0.75 절단).
2. 두 계통의 관계 계수 G(2f 척도)와 공조계수 f = G/2, 근연 등급, 계보 기대값과의 차이 Δ.
3. 그룹(A 중만생 다수성 / B 조생 고품질 / C 저항성 공여) 안·사이 평균 관계.

## 사용 지표
- 관계 계수 G: VanRaden 방법 1. 근교계 사이 비대각 G = 2f, 대각 G = 1 + F(색 척도 제외, 기본 마스킹)
- 공조계수 f = G/2. 근연 등급 `kinLevel(f)`(@/lib/genomics): f ≥ 0.375 강한 근연, 0.25 ≤ f < 0.375 근연 주의
- 계보 기대 f_ped: 같은 가계 (1 + f부모)/2(F01 0.5195), 반형제 가계 0.25, 그 밖 "—"
- Δ = f_G − f_ped
- 근연 군집 수: UPGMA(거리 1 − f) 높이 ≤ 0.75 최대 부분 트리 중 2계통 이상

## 구성
- `data.ts`: cross-planner `build()`를 같은 시드(20261023)·같은 호출 순서로 복사(후보·f가 cross-planner와 모든 쌍에서 같음). 대각용 잔여 이형접합도는 `createRng(SEED + 1)`. UPGMA·정렬·덴드로그램 선분·그룹 평균·쌍 목록 계산. 끝에 DEV 검산(`console.assert` + `[검산]`).
- `components/KinshipHeatmap.tsx`: 히트맵·그룹 색 띠·대각·선택 셀·그룹 경계선·덴드로그램을 ECharts 인스턴스 하나에(격자 2개) 그려 행 정렬을 픽셀 단위로 맞춘다. 화살표 키로 선택 셀 이동.
- `components/ScaleLegend.tsx`: HTML 연속 색 범례(공통 `SequentialScaleLegend` block 사용, ≤ 0 ~ 1.3, 0.50·0.75 눈금, 음수 G는 최저 색).
- `components/PairDetail.tsx`, `PairTable.tsx`(DataTable 제어형 정렬·페이지, 390px 카드 목록), `GroupMeanTable.tsx`.
- 공통 `useElementWidth`(@/design-system): 컨테이너 폭 → 셀 크기(6~11px). 640px 미만은 셀 6px·축 라벨·덴드로그램 숨김·가로 스크롤.

## 실제 데이터로 교체하기
`LINES`(계통 속성 + 잔여 이형접합도 `het`, 근교계수 `F`)와 `kin(i, j)`(또는 GRM을 직접 받는다면 `grm(i, j)`)만 API 응답으로 바꾼다. 실제 GRM은 기준 집단에 따라 음수 G가 나올 수 있으며, 히트맵은 최저 색으로 칠하고 툴팁에 실제 값을 보인다. 계보 기대값은 `fPed()`를 계보 DB 재귀 계산으로 바꾼다.
