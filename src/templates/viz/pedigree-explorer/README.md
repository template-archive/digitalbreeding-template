# 계통도 탐색기

- 카테고리: viz
- 명세: `docs/specs/pedigree-explorer.md`
- 작물: 벼(자식성, 모든 개체를 고정 근교계로 가정)

## 목적

기준 계통을 고르고 3~5세대 조상을 세대별로 펼쳐 본다. 부모 양쪽에 같이 들어간 공통 조상(근연 루프)과 부모 간 공조계수 f가 어느 조상에서 왔는지 확인하고, 조상 노드를 눌러 상세를 보거나 그 조상을 새 기준으로 다시 그린다.

## 화면 구성

| 영역            | 내용                                                                                                                                 |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| A. 조작 막대    | 기준 계통 콤보박스(검색, 구분별 묶음), 표시 세대 3/4/5, 근연 루프 강조 스위치, 다시 그리기 이력(브레드크럼 + 뒤로)                   |
| B. KPI          | 부모 간 공조계수 f(대표, 근연 등급 배지), 근교계수 F(F7), 근연 루프 수(표시 세대 안 n/전체), 기준 계통 GEBV                          |
| C. 계통도       | SVG 경로 펼침 계통도. 모본 위·실선 ♀, 부본 아래·점선 ♂. 노드 모양으로 품종·계통·도입·기초 구분, 루프 번호 배지·색 테두리, ×n, ＋상위 |
| D. 근연 루프 표 | 공통 조상별 기여 Σ(½)^(n₁+n₂), 모본·부본 쪽 경로, 세대. 합계 = f. 행 호버·번호 누름으로 계통도 경로쌍 강조                           |
| E. 조상 기여율  | 기초 조상 가로 막대(합계 100%), 모든 조상 펼침                                                                                       |
| F. 상세 패널    | 오른쪽 서랍(md 미만 아래 시트). 교배 조합(Purdy), 출원·등록, 형질, 유전자, GEBV·r², 자기 부모 간 f, 다시 그리기                      |

## 사용 지표

- 부모 간 공조계수 f: 재귀식 f(X,Y) = ½[f(모본_X, Y) + f(부본_X, Y)], f(X,X) = 1, 기초 개체끼리 0. 경로식 합과 같음(DEV 검산)
- 근연 등급: f ≥ 0.375 강한 근연, ≥ 0.25 근연 주의, 그 외 정상
- 근교계수 F₇ = 1 − (1 − f)·(½)⁶
- 조상 기여율 g = Σ_경로 (½)^세대수
- GEBV(쌀 수량, kg/10a, 2026-10 GBLUP 재추정)·신뢰도 r²

## 데이터 교체

`data.ts`의 `PEDIGREE` 배열(계통명·품종명·구분·모본·부본·연도·형질·유전자·GEBV·r²·출원)을 계보 DB 응답으로 바꾸면 나머지(공조계수·루프·기여율·인스턴스 배치)는 함수가 다시 계산한다. `EXTRA`·`SIBLING`은 상세 패널용 추가 사실이다. 개발 모드에서는 `data.ts` 끝의 `[검산]` assert가 수용 기준 숫자를 확인한다.

## 상태 확인

갤러리 URL에 `?state=loading|empty|error`. 부모 기록이 없는 개체(GR-0147 등)를 기준으로 고르면 계통도 빈 상태와 "해당 없음" 카드가 나온다.
