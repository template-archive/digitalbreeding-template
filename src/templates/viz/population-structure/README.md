# 집단 구조 분석

- 카테고리: viz · 작물: 벼(*Oryza sativa*) · 상태: review
- 명세: `docs/specs/population-structure.md`
- 연결 템플릿: `gwas-manhattan`(같은 YR 다양성 패널 412계통, MLM에 PC 3개 + GRM)

## 목적

GWAS 전에 패널의 집단 구조를 확인한다.

1. 하위 집단이 몇 개이고 각각 어떤 계통으로 이루어졌는가 (K = 4: 온대 자포니카 176 · 열대 자포니카 54 · 인디카 112 · 아우스 30 · 혼합형 40)
2. GWAS 모형에 넣은 PC 3개가 집단 구조를 충분히 잡는가 (PC1~PC3 누적 33.9%, 최적 K − 1 = 3)
3. 혼합형 계통이 어디에 있는가 (최대 Q < 0.70, 저항성 공여 YR20-1108·YR19-0731 포함)

## 화면 구성

| 영역 | 내용 |
| --- | --- |
| KPI | 하위 집단 수 · GWAS 공변량 PC(강조) · 혼합형 계통 · 분석 규모 |
| PCA 산점도 | PC 쌍 전환(PC1×PC2 / PC1×PC3 / PC2×PC3), 축 제목에 설명 분산 %, 사각형·자유형 브러시, 집단 표시/숨김 |
| 설명 분산(scree) | PC1~PC10, PC1~PC3 강조, "GWAS 공변량 PC 3개(누적 33.9%)" 경계선 |
| ADMIXTURE 막대 | K = 2~6, 정렬(하위 집단 순 / PC1 순 / 선택 계통 먼저), 하위 집단 띠, CV 오차 미니 그래프 |
| 하위 집단 요약 표 | 계통 수·비율·평균 소속 계수·육성/도입·대표 계통·선택 수. 행 클릭/Enter = 집단 전체 선택 |
| 선택 계통 목록 | 브러시·행 선택 결과, 막대와 같은 순서 |

선택(계통 ID 집합)은 PCA·막대·두 표가 공유한다. Esc 또는 "선택 해제"로 초기화.
개발용 상태 확인: `?state=loading|empty|error`.

## 사용 지표

- 주성분 고유벡터(plink `--pca` 형식: 열 평균 0, 제곱합 1, 직교) — 점 퍼짐은 설명 분산에 비례하지 않는다.
- 설명 분산 비율(PVE), ADMIXTURE Q(행 합 1), 5겹 CV 오차, 소속 판정(K = 4 최대 Q ≥ 0.70).
- ADMIXTURE는 하디-바인베르크 평형을 가정하므로 자식성 근교계에서는 Q를 조상 성분 비율의 근사로 읽는다(화면 각주).

## 데이터 교체 방법

`data.ts`만 바꾼다.

- `LINES`: 계통별 `{ id, name, origin, group, dom, maxQ, pc: [PC1, PC2, PC3], qm: {2..6: 천분율 정수 배열} }`. 실제 데이터는 `.eigenvec`(PC)과 K별 `.Q` 파일을 읽어 만든다. `group`은 K = 4 Q에서 `Q_ASSIGN` 규칙으로 계산한다.
- 상수: `PVE`(`.eigenval`에서 계산), `CV_ERROR`(ADMIXTURE `--cv` 로그), `PRUNED_SNPS`, `TOTAL_SNPS`, `GWAS_PCS`.
- `K_COMPONENTS`: K별 성분 이름·색 계열. 실제 Q 열 순서는 실행마다 바뀌므로 성분을 집단에 맞춰 재배열한 뒤 넣는다.
- 파일 끝의 `import.meta.env.DEV` 검산은 목업 수용 기준용이다. 실제 데이터로 바꾸면 지운다.
