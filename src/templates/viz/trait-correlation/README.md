# 형질 상관 행렬

- 카테고리: viz
- 명세: `docs/specs/trait-correlation.md`

## 목적
2026 하반기 부모 선발 전, 훈련 집단 1,850계통의 형질 8개(gs-model-performance 6형질 + 수장·주당 이삭수) 상관 구조를 보고 다음에 답한다.
1. 어떤 형질들이 유전적으로 함께 움직이나(UPGMA 군집 정렬, h = 0.75 절단 묶음 "수량·구성 요소", "생육·초형").
2. 표현형 상관만 보면 무엇을 잘못 읽나(쌀 수량–도열병 rG +0.10 vs rP −0.16, 환경 상관 −0.28).
3. 지수 가중치가 상관 구조와 만나 어떤 부수 효과를 내나(수량 단일 선발 대비 상관 반응).

## 사용 지표
- 유전 상관 rG(2변량 REML 상수), SE = Robertson(1959) 근사, Wald p, 95% CI
- 표현형 상관 rP(계통 평균 Pearson), Fisher z CI, 환경 상관 rE = (rP − hx·hy·rG)/(ex·ey), rP 분해
- GEBV 간 상관(교차 검증 GEBV), 협의 유전력 h²(대각)
- 상관 반응: 단일 R_y = i·r_x·s_x·rG_xy·σA,y, 지수 R_y = i·Σ w_k d_k r_k rG_ky σA,y / σ_I(gebv-selection과 같은 표준화 GEBV 지수)
- 연간 수량 개량량 R/L(2.2년), %/년 = ÷ 560, 2.5%/년 초과면 "범위 초과(이론값)"

## 구성
- `data.ts`: 형질 상수, RG_UP·설계 RE_UP, 콜레스키 생성(시드 20261023, 계통마다 정규 24개 → 계통명), 쌍별 통계, UPGMA, 상관 반응·판정, 해석·해설 문장, DEV 검산(`console.assert` + `[검산]`).
- `components/CorrelationMatrix.tsx`: SVG 행렬(상삼각 rG, 하삼각 rP, 대각 h²), 발산 척도 −1~1 고정(`--viz-div-*` 보간), 위·왼쪽 덴드로그램, 묶음 띠·경계, 선택·대칭 셀 강조, 화살표 키 이동·Enter 선택, HTML 툴팁. `MatrixLegend` 포함.
- `components/PairDetail.tsx`: 선택 쌍 상세, 분해 막대, 해석 문장, 양방향 상관 반응.
- `components/PairScatter.tsx`: 1,850점 large 산점도 + OLS 회귀선(GEBV·표현형).
- `components/ResponsePanel.tsx`: 선발 기준·비율 컨트롤, 해설 문장(G), σA 단위 막대(현재 vs 수량 단일 기준), 판정 배지.

## 실제 데이터로 교체하기
`TRAITS`(h²·SE·정확도·σA), `RG_UP`(REML 추정값), `LINES`(계통명·표현형·GEBV)만 API 응답으로 바꾼다. 유의성·군집·분해·상관 반응은 그대로 계산된다. `RE_UP`과 생성 함수 `build()`는 목업 전용이다.
