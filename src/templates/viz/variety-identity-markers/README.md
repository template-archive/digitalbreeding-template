# 품종 식별 마커 프로필 (`viz/variety-identity-markers`)

출원 후보·출원 중·등록·대비 품종 10개의 KASP 16마커(기능 11 · ID 5) DNA 프로필로 품종 간 식별 가능 여부를 확인하고, 식별이 어려운 쌍과 채종 로트 DNA 순도 검정 결과(입고 판정)를 함께 보는 화면입니다. 명세: `docs/specs/variety-identity-markers.md`.

## 데이터 교체

`data.ts`의 두 상수만 바꾸면 나머지는 계산됩니다.

- `RAW`(→ `PROFILES`): 품종·계통별 `geno`(마커 순서 `MARKERS`, 0 = AA, 2 = BB)와 역할·상태·분석 출처
- `PURITY_RAW`: 검정 ID, 연도, 구획, 입고 로트·입고량, 판독 불가 수, 재분석 립(`recheck`: 오호출 마커·유형 AB/opp, 판독 n에 포함·이형립 x에 불포함), 이형립(`kind`·`donor`). 실제 연동 시에는 이형립 유전형(0/1/2 배열)을 그대로 받아 `classify`·`origin`에 넣으면 됩니다.

판정 기준 상수: `DISTINCT_MIN`(2), `POP_STD`(0.001), `ACCEPT_PROB`(0.95), `SEEDS_PER_TEST`(188).
