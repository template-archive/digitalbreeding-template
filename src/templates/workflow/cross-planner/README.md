# 교배 조합 설계

- 카테고리: workflow
- 명세: `docs/specs/cross-planner.md`
- 작물·형질: 벼(자식성, 근교계 부모), 주 형질 쌀 수량 GEBV(kg/10a). 계획: 2027년 1차 교배(온실)

## 목적
육종가가 다음 교배 시즌의 교배 조합(Cross)을 고르는 화면이다. 세 단계로 진행한다.
1. **부모 후보 선택**: 후보 60계통을 필터(GEBV·신뢰도·출수기·간장·그룹)로 좁히고 부모 2~12계통을 고른다.
2. **조합 검토**: 부모×부모 상삼각 행렬에서 유용성 기준(UC)·자손 평균(μ)·자손 SD(σ)·공조계수(f)를 비교하고, 셀 상세 패널에서 조합을 담는다.
3. **확정**: 요약(조합 수·사용 부모 수·평균 UC·평균 f), 경고(근연 조합·개화기 불일치·부모 편중)를 확인하고 모본/부본을 정해 확정한다.

## 사용 지표와 계산 (`data.ts`)
- μ = (GEBV_P + GEBV_Q) / 2
- σ = σA · √(1 − f) · k, σA = 28.2 kg/10a, k = 0.85 + 0.25 · min(1, |GEBV_P − GEBV_Q| / 50) (분리 계수, 목업 근사)
- UC = μ + i · σ, i = 1.755 / 2.063 / 2.665 (p = 10 / 5 / 1%)
- 근연 등급(자손 분리 분산 축소): f ≥ 0.375 강한 근연, 0.25 ≤ f < 0.375 근연 주의
- 추천: 선택 부모의 쌍 중 f < 0.25, UC 내림차순 상위 5
- 경고: 출수기 차 > 10일 개화기 불일치, 한 부모 4건 이상 부모 편중
- 확정 ID: 확정 시점 UC 내림차순으로 CR27-001부터

앵커 8계통과 앵커 간 f는 명세 상수, 나머지 52계통과 관계 계수는 시드 20261023으로 생성한다. 후보 배열 순서는 앵커 8 → 생성 52(가계 순서)이며, 관계 계수 난수는 이 배열의 i<j 이중 루프 순서로 뽑는다.

## 실제 데이터로 교체하기
`CANDIDATES`(계통 목록)와 `kinship(P, Q)`(GRM에서 환산한 공조계수)만 API 응답으로 바꾸면 된다. 실제 교배 예측 도구(예: PopVar)의 σ를 쓰려면 `predict()`의 `sigma` 계산만 교체한다. 화면과 경고·요약 함수는 그대로 쓴다.

## 상태 미리보기
`?state=loading`(스켈레톤 유지) · `?state=empty`(후보 0건 → 빈 상태) · `?state=error`(오류 화면). 기본은 400ms 스켈레톤 후 데이터.

## 반응형
- ≥ 1024px: 필터 왼쪽 세로 패널(280px), 행렬 2/3 + 상세 1/3
- < 1024px: 필터는 표 위 접이식(기본 접힘, "필터 · 적용 n개")
- < 768px: 스테퍼 "2/3 조합 검토" 축약, 후보 표 계통명 열 고정, ② 단계 기본 조합 목록 보기(행렬 보기 전환), 확정 버튼 하단 고정
