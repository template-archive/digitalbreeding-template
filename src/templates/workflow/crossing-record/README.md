## 목적
2026년 2차 교배(하계, 교배 망실) 24조합(CR26-301~324)의 야장 값을 전산에 옮기고 F1 진위를 확인해 다음 회차 재교배 조합을 고른다.
1. F1 종자는 목표 대비 얼마나 확보됐나(목표 진행률, 달성 조합)
2. 어느 조합을 다시 교배해야 하나(자식 의심 · 종자 부족 · 입력 필요)
3. F1 진위 확인은 어디까지 왔나(확인 · 자식 의심 · 대기)

## 사용 지표
결실률, 결실 판정(< 12% 저조, > 50% 과다), 다형 마커 수, F1 개체 판정, F1 진위 상태(자식 비율 ≥ 50% → 자식 의심), 유효 F1, 목표 진행률(Σ min(유효 F1, 40) / 960), 목표 달성 조합, 재교배 필요. 정의는 명세 「지표 정의」.

## 실제 데이터로 교체하기
- `CROSSES`(조합 원본: 부모, 기록 값, 묶음, 다형 마커, KASP 개체 판정 `plants`)를 교배 야장·LIMS 응답으로 채운다. `PARENTS`·`PARENT_GENO`는 계통 DB와 부모 유전형으로 바꾼다. `PARENT_GENO`는 0 = AA, 2 = BB이며, 기능 마커(Pi9~GS3)는 BB = 효과(표적) 대립유전자 동형(저항성·Wx 저아밀로스·Hd1 출수 지연형·sd1 반왜성·GS3 천립중 증가형), ID 마커(ID02~ID11)는 BB = 대체 대립유전자(IRGSP-1.0 기준)다.
- 파생값은 `validate`·`derive`·`summarize`(순수 함수)가 계산한다. 저장은 `index.tsx`의 `save()`에서 API를 부르고 응답으로 `saved`·`savedOverrides`를 교체한다.
- 개발용 상태: `?state=loading|empty|error`.
