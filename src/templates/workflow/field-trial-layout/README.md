# 시험포장 배치·관리

- 카테고리: workflow
- 명세: `docs/specs/field-trial-layout.md`

## 목적
2026 생산력 검정(AYT) 알파격자 3반복 포장(9행 × 14열, 126구)에서 수확 후 자료 검토를 한 화면에서 끝낸다.
- 계통 검색 → 3개 반복의 구 위치 강조
- 결측·이상치 점검(결측·이상치 목록: 경보 = 이상치, 주의 = 결측 → 구 선택)
- 수량·출수기·간장 히트맵과 공간 경향(3×3 이동 평균 잔차)으로 비옥도 기울기·저수량 구역 확인
- 구별 메모 작성(로컬 상태 + 토스트). 관측값은 읽기 전용

## 사용 지표
시험구 수, 조사 완료율(관측값 / 126 × 3), 수량 평균·SD·변이계수(CV, 정상 구 원자료), 결측·이상치 건수,
계통 평균(결측·이상치 제외), 수량 지수(가람솔 = 100), 공간 경향. 모두 `data.ts`에서 계산한다.

## 구성
- `data.ts`: 배치 상수(LAYOUT), 처리 목록, 결측·이상치·메모 상수, 시드 20261023 형질값 생성, 통계(SUMMARY, LINE_STATS, TRENDS)
- `components/FieldGrid.tsx`: HTML 격자(role=grid, 로빙 tabindex, 방향키·Home/End·Enter), 모드별 셀 렌더
- `components/PlotPanel.tsx`: 구 상세 + 메모 편집
- `components/LineTable.tsx`: 계통별 요약 DataTable
- `components/scale.ts`: 토큰 기반 순차·발산 색 보간(color-mix), 빗금 패턴

## 실제 데이터로 교체하기
`PLOTS`(구 번호·반복·블록·행·열·처리·형질값·상태), `ENTRIES`, `ISSUES`, `INITIAL_MEMOS`를 API 응답으로 바꾸면
요약·계통 평균·공간 경향은 그대로 계산된다. 이상치 판정 범위(`TRAITS[*].range`)와 구 면적은 기관 기준으로 조정한다.
개발 모드에서 알파격자 조건(반복마다 1~42 한 번, 블록 공동 출현 ≤ 1), 범위 이상치 = 3건, 구 211 주변 3×3 수량 공간 경향 음수를 `console.assert`로 검산한다.
