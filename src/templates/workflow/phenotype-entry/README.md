# 표현형 데이터 입력 (workflow/phenotype-entry)

2026 생산력 검정(AYT) 시험포장 A-3(벼, 알파격자 3반복, 126구)에서 조사자가 야장을 보며 6개 조사 형질 값을 입력하는 화면이다. 입력하면 바로 검증하고, 저장·충돌 상태까지 다룬다. 입력이 끝난 자료는 `workflow/field-trial-layout`에서 검토한다. 두 화면은 같은 배치·관측값·결측·이상치·메모를 쓴다.

명세: `docs/specs/phenotype-entry.md`

## 답하는 질문

1. 입력이 어디까지 됐나? 전체 입력 진척률(값 또는 NA가 있는 칸 / 756칸), 저장 진척, 형질별·반복별 진척을 본다.
2. 저장 전에 고칠 칸은 어디인가? 오류(불가능 값·형식 위반)는 저장을 막는다. 주의(허용 범위 밖, 반복 간 편차)는 확인만 하면 된다.
3. 내 입력이 저장됐나? 저장 상태는 미저장, 저장 중, 저장됨, 충돌 넷 중 하나다.

## 구성

| 영역 | 구현 |
| --- | --- |
| 저장 상태 막대 | `components/SaveBar.tsx`. md 이상에서는 상단 sticky(top-4), md 미만에서는 화면 아래에 고정. 상태 배지는 `role=status`이고, 오류가 있으면 저장 버튼이 비활성되면서 그 이유를 글로 보여 준다 |
| 진척·검증 요약 | `KpiTile` 4개(입력 진척률 hero), `components/ProgressBars.tsx`(저장분은 진한 막대, 미저장분은 빗금 막대) |
| 도구 막대 | 반복 `Segmented`, 검증 상태 `Select`(괄호 안 행 수는 실시간 계산), 계통 검색, 키보드 단축키 도움말 |
| 입력 그리드 | `components/EntryGrid.tsx`. HTML table + `role=grid`, 로빙 tabindex, 스프레드시트 방식 키보드, 탭·줄바꿈 붙여넣기 |
| 셀 상세 | `components/CellDetail.tsx`. 사유 문구, 같은 처리 다른 반복 값, 다른 반복 평균과의 차이, 서버 값과 내 값, 충돌 해소 버튼 |
| 검증 목록 | `AlertList`. 경보 = 오류·충돌, 주의 = 범위 밖·반복 편차. 항목을 누르면 해당 칸으로 이동한다(가려져 있으면 필터를 먼저 초기화) |

## 데이터 교체

`data.ts`에서 아래 상수만 실제 API로 바꾸면 된다. 진척률, 검증 집계, 행 필터 수는 모두 칸 상태에서 계산한다.

- `PLOTS`: 구 배치(구 번호·반복·블록·행·열·처리)
- `SAVED`: 서버 저장값(`'{구}|{형질}'` → 숫자 또는 `'NA'`)
- `DRAFT`: 브라우저 로컬 초안(미저장 칸)
- `REMOTE`: 세션 시작 이후 다른 사용자가 바꾼 칸(실제로는 저장 API 응답의 버전 충돌)
- `TRAITS`: 형질별 불가능 범위·허용 범위·반복 편차 기준 D. 모두 **추정값**이므로 기관 기준으로 조정한다

저장은 `index.tsx`의 `save()`와 `resolve()`가 900 ms 지연으로 흉내 낸다. `?save=error`를 붙이면 저장 전체 실패를, `?state=loading|empty|error`를 붙이면 상태 화면을 볼 수 있다.
